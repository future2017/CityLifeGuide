# 慈善资源与个人众筹

> ⏱ 本文信息采集于 **2026-09**。政策调整频繁，动手前请用文末的「信息核实方式」确认一次。

> 📎 本节讲**政府之外的钱**。**政策救助部分（大病保险、医疗救助）见 [4.10 大病保险与医疗救助](catastrophic-insurance-and-medical-assistance.md)。**
> 顺序很重要：先走完政府救助，再找社会资源。

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 慈善与众筹是政府三重制度之外的补充，靠申请、看名额、不保证成功；先走完医保、大病保险、医疗救助再来 |
| **要带什么** | 慈善申请：诊断证明原件（须医院公章）、病案首页、治疗发票；众筹另需身份信息、家庭收入财产与求助目标金额 |
| **去哪办 / 找谁** | 儿童大病项目走户籍地县级红十字会（「红救助」小程序）；药品援助问主治医生；众筹限民政部指定平台 |
| **多久 / 多少钱** | 小天使基金白血病5万/3万；天使阳光基金先心5000–30000元；名额有限，当年资金不足顺延次年 |
| **最大的坑** | 隐瞒房产或商业保险即属「隐瞒事实」——会被终止服务、追回已拨资金；跳过政府救助先众筹，会损失确定性更高的路 |

## 一句话结论

> 政府的「三重制度」之外还有一层，就是**慈善组织与个人众筹**。它填的是政策报销之后仍然剩下的窟窿，特点是**靠申请、看名额、不保证成功**。

顺序不能颠倒：**先把基本医保、大病保险、医疗救助走完，再来找社会资源**。跳过政府救助直接发起众筹，往往是把最确定的一条路浪费掉了。

## 慈善组织与公益项目

### 先说清一件事：慈善救助是三重的补充，不是替代

国办发〔2021〕42号的定位是「发挥**补充**救助作用」。所有慈善项目的申请表，都会要求你先出示医保报销后的自付金额。**先把医保和救助走完，再去申请慈善。**

慈善医疗救助大致分五类：

| 类别 | 代表机构与项目 | 面向 |
|---|---|---|
| **儿童大病专项救助**（中央专项彩票公益金支持） | 中国红十字基金会「中央专项彩票公益金大病儿童救助项目」：**小天使基金**（白血病）、**天使阳光基金**（先心病） | 限定年龄的患儿，通常需中国籍 |
| **药品援助（患者援助项目，PAP）** | 中华慈善总会接受药企捐赠药品，向符合条件的低收入患者免费提供。官网公开的项目包括泰瑞沙、达希纳、捷恪卫、泰圣奇、高罗华等 | 特定药品对应适应症的患者，通常**须经项目注册医生医学评估**，部分项目仅接受「病前低保患者」 |
| **手术救助** | 中华慈善总会的「微笑列车」（唇腭裂免费手术）、「少数民族贫困家庭先心病儿童救助行动」、「贫困家庭包虫病患者救助行动」、「苦尽肝来」终末期肝病患儿医疗救助项目 | 特定病种 |
| **残障康复** | 中国残疾人福利基金会「集善工程」：启明行动（白内障）、助听行动（助听器/人工耳蜗）、助行行动等 | 残疾人及康复需求人群 |
| **政府与慈善协作** | 中华慈善总会「守望相助'救急难'行动」（由民政部社会救助司指导，依托低收入人口动态监测平台，帮扶政府救助后仍有困难的群众） | 经政府救助后仍困难的群众 |

（来源：[中国红十字基金会](https://www.crcf.org.cn/article/category/xiangmu_name_zhongyang)、[中华慈善总会](https://www.chinacharityfederation.org/)。）

### 怎么联系、走哪条链

**儿童大病救助有固定通路：不直接向基金会申请，必须从户籍地县级红十字会走起。**

中国红十字基金会明确：「**中国红十字基金会不直接受理个人申请**，所有渠道均由**户籍所在地县级及以上红十字会**逐级审核上报。」

- 线上：微信搜索「**红救助**」小程序在线填表上传；或关注「**小红救助**」微信公众号下载申请表
- 线下：把材料交到患儿户籍所在地**县级红十字会**
- 流程：提交资料 → 县区级红十字会逐级上报 → 中国红十字基金会审核下发《资助告知书》→ 按告知书补充回执资料 → 审核通过后发放救助金

小天使基金（0–18 周岁白血病患儿）的资助档位与必备材料（据地方红十字会转载的申请指南）：

- 已完成造血干细胞移植：一次性资助 **5 万元/人**
- 无需移植、或需移植但尚未手术：一次性资助 **3 万元/人**
- 先领 3 万元、后续完成移植：追加 **2 万元/人**
- 必备材料：完整填写的资助申请表（法定监护人签字）；患儿及父母双方户口簿复印件、父母双方身份证复印件（无法证明监护关系的补出生证明或派出所监护关系证明原件）；加盖医院公章/医务处章/疾病诊断专用章的最新病情诊断证明原件；加盖病案复印专用章的住院病案首页复印件；骨髓检查报告；**1000 元以上的治疗发票**

天使阳光基金（0–14 周岁先心病患儿）：按**家庭医疗自付金额**划分档次给予 **5000–30000 元**资金救助，需提供心脏彩超/超声心动图报告和标注「先天性心脏病/先心病」字样的诊断证明。

**两个必须知道的限制：**

- **名额和资金有限，按资料审核通过的先后顺序安排。当年资金不足则顺延至下一年。** 这不是「符合条件就一定给」，尽早、完整地提交才有效。
- 需要医院和医生配合（诊断证明、病案首页、专项检查报告），提前和主管医生打招呼。

### 药品援助类怎么找

以中华慈善总会为代表的药品援助项目，一般不做公开募捐，而是**接受药企捐赠的药品**定向发放给符合条件的患者。寻找路径：

1. 拿到药名（通用名或商品名），去中华慈善总会官网搜索是否有对应项目
2. 问你的**主治医生**——项目一般有「项目注册医生」名单，医生是否在名单内直接决定你能不能申请
3. 查该药品生产企业的官网患者援助栏目

中华慈善总会公开的联系方式：咨询电话 **010-66083260**，地址北京市西城区二龙路甲33号新龙大厦。

### 怎么核实一个慈善组织是真是假

**这一步不要省。** 骗局最爱伪造「基金会」「爱心组织」的名头。

民政部搭建了全国慈善信息公开平台「**慈善中国**」——**https://cszg.mca.gov.cn** （也可通过民政部门户网站 www.mca.gov.cn 的入口进入）。它可以查到：

- 慈善组织的登记信息（是否真实存在、登记机关、业务范围）
- **是否具有公开募捐资格**（没有这个资格的组织不得面向公众募捐）
- 公开募捐方案的**备案编号**（凡合法公开募捐活动都有「一号一源」可追溯的备案编号）
- 年度工作报告、财务会计报告、慈善项目实施情况

**三条识别规则：**

1. 合法公开募捐，**募捐方案必须在民政部门备案**，有备案编号。主办方拿不出备案编号的，直接排除。
2. **不具有公开募捐资格的组织或者个人，不得自行开展公开募捐。** 有人以个人名义在微信群、朋友圈「为某患者募捐」的，不属于合法的慈善公开募捐。
3. **慈善组织的银行账户必须是该慈善组织本组织的账户**，不得使用其他组织或者个人的账户。让你把钱转到个人微信/支付宝/银行卡的，一律拒绝。

## 网络众筹：能做什么、有什么风险

### 先分清两个概念

这一节说的是「**个人求助**」，指个人因疾病等原因导致家庭经济困难，向社会发布求助信息。**它不是慈善公开募捐，是个人赠与行为。** 法律后果完全不同：

| | 慈善公开募捐 | 个人求助 |
|---|---|---|
| 主体 | 具有公开募捐资格的慈善组织 | 求助人本人 / 信息发布人 |
| 受益人 | **不得为特定个人**（须有明确的受益人范围和确定方式） | 就是特定的求助人 |
| 平台 | 民政部指定的**互联网公开募捐服务平台** | 民政部指定的**个人求助网络服务平台** |
| 谁对信息真实性负责 | 慈善组织，并对合作方行为负监督责任 | **求助人和信息发布人** |
| 能否开捐赠票据税前扣除 | 能 | **不能** |

**所以：网络众筹收到的钱，不能开慈善捐赠税前扣除票据，也不受慈善组织那套信息公开规则约束。** 平台页面上必须显著提示这一点——这是《公开募捐平台服务管理办法》（2026-05-01 施行）修订后新增的要求：「应当在显著位置向公众进行风险防范提示，告知其信息不属于慈善公开募捐信息，**真实性由求助人和信息发布个人负责**。」

### 唯一的合法入口：民政部指定的平台

**《慈善法》第一百二十四条（2023-12-29 修改）**：

> 「个人因疾病等原因导致家庭经济困难，向社会发布求助信息的，**求助人和信息发布人应当对信息真实性负责，不得通过虚构、隐瞒事实等方式骗取救助**。从事个人求助网络服务的平台**应当经国务院民政部门指定**，对通过其发布的求助信息真实性进行查验，并及时、全面向社会公开相关信息。」

配套规章是《**个人求助网络服务平台管理办法**》（民政部等五部门令第75号，2024-09-05 公布施行）。它的核心规定：

- **第三条**：个人求助网络服务平台**应当经国务院民政部门指定**。**未经指定，任何组织或者个人不得以个人求助网络服务平台的名义开展活动**，不得从事求助信息发布和捐助资金归集、管理、拨付等个人求助网络服务。
- **第四条**：指定条件包括——运营主体为公司的，**实缴注册资本不低于 2000 万元**；**与银行签订捐助资金存管协议**；网络安全保护等级不低于三级；**具备查验通过其发布的求助信息真实性的能力**；只从事个人求助网络服务。
- **第十一条**：平台应当要求求助人、信息发布人提交五类信息和材料：① 身份信息；② 因疾病等原因导致家庭经济困难的情况；③ **求助目标金额及用途**；④ **求助信息真实性声明**；⑤ 其他需要说明的情况。并**建立审核团队，对求助信息的真实性进行查验**。
- **第十三条**：捐助资金应当由**专用存款账户管理、专项使用**。除平台收取服务费用、捐助资金无法原路退回等情形外，**只能向求助人本人或者其提供的医院等账户转账**。
- **第二十三条**：平台应于每年 6 月 30 日前向民政部报送上一年度工作报告和财务会计报告，**每半年向社会公开一次**其从事个人求助网络服务的情况。

**民政部 2024 年 12 月按上述办法组织遴选，公示的拟指定名单为三家**（[来源](https://mzj.sz.gov.cn/szmz/pc/zwgk/jcxxgk/zcqy/content/post_11912248.html)）：

| 平台名称 | 运营主体 |
|---|---|
| 水滴筹 | 北京水滴互保科技有限公司 |
| 轻松筹 | 北京众意互联网络科技有限公司 |
| 暖心惠民 | 北京暖心惠民科技有限公司 |

> 这份名单可能调整。发起前请到民政部官网确认当前的指定名单。**在其他任何平台发起「个人大病筹款」，都不符合现行规定。**

### 你要提交什么

法规层面的五类材料（上文第十一条）落到实操，各平台界面大同小异，一般是：

1. **身份**：求助人身份证正反面；发起人（信息发布人）身份信息；亲属关系证明（户口簿、出生证明等，证明你有权代为发起）
2. **病情**：诊断证明、检查报告（CT/病理/化验）、住院记录或出院小结
3. **费用**：医疗费用票据、费用清单、住院押金单、预估治疗费用说明
4. **家庭经济状况**：收入情况、房产、车辆、存款、医保参保情况、是否购买商业保险
5. **求助文**：求助目标金额及用途说明
6. **真实性声明**：这是法定必填项

平台一般会用「**技术+人工**」的方式持续审核，并公开必要的身份信息、困难情况、目标金额及用途，供公众监督；同时开通举报、证实、评论功能，让求助人社交圈内的熟人参与验证。

### 发布者要承担什么责任（本节最需要记住的部分）

**这是 2023 年修法新增的法定责任，不是平台自己的规矩。**

- **对信息真实性负责。** 《慈善法》第一百二十四条：求助人和信息发布人**应当对信息真实性负责**，不得通过虚构、隐瞒事实等方式骗取救助。
- **平台必须明确告知你这一点**（《管理办法》第十条）。
- **一旦被认定虚构或隐瞒**：平台应当**及时终止服务**，要求相关责任人**退回已经拨付的捐助资金并退还捐助人**（《管理办法》）。实践中平台还会把违规用户列入黑名单，禁止再次发起筹款。
- **可能承担法律责任**：骗取的捐助资金要返还；情节严重、涉嫌诈骗的，平台应当向公安机关反映，由司法机关追究责任。
- **用别人的材料、用别人的身份证发起**，属于「信息发布人」而非「求助人」，同样对真实性负责，责任不会因为「不是本人」而转移。

**一句话：众筹不是「讲故事筹钱」，是一份需要签字确认的信息真实性承诺。隐瞒一套房、一辆车、一份商业保险，都构成「隐瞒事实」。**

### 常见骗局与风险提示

1. **假平台 / 假代办。** 未经民政部指定就开展个人求助网络服务是违规行为，由县级以上民政部门责令限期改正，逾期不改会同网信、电信主管部门处理。**凡是自称「众筹专员」「筹款顾问」向你收取「代办费」「推广费」「加急费」来帮你筹款的，先查他是不是平台员工，再查平台是否在民政部指定名单上。**
2. **私下转账。** 合法资金流向只有一个：捐助人 → 平台的**专用存款账户** → 求助人本人账户或医院账户。**任何让你把钱转到私人微信、支付宝、银行卡的「志愿者」，都是骗子。**
3. **服务费要看清。** 《管理办法》第十七条允许平台收取**合理的费用**，但要求按**保本或者微利**原则确定收费项目、内容、标准、方式并**向社会公开**；**不得采用用户默认同意的方式收费，不得变相收费，不得搭售其他服务、捆绑收费**。实际费率各平台不同且会调整，**发起前把平台的收费规则完整读一遍**，别默认同意。（媒体曾报道过按提现金额一定比例收费、并设单项目上限的做法，但费率属于会变的商业信息——以你发起时平台公示的规则为准。）
4. **信息过度暴露。** 上传的身份证、户口簿、诊断证明、病案一旦上传就难以完全撤回。可能被用于推销、骚扰甚至精准诈骗。**只上传必要部分，对身份证号、详细住址、私人手机号做遮蔽。** 《管理办法》第十三条对个人信息保护有规定，但自我保护是第一层。
5. **筹款目的实现或消失后怎么办。** 《管理办法》要求：求助目的实现或者消失而尚未支出的捐助资金，应当退回捐助人。**如果筹到钱后放弃治疗、或情况发生重大变化，不要自己处置这笔钱**——按平台规则办理退回，否则可能被认定为挪用。
6. **提现规则各不同。** 提现的时间条件和材料要求由各平台在其公开规则中确定（例如"捐助人一定期限内未撤销捐助或提出异议后方可申请提现"），**各平台不一样，也可能调整**。急于用钱时要把这段时间留出来，并在发起前读一遍平台的提现规则。
7. **是「平台核实」不是「官方认证」。** 平台履行的是**查验义务**，不等于政府背书。捐助人看到的「已核实」，是平台基于你提交材料的审核结论。

## 办不成怎么办

### 慈善项目申请没有回音 / 被拒

- 先确认**是否投到了正确通道**：多数儿童大病项目**不直接向基金会申请**，而是通过合作医院或地方红十字会转报，投错地方等于没投
- 材料不全是退回的头号原因：诊断证明、费用清单、家庭收入证明缺一项就走不下去
- 被拒时**要求书面说明理由**；同一项目通常可以隔期再报

### 众筹审核不通过

- 平台会核对诊断证明、费用凭证与家庭财产状况；**夸大或隐瞒会被驳回**，严重时影响已筹款项
- 信息真实性与合规责任在**发布人**：失实可能承担法律责任

### 筹不到足够的钱

- 先把提现规则、服务费、退款规则读一遍（法规要求平台**保本或微利经营并公开收费**）
- 剩余缺口回到政策侧核对：大病保险是否已经触发？医疗救助是否已经申请？（见 [4.10](catastrophic-insurance-and-medical-assistance.md)）

### 遇到冒充的「基金会」

- 先上**「慈善中国」**查这个组织是否登记、项目是否备案；查不到的，一分钱都不要打
- 正规平台的款项进入**指定专用存款账户**，而不是某个人的个人账户

## 常见错误

- **先众筹、后跑政府救助** —— 顺序反了，损失了确定性更高的救助
- **找「基金会」不查登记** —— 骗局最爱伪造「爱心组织」「基金会」名头
- **用个人收款账户接受捐款** —— 正规平台的款项进入指定专用存款账户
- **夸大病情或隐瞒家庭资产** —— 发布人对信息真实性负责，失实可能承担法律责任
- **以为众筹来的钱不影响低保或救助资格认定** —— 财产状况变化需向认定部门报告

## 信息核实方式

1. **慈善中国**（民政部全国慈善信息公开平台）—— 查组织是否登记、项目是否备案
2. **民政部官网** —— 个人求助网络服务平台的指定名单
3. **中国红十字基金会、中华慈善总会官网** —— 项目与申请条件
4. **12345** —— 当地医疗救助政策与经办部门
5. **12393** —— 基本医保与大病保险的报销口径

## 行动清单

- [ ] 先确认基本医保、大病保险、医疗救助**三条路都走完了**（见 [4.10](catastrophic-insurance-and-medical-assistance.md)）
- [ ] 保存**全部发票原件与结算单** —— 慈善项目与众筹都要用
- [ ] 向慈善组织申请前，先在「慈善中国」上**核实该组织与项目**
- [ ] 发起众筹前，如实核对家庭可支配财产，避免被质疑失实
- [ ] 众筹信息由**本人或近亲属**发布，不找「代运营」中介
- [ ] 建一个票据文件夹，按时间存放
