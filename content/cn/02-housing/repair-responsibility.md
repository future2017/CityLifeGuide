# 房屋维修责任划分

> ⏱ 本文信息采集于 **2026-11**。法律与地方细则会变，动手前请用文末的「信息核实方式」确认一次。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 合同没约定时租房维修房东负责；人为损坏你赔，正常损耗不赔；共用部位大修走维修资金 |
| **要带什么** | 合同、入住交接单、带时间照片视频、文字报修记录、维修发票或报价单、保修书 |
| **去哪办 / 找谁** | 先找房东或物业；物业推诿拨 `12345` 转住建；保修期内找开发商或住建工程质量监督机构 |
| **多久 / 多少钱** | 日常维修通常几天；投诉转办 7–15 个工作日；调解和投诉免费，维修费由责任方承担 |
| **最大的坑** | 只口头报修、维修不留票，事后既难要钱也难抵租 |

## 一句话结论

**房屋维修先看合同；合同没写，就按《民法典》第七百一十二条由出租人修。** 房东不修，你可催告后自行维修、费用由房东负担；维修影响居住，可要求减租或延长租期。你弄坏的、擅自改造的你修你赔；正常使用的磨损不赔。共用部位大修，保修期内找开发商，期满走维修资金。

---

## 适用情形

**你租市场租赁住房。** 房东、二房东、住房租赁企业都算出租人，租赁企业同样适用《住房租赁条例》关于出租人的规定（第十四条第三款）。你和谁签合同就向谁主张维修；二房东跑路时，原房东是否担责看其是否同意转租。

**你是房东。** 房屋本体和设施自然损坏由你修；承租人人为损坏由承租人修或赔；共用部位大修由业主共同决定、从维修资金列支。保修期内出现质量缺陷，你应向开发商主张，不能把成本转给承租人。

**你是业主或业委会成员。** 电梯、屋顶、外墙、消防、供水等共用部位，日常养护由物业按合同做；大修、更新、改造才动用维修资金，并须经业主共同决定。

**你买的是保修期内的新建商品房。** 保修期从交付之日起算，主体结构、防水、供热供冷、电气管线各有最低期限。保修期内属于保修范围的质量问题，由房地产开发企业承担保修责任。

**不适用本文的情形。** 公租房、保障性租赁住房、单位自管房、直管公房另有规定；集体土地上的住房租赁由省级政府另行制定办法（《住房租赁条例》第四十九条）。

---

## 需要准备什么

**承租人**：合同和入住交接单（看维修条款、家电清单、原有瑕疵）；微信文字、短信、工单等报修记录，写清故障位置、时间、影响；带时间的照片视频，漏水拍源头和水渍范围，电器拍铭牌和故障现象；维修发票、收据、付款记录、换下的旧件；因漏水断电造成的物品损失清单。

**房东**：房屋质量保修书、交付通知书，确认开发商保修期起算日和剩余期限；物业服务合同，看清哪些日常维修由物业承担；维修资金账户信息；每次报修的时间、内容、费用、票据台账。

**业主**：不动产权证或房产证；业主大会决议、管理规约；维修方案、预算和分摊明细。

---

## 先分清四层责任

多数维修纠纷不是「谁该修」不清楚，而是把四层责任混成一层。按下面顺序判断：

| 情形 | 谁承担 | 依据 |
|---|---|---|
| 房屋本体、防水、供暖和供水管线自然损坏 | 出租人维修，费用出租人负担 | 《民法典》第七百一十二条、第七百一十三条 |
| 你按约定方法、按房屋性质正常使用造成的磨损 | 你不承担赔偿责任 | 《民法典》第七百一十条 |
| 你或同住人使用不当、私拉乱接、擅自拆改造成损坏 | 你维修或赔偿；擅自改善、增设的，恢复原状或赔偿 | 《民法典》第七百一十一条、第七百一十四条、第七百一十五条 |
| 家具家电自然老化、性能下降 | 出租人维修或更换 | 《民法典》第七百一十二条 |
| 灯泡、滤芯、电池、水龙头起泡器等易耗件 | 先看合同；没有约定时通常由承租人更换 | 《民法典》第七百一十二条「当事人另有约定」 |
| 共用部位、共用设施设备的日常维修养护 | 物业服务人按合同维修养护 | 《民法典》第九百四十二条 |
| 共用部位、共用设施设备的大修、更新、改造 | 保修期满后从住宅专项维修资金列支 | 《民法典》第二百八十一条；165 号令第十八条 |
| 保修期内属于保修范围的质量缺陷 | 房地产开发企业承担保修责任 | 《商品房销售管理办法》第三十三条；279 号令第四十条 |
| 公租房及其配套设施 | 所有权人及其委托的运营单位负责维修养护 | 住建部令第 11 号第二十四条 |

《民法典》第七百一十二条允许「当事人另有约定」，因此合同写「房屋及设施维修由承租人负责」一般有效。但把承重结构、消防设施、燃气管道等涉及安全的维修全部推给承租人，或用格式条款排除你主要权利的，效力存疑。签约时至少写清：哪些由房东修、哪些由你负责、报修后多久响应、紧急情况怎么处理。

## 什么算正常损耗，什么算你弄坏的

《民法典》第七百一十条：按照约定的方法或者根据租赁物的性质使用，致使租赁物受到损耗的，不承担赔偿责任。第七百一十三条第二款：因承租人过错致使租赁物需要维修的，出租人不承担维修义务。

| 通常算正常损耗（你不赔） | 通常算人为损坏（你修或赔） |
|---|---|
| 墙面自然泛黄、轻微污渍、细小裂纹 | 烟头烫痕、大面积涂鸦、打孔后不修补 |
| 木地板轻微磨损、非泡水造成的局部起翘 | 泡水导致地板大面积变形、发霉 |
| 家具正常使用痕迹、螺丝轻微松动 | 家具断裂、缺失、宠物抓咬 |
| 家电自然老化、制冷制热效果下降 | 违规使用导致烧毁、进水 |
| 窗帘、沙发套自然褪色 | 撕裂、染色、烟味难以去除 |
| 卫生间正常水垢、地漏正常老化 | 人为堵塞、砸裂瓷砖、私改管线 |

判断抓四点：看入住状态，入住照片、视频能证明「原来就有」；看使用方式，是否按约定用途使用、是否超负荷、是否擅自改装；赔偿按修复费用或折旧价，不按全新价，房东不能借一次损坏搞全屋翻新；自然老化属房东维修范围，不能从押金里扣。

## 共用部位与专项维修资金

### 什么算共用部位

165 号令第三条：共用部位一般包括住宅的基础、承重墙体、柱、梁、楼板、屋顶、户外墙面、门厅、楼梯间、走廊通道等；共用设施设备一般包括电梯、照明、消防设施、绿地、道路、路灯、沟渠、池、井、非经营性车场车库等。

### 钱从哪来

商品住宅、非住宅业主按建筑面积交存首期维修资金，每平方米为当地住宅建筑安装工程每平方米造价的 **5% 至 8%**，具体标准由市县人民政府住建部门确定并公布（165 号令第七条）。分户账面余额不足首期交存额 **30%** 的，应及时续交（第十七条）。

### 什么能花，什么不能花

维修资金**专项用于共用部位、共用设施设备保修期满后的维修和更新、改造**，不得挪作他用（第十八条）。下列费用不得列支（第二十五条）：保修期内应由建设单位或施工单位承担的维修费用；供水、供电、供气、供热、通讯、有线电视等单位应承担的管线设施维修养护费；人为损坏的修复费；物业服务合同约定由物业承担的日常维修养护费。

这条边界很重要：**保修期内找开发商，日常小修找物业，人为损坏找肇事者，只有保修期满后的大修、更新、改造才动维修资金。** 物业费覆盖日常养护；电梯主要部件更换、屋顶翻修、外墙修缮、二次供水改造走维修资金。物业把大修拆成小修、反复走物业费或要求业主摊派，可要求其出示合同依据和费用明细。

### 使用要业主表决

《民法典》第二百七十八条规定，使用建筑物及其附属设施的维修资金属业主共同决定事项：应由专有部分面积占比三分之二以上的业主且人数占比三分之二以上的业主参与表决，经参与表决专有部分面积过半数的业主且参与表决人数过半数的业主同意。筹集维修资金门槛更高，须经参与表决专有部分面积四分之三以上且人数四分之三以上的业主同意。

165 号令第二十二条的「双三分之二讨论通过」是 2008 年口径，早于《民法典》；现在应按第二百七十八条执行，地方办事指南也已调整。业委会仍拿旧标准说事，可要求其说明依据。

### 紧急情况可以走应急通道

《民法典》第二百八十一条第二款：紧急情况下需要维修建筑物及其附属设施的，业主大会或者业主委员会可以依法申请使用维修资金。165 号令第二十四条规定，发生危及房屋安全的紧急情况可按应急程序列支；未按规定维修的，住建部门可以组织代修，费用从相关业主分户账中列支。电梯困人、消防失灵、屋面严重渗漏、外墙有脱落危险，都应尽快处理。

## 保修期内找开发商

《建设工程质量管理条例》第四十条规定，正常使用条件下最低保修期限为：地基基础和主体结构，为设计文件规定的合理使用年限；屋面防水、有防水要求的卫生间、房间和外墙面防渗漏，为 **5 年**；供热与供冷系统，为 **2 个采暖期、供冷期**；电气管线、给排水管道、设备安装和装修工程，为 **2 年**。其他项目由发包方与承包方约定；保修期自竣工验收合格之日起计算。

你拿到的是「交付起算」的保修期。《商品房销售管理办法》第三十三条规定，房地产开发企业应当对所售商品房承担质量保修责任，保修期从**交付之日**起计算；商品住宅保修期限不得低于施工单位出具的质量保修书约定保修期的存续期，存续期少于规定最低期限的，不得低于最低期限。收好《住宅质量保证书》《住宅使用说明书》和交付通知；租房时可向房东索要，确认是否还在保修期内。

开发商不修的，向项目所在地住建部门工程质量监督机构投诉；《建设工程质量管理条例》第五十三条规定任何单位和个人都有权检举、控告、投诉。顺序是：书面报修留记录 → 投诉 → 主张赔偿。不要自己先大修再找开发商，除非情况紧急且已留证。

## 租客怎么催修和留证

**第一步，书面报修并给合理期限。** 微信文字、短信、邮件都行，写清故障是什么、何时开始、影响到什么程度、请对方在什么期限内修。常见做法是给 3–7 天；漏水、漏电、燃气、电梯困人等紧急情况，应立即报修并通知物业。

示例：

> X 先生/女士：我是 X 小区 X 栋 X 室承租人。卫生间顶部自 X 月 X 日起持续渗水，已拍照，影响使用并有漏电风险。请于 X 月 X 日前维修；逾期我将按《民法典》第七百一十三条自行维修，费用由你承担，并保留主张减租的权利。

**第二步，房东不修再自行维修。** 《民法典》第七百一十三条第一款：承租人在租赁物需要维修时可以请求出租人在合理期限内维修；出租人未履行维修义务的，承租人可以自行维修，维修费用由出租人负担。注意三点：先催告（紧急情况除外）、费用合理（先要报价，别趁机换新）、票据齐全（发票、付款记录、旧件照片）。涉及燃气、电路、承重结构的，必须找专业单位。

**第三步，主张抵扣、减租或延长租期。** 维修费可要求房东支付，也可协商从下期租金抵扣，但要用书面方式确认，别单方少付租金，否则可能被认定欠租。因维修影响使用的，按第七百一十三条可要求相应减少租金或延长租期；影响天数、折算金额最好当场记录并书面确认。

证据清单：报修聊天原始记录、带时间水印的照片视频、维修合同和票据、自己参与的通话录音、住宿费和物品损失票据。

## 房东怎么防止被过度索赔

1. **合同写细。** 列明谁修什么、易耗品谁换、报修响应时间、紧急入户规则，别只写「维修由承租人负责」。
2. **交接做足。** 入住时逐项列家具家电、拍照、抄表，双方签字；退租按同一张清单验收。
3. **及时响应。** 收到报修先回复再约时间；拖着不修，承租人自行维修后费用还是你承担，还可能被要求减租。
4. **区分损耗与损坏。** 自然老化、原有瑕疵自己承担；人为损坏要求承租人修或赔，但要有照片、交接单、报价支撑。
5. **不拿押金当维修基金，保留维修记录。** 押金只能扣欠租、欠费和实际损失，没有凭证的「翻新费」「折旧费」站不住；维修日期、项目、费用、施工方留档，既方便向开发商或维修资金主张，也证明你尽到义务。

## 去哪里办

| 渠道 | 能做什么 | 边界 |
|---|---|---|
| 房东本人 | 报修、约时间、协商费用和减租 | 没有强制力，靠合同和证据 |
| 物业服务企业 | 共用部位日常维修养护；协助入户、止损、见证 | 室内自用部位一般不归物业免费修 |
| 居委会、街道人民调解委员会 | 免费调解，熟悉本地情况 | 一方不同意就调不成 |
| `12345` 政务服务便民热线 | 转办住建、房管、街道等部门，留下工单号 | 不裁决民事纠纷，只协调转办 |
| 住建部门（住建委、房管局） | 监管物业、租赁企业、维修资金；处理工程质量投诉 | 对个人房东多只能调解 |
| 工程质量监督机构 | 受理保修期内的房屋质量缺陷投诉 | 需项目名称、交付时间、具体缺陷 |
| `12348` 公共法律服务热线 | 免费法律咨询，符合条件可申请法律援助 | 维修纠纷通常需自行起诉 |
| 人民法院 | 起诉要求维修、赔偿、减租或解除合同 | 要交诉讼费、耗时间 |
| `110` | 房东暴力、威胁、非法侵入、断水断电逼迁 | 维修费本身是民事纠纷，警察一般不介入 |

**顺序建议**：先书面报修协商 → 物业、居委会或 12345 调解 → 仍不解决再起诉；不要只打电话不留证据。

## 多久办完

| 事项 | 大致时间 |
|---|---|
| 房东或物业响应报修 | 合同有约定从约定；紧急情况应立即处理 |
| 日常小修 | 通常 1–7 天，视师傅档期和配件 |
| 12345 转办、住建协调 | 一般 7–15 个工作日，各地不同 |
| 人民调解 | 2–4 周，视双方配合程度 |
| 维修资金一般使用 | 从提出方案、表决、审核到划款，通常数周到数月 |
| 维修资金应急使用 | 各地有简化流程，通常快于一般程序 |
| 民事诉讼 | 简易程序 3 个月，普通程序 6 个月，均可依法延长 |

## 费用

- **日常维修**：由责任方承担。房东负责的房东付，你人为损坏的你付；价格按当地市场价，先要报价再施工。
- **承租人自行维修**：费用先垫付，凭票据向房东主张或协商抵扣租金；费用要合理，不能借机换新、扩大范围。
- **共用部位大修**：从维修资金列支，不动用业主当期现金；分户账余额不足首期交存额 30% 时需要续交。
- **投诉、12345、人民调解、12348 咨询**：免费。
- **诉讼**：案件受理费按标的额分段计算，标的额小的通常几十元；鉴定费、律师费另计。房屋质量、漏水原因、修复造价都可鉴定，费用先由申请方垫付，最终由败诉方或责任方承担。

## 办不成怎么办

### 情况 1：房东拒修、拖延、拉黑

1. 发书面催告，写明故障、影响、期限和逾期后果，保留发送记录。
2. 逾期不修，自行维修并保留票据、旧件、施工记录。
3. 书面要求房东支付维修费或协商从租金抵扣；拒绝的，发第二次催告；仍不解决，向房屋所在地法院起诉，主张维修费、减租、延长租期或赔偿。金额小的可走小额诉讼。

### 情况 2：房屋危及安全

先撤离、断水断电、报物业和 119/110/燃气公司，再书面通知房东解除合同。依据《民法典》第七百三十一条，危及安全健康的可随时解除；造成人身、财产损害的可主张赔偿。不要为了押金或租金继续住在有结构、消防、燃气隐患的房子里。

### 情况 3：物业推诿

要求物业书面说明：这项维修属不属于物业服务合同范围、依据哪一条、为什么不做。属日常养护的，向住建部门投诉物业不履行合同；属大修、更新、改造的，要求业委会或物业启动维修资金程序，业委会不作为的向街道、住建部门反映。物业以停水停电逼搬的，保留证据并报警、投诉。

### 情况 4：保修期内开发商不修

先向开发商书面报修并抄送物业，保留报修单、照片、函件；逾期不修，向项目所在地住建部门工程质量监督机构投诉；造成损失的可起诉要求维修和赔偿。不要把保修责任转嫁给承租人，也不要用维修资金替开发商买单。

### 情况 5：维修资金用不了

先查分户账余额和小区账户状态，确认是余额不足、表决未通过还是材料不全。表决未通过的，要求业委会说明表决范围和票数；对程序有异议的，可请求街道、住建部门指导，或依法请求法院撤销侵害业主合法权益的决定（《民法典》第二百八十条）。发生危及房屋安全的紧急情况，要求按应急程序列支；物业、业委会不实施的，向住建部门申请组织代修。

### 情况 6：房东反过来说你损坏房屋

要求房东列明损坏项目、位置、金额、维修凭证；用入住照片、交接单、报修记录反驳；强调正常损耗不赔（第七百一十条）；对「全屋翻新」「按全新价赔偿」提出异议，要求按修复费用或折旧价计算。

## 常见错误

1. **以为租房所有维修都归房东。** 你人为损坏、擅自改造的自己修自己赔，易耗件也可能按合同由你换。
2. **只口头报修。** 没有文字记录，房东否认收到，你很难证明已催告。
3. **没催告就先大修。** 除非情况紧急，否则应先给合理期限，费用未必能全额主张。
4. **自行维修不留票据。** 没有发票、付款记录，抵租或起诉都缺证据。
5. **单方少付租金。** 未经书面确认直接扣租，可能被认定欠租，反被解除合同。
6. **把正常损耗当损坏赔。** 墙面泛黄、地板轻微磨损、家电老化，不该你赔。
7. **把保修期内的质量缺陷推给维修资金。** 保修期内应由开发商承担，维修资金不得列支。
8. **以为物业费包含大修。** 物业费覆盖日常维修养护，电梯更换、屋顶翻修要走维修资金。
9. **以为维修资金想用就能用。** 使用要业主共同决定，还要核对表决票数和面积；程序违法，决议可能被撤销。

## 信息核实方式

1. **国家法律法规数据库** `flk.npc.gov.cn`：核对《民法典》现行文本和条文序号。
2. **中国政府网** `www.gov.cn`：查《住房租赁条例》全文、令号和施行日期。
3. **司法部国家行政法规库** `xzfg.moj.gov.cn`：查《建设工程质量管理条例》现行修订版本。
4. **住建部**及项目所在地住建委、房管局官网：查维修资金政策、物业服务合同示范文本、工程质量投诉入口。
5. **当地住房资金管理部门或公积金中心**：查维修资金分户账余额、交存标准、使用和续筹流程；`12345` 问住建投诉电话，`12348` 问诉讼材料。

本文不构成最终依据。动手前先核实：当地维修资金交存标准、保修期起算口径、小区是否已成立业主大会。
