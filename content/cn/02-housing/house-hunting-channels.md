# 找房渠道对比与避坑

> ⏱ 本文信息采集于 **2026-11**。住房租赁规则近两年变化很大，动手前请用文末的「信息核实方式」再确认一次。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 先选渠道再刷房源：直租省钱、中介省事、二房东最险；要你先交钱的房源先停一步 |
| **要带什么** | 身份证、手机；看房核对房东身份证与不动产权证，转租的还要看原合同和授权书 |
| **去哪办 / 找谁** | 房源核验用当地住房租赁平台或不动产登记查询；备案在平台或区房产管理部门窗口 |
| **多久 / 多少钱** | 找房一到四周；备案即时到三个工作日、免费；中介费常见为半个月至一个月租金 |
| **最大的坑** | 把意向金写成定金、把钱交给中介或二房东、租到已抵押或已被查封的房子 |

## 一句话结论

**找房的第一步不是刷房源，而是先选渠道、再定核验顺序：个人房东直租成本最低但最费时间，正规中介最省事但要付佣金，长租公寓和二房东风险最高、必须查资金监管和转租授权。** 签约前只认三样：**产权证上的名字、房东本人的身份证、你自己查到的登记信息**。三样对不上，价格再低也不要签。

《住房租赁条例》（国务院令第 812 号）自 **2025 年 9 月 15 日**起施行，是我国第一部专门规范住房租赁的行政法规。它把房源信息真实、图片与实物一致、经纪机构发布前核验权属并实地看房、押金扣减须有合同依据写成法定义务，虚假房源最高可罚 10 万元。你要不到房源核验码、住房状况说明书、经纪服务合同或收费清单，本身就是信号。

---

## 适用情形：你是哪一类租客

**A. 刚毕业、第一次租房。** 预算紧、时间少，最容易被虚假房源和“押一付一”的租金贷盯上。第一原则：**不年付、不贷款、不把钱打给个人**。

**B. 跨城换工作，人还没到。** 最大风险是远程签约。必须实时视频看房、要求拍楼栋门牌、查登记信息、合同先发电子版。人不到场，不交定金。

**C. 家庭整租、准备长住。** 你更需要稳定和公共服务：**租赁备案**直接影响居住证、积分、子女入学、公积金提取。价格可以谈，备案不能省。

**D. 合租单间、预算有限。** 这是二房东、隔断房最集中的市场。先查两件事：是不是**非居住空间单独出租**（厨房、卫生间、阳台、过道、地下储藏室、车库都不行）；二房东有没有**转租授权**。

**E. 选择长租公寓。** 看三样：营业执照经营范围有没有“住房租赁”、有没有公示**租金监管账户**、是否要求一次付超过三个月租金。

## 渠道对比：四条路，成本和坑都不一样

| 渠道 | 成本 | 主要风险 | 适合谁 |
|---|---|---|---|
| **个人房东直租** | 无佣金，租金可谈 | 房源少、真假难辨、合同粗糙、房东临时反悔 | 时间充裕、愿意自己跑、租期较长的人 |
| **房产中介（居间）** | 佣金常见为半个月至一个月租金，由一方或双方承担 | 虚假房源引流、佣金外加费、“跳单”争议、代收租金 | 时间紧、异地、需要带看和合同协助的人 |
| **长租公寓 / 机构二房东** | 租金可能略高，另收服务费 | 资金链断裂、租金贷、押金难退、装修污染 | 追求拎包入住、短期过渡的人 |
| **个人二房东 / 合租** | 单价低，可短租 | 无转租授权、大房东收房、押金被卷走 | 预算紧、只住几个月的人 |
| **网络平台（作为入口）** | 免费 | 虚假房源、图片与实物不符、低价引流 | 所有人；只当线索，不当依据 |

这张表最关键的一列是“**谁承担风险**”：直租在房东个人，中介在机构，二房东在“他能不能继续从大房东手里租下去”。

### 个人房东直租

房源来自小区公告栏、业主群、熟人介绍、本地论坛和平台的“个人房源”筛选。优点是省佣金、价格好谈、能直接见到产权人；缺点是房源分散、看房难约，而且**冒充房东的成本很低**。

直租必须做三步：看**不动产权证原件**，核对权利人姓名与身份证、坐落；看**身份证原件**，让他当场登录当地不动产登记查询渠道，或与你一起去查；**租金打到产权人本人账户**，户名与产权证一致。三步缺一步，不付定金。共有房屋要求全体共有人签字或出具同意书——事前多要一个签名，比事后争论省事。

### 房产中介：你买的是居间服务

《民法典》第九百六十三条规定，中介人促成合同成立的，委托人按约定支付报酬；**未促成的，不得请求支付报酬**，只能按约定请求必要的活动费用。《房地产经纪管理办法》第十九条进一步明确：未完成约定事项或服务未达约定标准的，**不得收取佣金**；两家以上机构合作同一宗业务，**只能按一宗收费**。

2023 年住建部、市场监管总局《关于规范房地产经纪服务的意见》要求：收费各方协商、鼓励分档定价、**引导双方共同承担**、明码标价并出具**收费清单**、基本服务与延伸服务分开标价。

《住房租赁条例》把中介义务写得更细：发布房源前核对并记录委托人身份、住房权属信息，**实地查看房源**，签订经纪服务合同，编制**住房状况说明书**；收费项目明码标价，不得在标价外加价；**不得代收、代付租金和押金**（第二十五条）。

**中介费由谁承担？** 法律没有规定“必须由租客付”，原则是**谁委托、谁付费**：房东委托中介出租，理论上由房东付；你另签经纪服务合同、单独委托它找房，才由你付。实践中承租人承担或双方分担都常见。签字前问清：对应哪项服务、向谁付、能不能开发票。

两个套路要防。一是“**看房确认书**”里埋“跳单”条款：按《民法典》第九百六十五条，你利用它提供的交易机会却绕开它直接签约，可能要付报酬；但同一房源多家中介挂出、你通过另一家低佣金成交，是否构成跳单要看证据。最稳妥是**签约前书面确认佣金金额、支付时间和退费条件**。二是“**佣金外加费**”：信息费、钥匙费、辛苦费，价目表上没有的都可以拒付。

### 长租公寓与二房东：先看它有没有“收钱的资格”

“二房东”不是法律术语，法律上看两件事：是不是**住房租赁企业**，有没有**转租授权**。

《住房租赁条例》第十四条定义了住房租赁企业，第十九条要求从事转租经营的企业设立**住房租赁资金监管账户**并公示，通过该账户收付资金。住建部等六部门 2021 年的意见更具体：**转租住房 10 套（间）以上的自然人**也应办理市场主体登记；住房租赁企业**单次收租原则上不超过 3 个月**；单次收租超过 3 个月、或收押金超过 1 个月的，**应纳入监管账户**。

签之前查四样：**营业执照**经营范围有没有“住房租赁”；有没有公示**资金监管账户**；二房东与大房东的合同里有没有转租条款、**剩余租期是否覆盖你的租期**、有没有大房东的同意书；收款账户是不是对公账户或监管账户，**不能是个人微信、支付宝、银行卡**。

**租金贷是红线。** 住建部 2021 年意见明确：不得将租金贷款内容嵌入租赁合同，不得以租金分期、租金优惠等名义诱导你使用；贷款额度不得高于合同金额、期限不得超过租赁期限，**资金只能划入借款人账户**。中介说“押一付一，剩下的做个小分期”，你要问：这是不是贷款、上不上征信、钱打给谁。

二房东跑路、大房东来收房，你并非没有办法。《民法典》第七百一十九条规定：承租人拖欠租金的，**次承租人可以代承租人支付欠付的租金和违约金**，代付的钱可充抵你应付的租金，超出部分向二房东追偿。这条能帮你争取“继续住下去”的空间。同时保留合同、转账记录，联合其他租客报警并向住建部门投诉。

### 平台信息：把“线索”和“事实”分开

虚假房源的特征很稳定：价格明显低于同小区同户型；图片像样板间，同一组图出现在多个小区；只肯加微信，不肯在平台留对话；拒绝实时视频，或视频里看不到门牌、楼栋、窗外；约到现场说“刚租掉”，再带你去看更贵的。对策：同小区先比价；要求拍**楼栋号、单元门、门牌**；约**实时视频**；沟通留在平台内；发现图文不符，截图、记下发布编号，向平台和 12345 举报。

《住房租赁条例》第十六条要求企业发布的地址、面积、租金真实准确，**图片与实物一致**；第三十六条要求平台核验发布者身份；第四十二条规定发布虚假或误导性房源信息可处 **2 万元以上 10 万元以下**罚款，情节严重的可吊销营业执照。部分城市有**房源核验码**，说明平台做过权属核验，但不等于实地完全一致。

## 需要准备什么

**你自己带：** 身份证（出示即可，不交给任何人保管）；**预算表**（押金 + 首期租金 + 中介费 + 搬家 + 宽带 + 可能的物业、供暖费）；手机；卷尺、充电器。

**要求房东或中介出示：**

| 文件 | 看什么 |
|---|---|
| 不动产权证 / 房产证 | 权利人姓名、坐落、面积；与身份证是否一致 |
| 房东身份证 | 姓名与产权证一致；本人到场 |
| 授权委托书 | 产权人不到场时，写明授权范围、期限，最好有视频确认 |
| 转租授权 + 原租赁合同 | 二房东场景；原合同是否允许转租、剩余租期是否覆盖你的租期 |
| 不动产登记查询结果 | 是否抵押、是否查封；共有人情况 |
| 住房状况说明书 | 中介或租赁企业应编制，写明房屋状况、租金押金、费用分担 |

**签约后要留下：** 合同原件或电子合同；押金、定金、中介费收据或发票；**收费清单**（签字版）；交接清单；入住当天水电燃气表读数照片；转账记录；房东身份证照片（注明“仅用于本次租赁备案”）。

**不需要：** 身份证原件托管、押金之外的“钥匙费”“信息费”、未看房先交的“锁定房源费”、空白合同签字。

## 去哪里办 / 找谁

| 你要办的事 | 去哪里 |
|---|---|
| 找政府核验过的房源 | 当地**住房租赁管理服务平台**、政务服务 APP 的住房租赁专区 |
| 查中介/租赁企业是否备案 | 当地住建委（房管局）官网公示名单；国家企业信用信息公示系统 |
| 查房屋抵押、查封 | 当地不动产登记中心；部分城市政务 APP（权利人、利害关系人） |
| 办租赁合同备案 | 当地住房租赁平台、政务服务 APP，或区房产管理部门窗口 |
| 投诉乱收费、虚假房源 | `12345`、`12315`；当地住建委（房管局） |
| 涉嫌合同诈骗、卷款跑路 | `110` 报警，同时向住建部门投诉 |
| 法律咨询 | `12348` |

**办事话术：** “我要办**住房租赁合同备案**，合同已经签了，房东不配合，我作为承租人自己来办，需要哪些材料？”不知道找哪个部门，就先打 12345 问“住房租赁备案、中介投诉归谁管”。

## 多久办完

| 事项 | 时效 |
|---|---|
| 找房、看房 | 通常 **1–4 周**；旺季、核心地段更久 |
| 产权、抵押、查封核验 | 当场看证 + 线上查询 **1 天内**；线下查档 **1–3 个工作日** |
| 签约 | **半天**；逐条看完再签，不赶 |
| 租赁合同备案 | 线上**即时到 3 个工作日**；线下材料齐全一般**当场或 3 个工作日内** |
| 中介费、定金纠纷协商 | **1–2 周**；投诉处理通常 **15–60 日** |
| 民事诉讼 | 简易程序 **3 个月**，普通程序 **6 个月**（不含上诉） |

备案的法定起点是**合同订立后 30 日内**（《商品房屋租赁管理办法》第十四条）。《住房租赁条例》第八条明确：**未备案时承租人可以自己办**、**备案不得收费**。房东拖，你不用等。

## 费用

| 项目 | 常见口径 | 说明 |
|---|---|---|
| **中介费（佣金）** | 半个月至一个月租金 | 市场惯例，不是法定标准；北京规定经纪机构佣金**一般不超过一个月租金**，续租不得再收。谁承担以合同约定为准 |
| **定金** | 常见一个月租金 | 法律上限是**合同总额的 20%**（《民法典》第五百八十六条），超过部分不产生定金效力 |
| **押金** | 常见一个月租金 | 合同写明数额、返还时间、扣减情形（《住房租赁条例》第十条）；租赁企业超收部分需进监管账户 |
| **首期租金** | “押一付三”最常见 | 长租公寓单次收租原则上不超过 3 个月，超收部分应进监管账户 |
| **租赁备案** | **免费** | 《住房租赁条例》第八条明确不得收费 |

**算一笔账。** 月租 3000 元，押一付三：押金 3000 + 首期租金 9000 = **12000 元**；中介费一个月 3000 元，首付 **15000 元**；半个月 1500 元，首付 **13500 元**。佣金谈下半个月，当场少掏 **1500 元**。

## 看房时怎么核验：这一步决定你会不会被清退

**第一，人证是否一致。** 让房东出示身份证和不动产权证，核对权利人姓名、房屋坐落、建筑面积。名字对不上，问清他和产权人是什么关系，要求对应证明。**不要接受“房东在外地，我是他朋友”的口头说法。**

**第二，有没有抵押、查封。** 让房东当场登录当地不动产登记查询渠道，把结果给你看；或一起去登记中心查。抵押不等于不能租——《民法典》第四百零五条规定，抵押权设立前已经出租并转移占有的，原租赁关系不受抵押权影响；但**抵押设立在你的租赁之前**，抵押权实现时你的租赁可能对抗不了受让人。**已查封的房子不要租**，查封后签订的租赁通常不能对抗法院执行。

**第三，转租有没有授权。** 和二房东签约，必须看原租赁合同：真实、在有效期内、**允许转租**、剩余租期覆盖你的租期；再看大房东的转租同意书或授权委托书。缺一，你就是在赌二房东不跑路。

**第四，房子本身能不能住。** 《住房租赁条例》第七条明确：厨房、卫生间、阳台、过道、地下储藏室、车库等**非居住空间不得单独出租用于居住**；单间租住人数和人均最低租住面积要符合当地标准。重点查：隔断墙、独立窗户和通风、消防通道、燃气热水器位置、霉味和漏水、电路、水压、手机信号。

**第五，钱怎么算。** 物业费、取暖费、宽带费、保洁费谁付；水电气是民用价还是商用价；有无历史欠费；押金什么条件下扣、扣多少、多久退。**能写进合同的，不要只停在口头。**

**第六，留下证据，并换个时间再看一次。** 从进门开始拍：门牌、楼栋、房间全景、家电型号、已有损坏、水电燃气表读数，让房东在交接清单上签字。白天看采光，晚上看噪音、照明、小区安全；问一句物业或邻居：这套房是不是常换租客、房东好不好沟通、有没有纠纷。

## 定金、意向金、押金：三种钱不要混

| 名称 | 法律性质 | 能不能退 | 依据 |
|---|---|---|---|
| **定金** | 债权担保，**实际交付时成立** | 你违约不退；对方违约**双倍返还** | 《民法典》第五百八十六条、第五百八十七条 |
| **订金 / 意向金 / 诚意金** | 一般视为预付款或意向款，**没有定金罚则** | 原则上可退，除非合同明确约定为定金 | 司法实践；关键看合同怎么写 |
| **押金** | 履约担保 | 退租时按合同结算，无合同依据不得扣 | 《住房租赁条例》第十条 |

三句话记住：**写“定金”就按定金办**——你反悔钱没了，房东反悔退两倍；**写“意向金”不等于不能退**，但协议里常埋“签约时自动转为定金”，要求改成“未签约则全额无息退还”并写明时限；**收据写清**事由、金额、日期、收款人、退款条件，盖公司章，不要只留微信转账截图。定金和押金**不要打给中介个人**，条例第二十五条禁止经纪机构代收代付。

## 租赁备案：房东不办，你可以自己办

**法律依据。** 《住房租赁条例》第八条：出租人和承租人实名签订合同；出租人通过住房租赁管理服务平台等方式向房产管理部门备案；**备案不得收费**；**出租人未办理备案的，承租人可以办理**。通过经纪机构签约的，由经纪机构备案（第二十七条）。时限上，《商品房屋租赁管理办法》第十四条要求合同订立后 **30 日内**办理。

**材料。** 租赁合同、双方身份证明、房屋权属证明；线上通常只需上传照片。

**用途。** 居住证、积分落户、子女入学、公积金提取、租金补贴，很多城市都以备案合同为依据；上海等地明确，已备案的办理相关公共服务事项时可免于提交租赁合同。

**房东不配合。** 你自己办：带合同和身份证明去区房产管理部门窗口，或在住房租赁平台提交。被要求房东到场时，说明“出租人不备案，承租人依据《住房租赁条例》第八条自行备案”，必要时打 12345 协调。备案是法定义务，不是你替他放弃的权利。

## 办不成怎么办

### 情况 1：网上看中的房，到现场说“刚租掉”

典型**低价引流**。要求看同小区、同价位、真实在租的其他房源；记录原房源发布编号、截图、链接；向平台举报；平台不处理，打 12345 或 12315。**不要因为白跑一趟就签下更贵的房**，这正是对方想要的。

### 情况 2：中介先收“意向金 / 看房费 / 信息费”，或事后乱收、加价

正规居间，**带看本身不单独收费**，佣金在成交后按合同收。要求出示价目表和**收费清单**（建房规〔2023〕2 号第四条要求收费前出具、当事人签字）；价目表上没有的拒付；已付的要求退还并保留转账记录，不退打 12315。**未促成交易却收佣金，违反《房地产经纪管理办法》第十九条。** 拒不出具清单或拒绝开票的，同时向住建委投诉。

### 情况 3：签完才发现对方不是产权人

立即停止付款。要求出示产权证、产权人身份证、授权委托书；无法证明的，属于以欺诈手段订立的合同，可请求撤销（《民法典》第一百四十八条）并要求返还已付款项。涉及伪造证件、卷款失联的，直接报警。

### 情况 4：二房东跑路，大房东来收房

先别搬。拿出合同和付款记录，向大房东说明你是**次承租人**；依据《民法典》第七百一十九条，你可以**代二房东支付欠付的租金和违约金**，这笔钱可充抵你应付的租金，超出部分向二房东追偿。同时联合其他租客、报警、向住建部门投诉二房东未设资金监管账户。能和大房东直接重签合同，往往最省事。

### 情况 5：房东拒绝备案

你自己办，线上提交或去区房产管理部门窗口；被要求房东到场时，引用《住房租赁条例》第八条。仍不办的，打 12345 要求协调，并保留你已申请备案的记录。

### 情况 6：租到已抵押或已被查封的房子

**查封房**不要入住；已签合同的，主张解除并要求返还租金、押金、赔偿损失。**抵押房**看抵押登记时间和你实际占有房屋的时间：抵押设立在租赁之前，你的租赁可能对抗不了抵押权实现；抵押设立在租赁之后，依据《民法典》第四百零五条，原租赁关系不受影响。签约前查一次登记信息，比事后争论有用。

### 情况 7：被诱导办了“租金贷”

先确认三件事：贷款合同谁签的、钱打给了谁、上不上征信。依据住建部 2021 年意见，租金贷资金**只能划入借款人账户**，不得嵌入租赁合同，不得以租金优惠诱导。钱打给公司的，向金融监管部门投诉，同时向住建部门举报；涉嫌诈骗的报警。先固定证据再谈解除，不要为了“不影响征信”继续还款而不维权。

## 常见错误

1. **只看图片不看房，或只白天看一次。** 采光、噪音、漏水、邻居问题，晚上和雨天最明显。
2. **把“意向金”当“定金”，或没看清“自动转为定金”。** 交钱前只看两个字。
3. **不看产权证和身份证，和“房东的朋友”签约。** 谁有权收钱，只看登记，不看关系。
4. **和二房东签约，不看转租授权和原合同租期。** 原合同只剩三个月，你的“一年租约”随时作废。
5. **稀里糊涂签了租金贷。** “押一付一”“免押金”背后，可能是一份上征信的贷款合同。
6. **不做租赁备案。** 等到办居住证、孩子入学、提取公积金时才发现缺材料。
7. **相信口头承诺。** 免物业费、送宽带、可养宠物、到期可续租，统统写进合同或补充条款。
8. **不看水电燃气是民用价还是商用价。** 商水商电一个月可能多出几百元。

## 各地差异

| 事项 | 各地做法 | 来源 |
|---|---|---|
| 经纪机构佣金上限 | **全国**：无统一上限，由交易各方协商；政策引导双方共同承担 | 建房规〔2023〕2 号第三条 |
| 同上 | **北京**：佣金**一般不得超过一个月租金**；合同期满续订或重签的，**不得再次收取佣金** | 《北京市住房租赁条例》第四十六条 |
| 租赁企业收租与押金 | **全国**：单次收租原则上不超过 3 个月；单次收租超 3 个月或押金超 1 个月的，应纳入监管账户 | 建房规〔2021〕2 号第二条、第三条 |
| 同上 | **北京**：押金一般不超过一个月并第三方托管；单次收租一般不超过三个月，超收部分纳入监管 | 《北京市住房租赁条例》第三十六条 |
| 同上 | **上海**：一次性收取租金超过三个月的部分、押金超过一个月租金的部分，应存入资金监管专用账户 | 《上海市住房租赁条例》第二十九条 |
| 个人二房东监管 | **全国**：转租住房 10 套（间）以上的自然人应办理市场主体登记 | 建房规〔2021〕2 号第一条 |
| 同上 | **北京**：个人转租 10 套（间）及以上纳入行业监管 | 新华网 2025-11-19 |
| 合同备案主体 | **全国**：出租人办理；未办理的，承租人可以办理；备案免费 | 《住房租赁条例》第八条 |
| 备案时限 | **全国**：合同订立后 30 日内 | 《商品房屋租赁管理办法》第十四条 |
| 备案与网签 | **上海**：通过住房租赁平台完成网上签约的，**无需另行办理登记备案** | 《上海市住房租赁条例》第三十九条 |

> 📌 这一节是**证据收集**，不是完整对照表。你所在城市的佣金上限、备案入口、监管银行名单，以当地住建部门最新公示为准。

## 信息核实方式

1. **当地住建委（房管局）官网 + 住房租赁管理服务平台** —— 查备案名单、房源核验码、资金监管账户、投诉入口，这是最权威的地方口径。
2. **国家企业信用信息公示系统** https://www.gsxt.gov.cn —— 查中介、长租公寓、二房东公司的营业执照、经营范围、经营异常、行政处罚。
3. **中国执行信息公开网** http://zxgk.court.gov.cn —— 查房东或二房东是不是被执行人、有没有失信记录。
4. **当地不动产登记中心 / 政务 APP** —— 查抵押、查封、共有情况。承租人作为利害关系人能否查、需要什么材料，各地口径不同，先打电话问。
5. **国家法律法规数据库** https://flk.npc.gov.cn 和 **中国政府网** https://www.gov.cn —— 核对《住房租赁条例》《民法典》原文，确认某条规定是否已修改。
6. **`12345` / `12315` / `12348`** —— 不知道找哪个部门打 12345；乱收费、虚假宣传、不开发票打 12315；涉及金额较大或已产生纠纷打 12348 问管辖和证据要求。

## 行动清单

**看房前**

- [ ] 算清首付：押金 + 首期租金 + 中介费 + 搬家 + 宽带
- [ ] 选定渠道，明确能接受的最高佣金

**看房时**

- [ ] 核对不动产权证、房东身份证，名字和坐落一致
- [ ] 查抵押、查封、共有情况
- [ ] 二房东场景：看原租赁合同、转租条款、授权书、剩余租期
- [ ] 检查非居住空间、隔断、消防、燃气、漏水、水压、电路
- [ ] 问清物业费、取暖费、宽带费、水电气单价、历史欠费
- [ ] 拍照录像，记录水电燃气读数，列交接清单

**签约前**

- [ ] 确认交的是“定金”还是“意向金”，退款条件写清楚
- [ ] 确认佣金金额、承担方、支付时间、是否开票
- [ ] 拒绝租金贷；拒绝把租金、押金交给中介代收代付
- [ ] 所有口头承诺写进合同或补充条款

**签约后**

- [ ] 30 日内办租赁备案；房东不办就自己办
- [ ] 保留合同、收据、收费清单、转账记录
- [ ] 入住 7 日内检查家电、漏水、异味，有问题书面通知房东
