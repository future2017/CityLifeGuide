# 信息时效性与核实方法

> ⏱ 本文信息采集于 **2026-09**。这一篇讲的是核实方法，本身不涉及会变的政策。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 办事类信息一定会过期，区别只在于多久；所以每条都标了采集日期 |
| **一条信息可信到什么程度** | 看它的日期和来源，两者缺一不可 |
| **最容易过期的三类** | 价格与比例、经办流程与材料清单、地方细则 |
| **动手前怎么核** | 用条目末尾的「信息核实方式」，花两分钟查官方原文 |
| **最大的坑** | 拿二手解读当依据——转载页、问答页、政策解读常常比原文旧一步 |

## 一句话结论

**在办事这件事上，「什么时候查的」和「从哪查的」比「说了什么」更容易出事。**

同一个问题，两年前的正确答案今天可能是错的：法规会修订，条号会变，文件会被新文件取代，办事材料会简化，收费标准会调整。本指南能做的是把**采集日期和来源**摊开给你看，让你自己判断它还值不值得信。

> 一条没有日期的政策信息，等于没有信息。

---

## 每条都有「采集日期」和「复核期限」

每个条目的 front-matter 里有两个字段，正文顶部也会重复一次：

| 字段 | 含义 |
|---|---|
| `collected` | **采集日期**——这一条的内容是这时候查的 |
| `review_by` | **复核期限**——到了这个时间，这一条应当被重新核一遍 |

这不是装饰。政策类内容没有采集日期，读者无法判断可信度，作者也无法知道该从哪里开始更新。

**如果某一条的 `review_by` 已经过去很久，而你还看到它在网上流传——请以官方口径为准。**

## 最会过期的是哪三类信息

按过期速度排序，你最容易踩到的三类：

| 类型 | 典型表现 | 多久会变 |
|---|---|---|
| **价格、比例、标准** | 报销比例、缴费基数上下限、补贴金额、收费标准 | 每年调整（多数随年度通知） |
| **经办流程与材料清单** | 需要带什么、要不要预约、能不能网办 | 随「放管服」改革缩短、简化 |
| **地方细则** | 落户门槛、限购条件、入学要求 | 说改就改，且常常只有本地发布 |

反过来，**法律条文本身**相对稳定——但要注意三点：有没有被修订、条号有没有变、有没有被新的司法解释或实施细则改变适用方式。

## 一个真实的例子：条号会「存活」但内容会变

修订过一次的法律，条文可能整体重编号。原来你记的「第三十三条」在新版本里可能是「第三十四条」，也可能整条被吸收进另一条。

更隐蔽的一种：旧条文没被删，但已经被**新的司法解释**改变了适用方式。这时候引用旧条文本身没错，照旧文条办事却会出错。

所以核实不是「查到就行」，而是**查到「现在这一版」**。

## 动手前怎么核实

按下面顺序查，一般两分钟以内能定位：

1. **先查法律。** 国家法律法规数据库（`flk.npc.gov.cn`）里有现行有效的法律、行政法规、地方性法规和司法解释原文，能直接看到「是否已被修订」。
2. **再查政策文件。** 到中国政府网的政策文件库，或用发文机关官网的文件栏目——**优先看发文机关的发布页，而不是转载页**。
3. **最后查本地口径。** 本地政务服务网或主管部门官网的办事指南，是窗口实际执行的依据。
4. **打电话兜底。** 12345 政务服务便民热线对本地窗口口径最清楚；人社、医保、税务各有专业热线（见附录 A）。

## 本指南的来源规则

为了让你核得动，我们给自己定了三条硬规则，写进每一条里：

| 规则 | 具体做法 |
|---|---|
| **政策与数字必须有官方来源** | 只引官方域名：`gov.cn`、`npc.gov.cn`、各部委官网、省市人民政府及主管部门官网 |
| **查不到就直说** | 确实检索不到官方原文页的，写「以当地规定为准」并说明查不到，**不编来源、不拿聚合站凑数** |
| **二手来源必须标注** | 只能找到媒体转载、找不到官方发布页的，保留链接但**明确标注「媒体来源，官网未检得原始页面」** |

第三条尤其重要：有些文件年代久远（例如 2009 年前后的部委规范性文件），主管部门官网从未上网公开。这种情况下装作有官方来源，比承认查不到危害大得多。

## 首版做过一次全量时效复核

2026-09，本指南在首版定稿前对全部条目的引用做了一轮逐条复核，标准是三个问题：

1. 这份文件**现在还有效吗**？（有没有被废止、被新文件取代、被修订）
2. 我引的**条号在这一版里还成立吗**？（有没有重编号、被吸收、被废止）
3. 我给的**链接指向的是官方原文、还是解读页/转载页**？

这一轮里发现并修正了若干真实问题，其中几类值得你知道：

- **引了已废止的文件**——例如某市医保办法已被新的市政府令整体取代，条号体系全部重编；
- **引了过期的年度文件**——年度性通知逐年发布，拿 2019 年的通知当现行标准是错的；
- **引了「对的文件」的二手页面**——转载页、政策解读页、答记者问、办税指南，域名可能还是官方的，但**不是原文**；
- **读起来像常识、却找不到出处的事实**——这类最危险，已经删除。

复核结果按章登记在附录 D，你可以看到每一部分的采集日期与复核情况。

## 信息核实方式

| 你想核什么 | 去哪核 |
|---|---|
| 法律、行政法规、司法解释原文与效力状态 | 国家法律法规数据库 `flk.npc.gov.cn` |
| 国务院及各部门政策文件 | 中国政府网 `gov.cn` → 政策文件库 |
| 人社 / 医保 / 卫健 / 税务专业政策 | 对应部委官网 |
| 本地办事指南与细则 | 本地政务服务网及主管部门官网 |
| 窗口临时口径 | 12345 或专业热线（见附录 A） |

> **本文不能作为最终依据。** 发现本文与官方现行口径不符时，请以官方为准，并告诉我们更正。
