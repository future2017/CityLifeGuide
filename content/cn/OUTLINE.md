# 国内版 · 大纲与目录

> 版本 v0.3 · 2026-09-29
> 读者定位：在中国境内城市生活的人（本地居民、跨省迁移者、初入社会的年轻人）

---

## 一、组织逻辑（为什么这样排）

**双入口结构**，这是本指南与普通攻略的根本区别：

| 入口 | 用途 | 位置 |
|---|---|---|
| **按领域**（主轴） | 已经知道要办什么事，来查具体怎么办 | 正文章节 |
| **按场景**（附录 C） | 知道自己遇到了麻烦，但不知道该办什么 | 附录 C 场景索引 |

只有领域分类，新手会不知道从哪一节开始看；只有场景分类，具体事务又检索不到。两条路都要有。

**每个条目的信息密度标准**：不写「什么是社保」，只写「你要带什么、去哪办、多久、多少钱、办不成怎么办」。

## 二、条文模板（所有条目统一使用）

```markdown
---
title: 异地就医备案
part: 4 · 医疗
section: "4.4"
scope: 全国（各地细则见正文）
applies_to: [职工医保参保人, 居民医保参保人]
collected: 2026-09
review_by: 2027-03
sources:
  - 来源名称 + 链接
---

## ⚡ 30 秒速览   ← **首个 H2，置顶**

| | |
|---|---|
| **结论** | 一句话讲清该不该做、什么时候做 |
| **要带什么** | 材料清单；并注明哪些其实不需要 |
| **去哪办 / 找谁** | 线上渠道 + 线下窗口 + 电话 |
| **多久 / 多少钱** | 时效与费用；免费项与真正的成本分开写 |
| **最大的坑** | 最容易被忽略、代价最大的那一个点 |

## 一句话结论

## 适用情形        ← 你属于哪一类，以及分类带来的待遇差异

## 需要准备什么     ← 逐项写明原件/复印件/电子版，并注明哪些其实不需要

## 去哪里办        ← 线上渠道 + 线下网点 + 办事话术

## 多久办完

## 费用            ← 免费项与真正的成本分开写

## 办不成怎么办     ← 按发生顺序排列的失败场景 + 对应处理

## 常见错误

## 各地差异        ← 一行一个地区的取证表（格式见下），与第 12 部分的接口

## 信息核实方式     ← 官方查询入口，本文不能作为最终依据

## 行动清单
```

**置顶速览块的硬性要求**：每个条目的**第一个 H2 必须是「## ⚡ 30 秒速览」**，用五行表格给出可操作结论，让读者不读完全文也能办事。单元格 ≤60 字、**内不能有换行**；某一行的标签不适用时，换成对该条目更有用的一行（如「先做什么」），留空不如换行。**速览块只能复述正文已有的内容，不得引入正文未出现的事实、数字或来源。**

### 「各地差异」小节的格式标准（2026-09-29 定）

这一节在 v1 的定位是**证据收集**，不是成品对照表——攒的是「同一件事、各地到底怎么办」的原始样本，用来支撑后续的架构决策（做「通用版＋城市差异」，还是逐城单独做）。所以它必须**可机械聚合**：

| 规则 | 说明 |
|---|---|
| **表头固定三列** | `事项 \| 各地做法 \| 来源`。第三列必须是来源，不得换成「性质」「说明」「查哪里」 |
| **一行只放一个地区** | 做法单元格以 `**地区名**：` 开头。**禁止把多个地区挤进同一格**（`**北京**：…；**深圳**：…`），否则无法按城市聚合 |
| **同一事项的续行写「同上」** | 事项列从第二行起写 `同上`，聚合脚本按前向填充处理 |
| **每行自带来源** | 能定位到条款的写文号或条号。整表共用一个来源，等于没有来源 |
| **地区名写规范全称** | 「北京」「上海」「广东省」；同城不同层级必须写全——**北京朝阳区 ≠ 辽宁朝阳市** |
| **非一线/新一线地区可以出现** | 但该行要注明它代表什么：全国唯一样本 / 口径分歧的证据 / 省级统一口径。**城市名单本身不设限**，覆盖范围留到样本量足够后由架构决策统一收敛 |

**允许的第二类表：差异点清单。** 当一件事**全国没有统一规定、也找不到任何具体地区的做法可引**（例如「值班报酬全国无法律规定」），可以退化成两列 `事项 \| 现状`；但**必须在表前一句话说明这是「无地方样本可引」的差异点，不是各地做法对照**。两类表不能共用一个不说明的表头。

**取材范围不设限，但范围限制的适用范围要说清：** 第 12 部分「城市差异」（v1 一线 + 新一线，19 城）的覆盖范围**只约束第 12 部分本身**，既不约束各条目的「各地差异」小节，也不约束来源引用——一条全国性规则常常只有某个地市级官网有公开解释页，那类页面照引不误。

`collected` / `review_by` 两个字段是**硬性要求** —— 政策类内容没有采集日期就没有可信度。
`各地差异` 一节是**硬性要求** —— 凡涉及地方细则的条目，必须把「各地不一样」这件事写出来。

- **目录**：`NN-<英文部分名>`，`NN` 与章节号对应。内容到位时再建目录，不预先铺空目录。
- **文件**：小写英文 + 连字符，如 `cross-province-medical-filing.md`。
- **一个主题一个文件**，不把多个主题塞进同一文件。

**「新一线」的界定依据**：以第一财经·新一线城市研究所每年发布的《新一线城市魅力排行榜》为准（一线 4 城 + 新一线 15 城）。榜单每年更新，本章城市名单随之调整。

截至《2025 新一线城市魅力排行榜》（2025-05-28 发布）：

| 分级 | 城市 |
|---|---|
| 一线（4） | 上海、北京、深圳、广州 |
| 新一线（15） | 成都、杭州、重庆、武汉、苏州、西安、南京、长沙、郑州、天津、合肥、青岛、东莞、宁波、佛山 |

> ⚠️ 本章城市范围**必须标注所依据榜单的年份**。写作前先核实是否已有更新年份的榜单。
> 来源：新一线城市研究所 / 第一财经 https://www.yicai.com/

**本章要回答的问题**：「同一件事，各城怎么办」。具体差异集中在——

- 落户门槛与方式（学历落户 / 积分落户 / 投靠）
- 购房资格与限购细则
- 社保与公积金的城市细则（缴纳基数、提取规则、异地互认）
- 车牌获取方式（摇号 / 竞价 / 排队）
- 随迁子女入学条件
- 居住证积分规则
- 医保报销比例与门诊统筹标准

**工作方式**：不做成「各城一篇」，而是**在一个主题下横向铺开各城做法**（见 4.4 节「各地差异」的格式）。这样才能真正回答「同一件事、各城怎么办」。

## 六、体例约定

| 项目 | 约定 |
|---|---|
| 文件命名 | `主题.md`，小写英文，连字符分隔；一个主题一个文件 |
| 语言 | 简体中文 |
| 人称 | 第二人称「你」，不用「您」（降低距离感，与实用指南定位一致） |
| 政策引用 | 必须附官方来源链接与采集日期 |
| 数据 | 价格、时限、比例等数字必须标注来源与日期 |
| 数字举例 | 给具体算例（如「8 万元住院费，备案与不备案差 8000 元」），不写空泛结论 |
| 不确定表述 | 用「多数地区」「实践中」「以当地规定为准」，不用绝对化断言 |
| 办不成怎么办 | 每个涉及审批的条目必须有此节，按失败场景排列 |
| 30 秒速览 | 每个条目的首个 H2；五行表格，只复述正文内容 |
| 图片 | 优先自制示意图；禁止使用地图服务截图 |
