# 国内版

面向**在中国境内城市生活**的读者。

## 定位

解决「具体怎么办」的问题 —— 不是风景介绍，而是办事指引。

## 拟覆盖方向

- 居住与租房（找房渠道、合同要点、押金纠纷处理）
- 政务办事（居住证、社保医保、公积金、出入境）
- 就医（分级诊疗、挂号渠道、异地就医备案）
- 交通出行（地铁公交、打车、长途、驾照相关）
- 消费与维权（退换货、投诉渠道、常见坑）
- 生活服务（快递、外卖、家政、维修）
- **城市差异（必备章节）** —— 属于**第 12 部分本身**的范围：v1 覆盖一线 + 新一线，
  逐城横向对照同一事务的不同办法；界定依据为第一财经·新一线城市研究所年度《新一
  线城市魅力排行榜》，城市名单随榜单年份更新
- **各条目里的「各地差异」小节** —— 定位是**证据收集**，不是成品对照表：格式固定
  为「一行一个地区 + 每行自带来源」，用来积累可机械聚合的样本，好为「做通用版＋
  城市差异，还是逐城单独做」这个架构决策提供依据。所以它**不设城市范围限制**——
  一线 / 新一线 / 其他地区的官方口径都可以收，只要求标注该样本代表什么。格式细则
  见 [OUTLINE.md](OUTLINE.md) 第二节

## 读者定位

在中国境内城市生活的人：本地居民、跨省迁移者、初入社会的年轻人。写作前提是读者
**不知道去哪问、不知道该带什么**，而不是缺少背景知识。

## 写作约定

- 每个主题开头标注 **信息采集日期** 与 **适用城市范围**
- 政策类内容必须给出官方来源链接
- 办事流程按「材料 → 渠道 → 时限 → 费用」四要素写
- 面向第一次接触该事务的读者，不预设背景知识

## 文件命名

```
内容主题-城市或范围.md
例：renting-deposit-dispute-beijing.md
    social-security-transfer.md
```
