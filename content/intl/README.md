# International Edition

For readers living in, relocating to, or traveling through cities **outside mainland China** — written primarily for a Chinese-speaking audience going abroad, and for English-speaking readers new to a city.

## Scope

Practical, procedure-first guides. Not travel brochures.

## Planned sections

- **Before you arrive** — visas, documents, banking, SIM/eSIM, insurance
- **Housing** — finding a place, lease terms, deposits, common scams, tenant rights
- **Money** — opening accounts, transfers, cards, tax basics, tipping norms
- **Getting around** — transit cards, ride-hailing, driving licences, intercity
- **Healthcare** — registration, insurance, pharmacies, emergency numbers
- **Daily admin** — registering with local authorities, utilities, mail, phone contracts
- **Getting help** — police, legal aid, embassy/consulate, consumer complaint routes
- **Culture notes** — the small unwritten rules that cause most friction

## Editorial conventions

- **State the country and city** in every document; rules are national, practice is local
- Mark every document with a **data-collected date** — this domain changes fast
- Give **official sources** (government portals, not blogs) for anything regulatory
- Note where the answer differs for **residents vs. visitors vs. students vs. workers**
- Write for a reader with **no local language ability** — include what you can actually say/show
- Follow the same structure per document: *What you need → Where → How long → Cost → What can go wrong*

## File naming

```
<topic>-<country-or-city>.md
e.g. open-bank-account-germany.md
     rental-deposit-rights-uk.md
```

## Language

Primary English. Where a term matters in the local language, give both.
