# 医保结算流程与自费部分

> ⏱ 本文信息采集于 **2026-09**。政策调整频繁，动手前请用文末的「信息核实方式」确认一次。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 医保不是「花多少报多少」：先在三大目录里筛一遍、扣起付线、按比例报、最后撞封顶线 |
| **要带什么** | 医保电子凭证或社保卡（**身份证不能用于结算**）；出院留好医疗收费票据、费用清单/结算单、出院记录 |
| **去哪办 / 找谁** | 门诊挂号处、住院收费处当场结算；对账找医院**医保办**（不是收费窗口），投诉打 `区号+12393` |
| **多久 / 多少钱** | 挂号缴费、出院都是**即时结算**，不用先垫全款；自己只掏个人自付 + 个人自费两笔 |
| **最大的坑** | 分不清**个人自付**与**个人自费**：自付在目录内、可用个人账户付；自费在目录外、医保一分不报，只能掏现金 |

## 一句话结论

**医保不是"花多少报多少"，而是先在三大目录里筛一遍、再扣起付线、再按比例报、最后撞封顶线。**
所以同一个病、同一笔费用，最后你能报多少，取决于四件事：**用了多少目录外的项目、你参保地的起付线、报销比例、封顶线**。

**普通人最容易踩的坑是分不清"个人自付"和"个人自费"**：前者是目录内该你承担的部分（可以用个人账户的钱付），后者是完全不在目录内、医保一分不报、个人账户也**不能**用来付。看懂结算单上这两个词，你才知道钱花在哪。

## 基本概念（三大目录与起付线封顶线）

### 三大目录：医保只对"目录内"负责

我国基本医疗保险的报销范围实行**目录管理**。目录内的费用，由医保基金和个人按比例分担；**目录外的费用，医保基金一律不予支付**。这三份目录合称医保"三目录"（[黑龙江省医保局转载，来源为福建省医保局](https://ybj.hlj.gov.cn/ybj/ybrd/202410/c00_31778157.shtml)）：

| 目录 | 管什么 | 谁定 |
|---|---|---|
| **药品目录** | 西药、中成药、协议期内谈判药品、中药饮片 | 国家统一制定、动态调整，**原则上每年调整一次**；省级可按规定将民族药、医疗机构制剂、中药饮片纳入本地支付范围 |
| **诊疗项目目录**（医疗服务项目） | 挂号、检查、检验、手术、治疗等医疗服务项目 | 国家定准入和管理政策，**原则上由省级医保部门确定** |
| **医用耗材目录** | 一次性医用材料、心脏支架、人工关节、起搏器等 | 国家定政策（医保发〔2023〕23号），**省级制定本省耗材目录** |

> 💡 三目录的**甲乙类**是"甲乙分类"，不是"医院等级"。

**药品的甲类 / 乙类 / 目录外**（《基本医疗保险用药管理暂行办法》第二十四、二十五条）：

| 类别 | 含义 | 你要承担什么 |
|---|---|---|
| **甲类药品** | 临床治疗必需、使用广泛、疗效确切、同类中价格较低的药品 | 直接按参保地报销比例结算，**没有先行自付** |
| **乙类药品** | 可供临床选择使用、疗效确切、同类中比甲类价格略高的药品。**协议期内谈判药品纳入乙类管理** | 按支付标准**先由个人自付一定比例**（这个比例由省级或统筹地区确定），余额再按比例报销 |
| **目录外药品** | 不在药品目录内（滋补类、保健药品、预防性疫苗、主要起美容减肥增强性功能等作用的药品按办法第八条不纳入） | **全自费，医保不报** |

**诊疗项目**的表述各地不同——国家层面对诊疗项目采用"**排除法**"：分为"不予支付费用的诊疗项目"和"支付部分费用的诊疗项目"两种清单；部分统筹地区在本地目录里直接写成"甲类项目 / 乙类项目"，含义一样：一种全额纳入、一种要个人先自付一定比例（[劳社部发〔1999〕22号](https://rsj.sh.gov.cn/trlzyhshbzbgz_17256/20200617/t0035_1388359.html)）。

**明确不报的典型项目**（劳社部发〔1999〕22号附件，全国口径，各省只能增补不能删减）：

- 挂号费、院外会诊费、病历工本费、出诊费、检查治疗加急费、点名手术附加费、自请特别护士等特需医疗服务
- 美容、健美、非功能性整容、矫形、减肥增胖增高、健康体检、预防保健性诊疗
- 就（转）诊交通费、急救车费、空调费、电视费、电话费、陪护费、护工费、洗理费、门诊煎药费、膳食费、文娱活动费
- **超标准床位费**：实际床位费高于当地医保住院床位费支付标准的，**超出部分由个人自付**

**医保基金整体不予支付的六类情形**（《社会保险法》与医保待遇清单制度口径）：应当从工伤保险基金支付的、应由第三人负担的、应由公共卫生负担的、在境外就医的、体育健身/养生保健/健康体检、国家规定的其他情形。

### 起付线 / 报销比例 / 封顶线：三个闸门

这三者**串联**工作，不是各算各的（东城区医保局对起付线的定义：*参保人员在享受医疗费用报销之前需要自己先行支付的费用额度*）：

```
医疗总费用
  ├─ 目录外部分 ──────────────────────────→ 全自费（医保 0 报销）
  └─ 目录内部分（政策范围内费用）
        ├─ 乙类先行自付部分 ──────────────→ 个人自付
        └─ 剩余部分
              ├─ 起付线以内 ──────────────→ 个人自付
              └─ 起付线以上
                    ├─ 按比例报销 ────────→ 医保统筹支付
                    ├─ 按比例自付 ────────→ 个人自付
                    └─ 超过封顶线部分 ────→ 个人自付
```

1. **起付线**（起付标准）：线以下全自付。**门诊和住院按年度分别设置、单独累计**。
2. **报销比例**：起付线以上的目录内费用，按比例由统筹基金支付。比例与**医院级别、参保类型、在职/退休、费用分段**都有关。
3. **封顶线**（最高支付限额）：一个年度内统筹基金**最多**给你报多少，超过的部分医保不管（可走大病保险、补充医疗等第二重保障）。

> ⚠️ **比例和起付线没有全国统一数字**，由**参保地**决定，各省、甚至同省不同市都不同。下面所有具体数字都只是**有官方来源的地区示例**，不要照搬到你自己身上。

**示例 A：北京市**（[北京市医保局待遇表](https://ybj.beijing.gov.cn/2020_zwfw/2020_bmcx/202004/t20200409_1798870.html)、[东城区医保局](https://www.bjdch.gov.cn/zwgk/jgdh/qzfzcbmdh/qybj/bmgzybj/202401/t20240122_3542305.html)）

- 职工门诊：起付线在职 **1800 元**、退休 1300 元；2 万元以下 医院 **70%**、社区 **90%**；2 万元以上在职 **60%**、退休 **80%**，2023-01-01 起门诊**不再设封顶线**
- 职工住院：起付线本年度第一次 **1300 元**、第二次及以后每次 **650 元**；报销比例按费用分段和医院级别在 **85%–99.1%**；住院**封顶线 50 万元**
- 居民医保：门诊起付线 100 元（一级）/550 元（二级），报销 55%/50%，**门诊封顶线 5000 元**；住院起付线 300/800/1300 元，报销 80%/70%/75%–78%，**住院封顶线 25 万元**

**示例 B：武汉市**（[武汉市医保局明白卡](https://ybj.wuhan.gov.cn/zwgk_52/zcfgyjd/zcwd/202404/t20240418_2390457.shtml)）

- 职工门诊统筹起付线 **0 元**，一级机构在职 **85%**、二级 65%、三级 55%；**年度最高支付限额在职 3500 元、退休 4500 元**
- 职工住院起付线：三级 **800 元**、二级 600 元、一级 400 元、社区卫生服务中心 200 元；同一年度内第二次及以上住院**起付线减半**（社区卫生服务中心除外）
- 住院报销比例（在职）：三级 86%、二级 89%、一级及以下 92%；**年度限额 24 万元（含统筹基金支付和个人自付）**
- 使用乙类药品/乙类诊疗项目的，**个人先支付 10%**

## 门诊怎么结算

### 普通门诊统筹

门诊共济改革后，普通门诊费用由**统筹基金**报销，不再只靠自己个人账户的钱。国家层面的底线要求是：**普通门诊统筹覆盖职工医保全体参保人员，政策范围内支付比例从 50% 起步**，待遇可向退休人员倾斜，起付标准和最高支付限额由各地科学测算（[国办发〔2021〕14号](https://www.nhsa.gov.cn/art/2021/4/22/art_37_4921.html)）。居民医保同步建立门诊统筹。

三个需要你自己确认的点：

1. **起付线与年度限额**：各地差别巨大。武汉职工门诊起付 **0 元**、年限额在职 3500 元；北京职工门诊起付 1800 元、但上不封顶。
2. **要不要选定点**：**职工医保普通门诊**在统筹区内定点医疗机构一般直接刷卡即可，通常不需要提前选定点；**居民医保门诊统筹**在很多地方是"**单定点**"管理——必须选一家社区卫生服务机构或乡镇卫生院作为门诊统筹定点，在别处看普通门诊可能不报或报得少。例：济南市明确居民门统定点"实行'单定点'管理，即参保人选择一家基本医疗保险定点社区卫生服务机构或乡镇卫生院"，且每年 1 月才能变更（[济南市医保局](https://ybj.jinan.gov.cn/col80598/art/2025/art_80598_4775674.html)）。
3. **药店能不能报**：国办发〔2021〕14号要求"将符合条件的定点零售药店提供的用药保障服务纳入门诊保障范围，支持外配处方在定点零售药店结算和配药"。武汉明确定点零售药店的门诊统筹报销比例按**一级医疗机构**执行。是否开通、报多少，仍看参保地。

### 门诊结算动作：三句话

1. **挂号时**就说"我有医保"，用**医保电子凭证或社保卡**挂号，不要用身份证或自费卡挂号——自费挂号后这笔费用很可能整单变成自费。
2. **医生开药/开检查时**主动问一句："这些在医保目录内吗？是甲类还是乙类？有没有目录外的？" 医生一般能答，也可以自己查（见「信息核实方式」）。
3. **缴费时**出示医保电子凭证/社保卡，系统**即时结算**，你只付个人应付的部分（个人自付 + 个人自费）。发票和费用清单上会分开列这三行。

## 住院怎么结算

### 出院即时结算的标准流程

住院是**出院时一次性结算**，不需要你先垫全款再报销（这是"直接结算"的含义）：

1. **入院登记**：办理住院时出示**医保电子凭证或社保卡**登记医保身份。没登记，整次住院可能被记为自费。
2. **住院期间**：医院会给出**每日费用清单**。逐日看，看到疑似自费项目（进口耗材、自费药、特需服务）当场问护士站或医保办。**这时候改还来得及，出院后再改很麻烦。**
3. **出院结算**：到住院收费处（现在很多医院已支持病区内"一站式"结算）办理。系统自动完成：目录筛选 → 扣起付线 → 按比例计算 → 比对封顶线，只收你个人应付部分。
4. **拿凭证**：**医疗收费票据**（发票）+ **住院费用清单/医保结算单** + **出院记录/诊断证明**。这三样留好，商业保险、单位二次报销、异地手工报销都要用。

### 结算单上你要看的四行

| 结算单上的词 | 含义 |
|---|---|
| **医疗费总额** | 这次住院一共花了多少 |
| **医保统筹基金支付** | 医保**实际替你付**的钱（这才是真正的"报销额"） |
| **个人自付** | 目录内、但按规则由你承担的部分 |
| **个人自费** | 目录外、你全额承担的部分 |

**校验公式：医疗费总额 = 统筹基金支付 + 个人自付 + 个人自费。** 对不上就是有问题，当场要求医院医保办解释。

### 三个必须知道的机制

- **乙类先行自付**是单独一笔，先扣再加比例。武汉：乙类药品和乙类诊疗项目**个人先支付 10%**，余额再走正常比例。
- **起付线按次、按年度**。北京职工本年度第一次住院 1300 元，第二次及以后每次 650 元。武汉同一年度内两次以上住院**起付线减半**。
- **封顶线可能包含个人自付**。武汉职工住院"年度限额 24 万元（含统筹基金支付和个人自付）"——注意这个口径，它不是你实际能报 24 万。

### 算例：一笔 5 万元住院费逐项拆解

**设定**（说明：起付线和比例取自武汉市职工医保在职人员的官方口径；目录外金额和乙类金额是**为了演示而假设**的数字，真实数值必须看你自己的费用清单）：

- 参保人：武汉市职工医保，**在职**
- 就医：**三级医院**住院，本年度**第一次**住院
- 起付线：**800 元**（武汉三级医院）
- 报销比例：**86%**（武汉在职职工三级医院）
- 乙类先行自付比例：**10%**（武汉规定）
- 未触及年度限额 24 万元，且本例不考虑大病保险等第二重保障

| 项目 | 金额 | 说明 |
|---|---|---|
| **A. 医疗费总额** | **50,000 元** | 医院开的账 |
| **B. 目录外费用** | **6,000 元** | 进口耗材、目录外自费药、超标准床位费、特需服务等 |
| **C. 目录内费用（政策范围内）** | **44,000 元** | A − B |
| **D. 其中属于乙类的部分** | **20,000 元** | 乙类药品 + 乙类诊疗项目 |
| **E. 乙类先行自付 = D × 10%** | **2,000 元** | ① 个人自付 |
| **F. 进入统筹计算的费用 = C − E** | **42,000 元** | |
| **G. 起付线** | **800 元** | ② 个人自付 |
| **H. 可报销基数 = F − G** | **41,200 元** | 起付线以上、封顶线以下 |
| **I. 医保统筹基金支付 = H × 86%** | **35,432 元** | 医保真金白银替你付的 |
| **J. 按比例自付 = H × 14%** | **5,768 元** | ③ 个人自付 |
| **K. 个人自付合计 = E+G+J** | **8,568 元** | 目录内你承担的部分 |
| **L. 个人自费 = B** | **6,000 元** | 目录外，一分不报 |
| **M. 你实际要掏的钱 = K+L** | **14,568 元** | |

**校验**：35,432 + 8,568 + 6,000 = 50,000 ✅

**两个不同口径的"报销比例"，别搞混**：

- **按总额算**：35,432 ÷ 50,000 = **70.9%** —— 这是你体感上的"报了多少"
- **按政策范围内费用算**：35,432 ÷ 44,000 = **80.5%** —— 这是医保局宣传里常说的报销比例

差额来自那 6,000 元目录外费用。**同样的 5 万元，如果目录外费用变成 15,000 元，你实际要掏的钱会明显增加——这就是为什么住院期间盯费用清单有意义。**

## 个人自付与个人自费的区别

**这是全文最重要的一节。** 两个词只差一个字，含义和钱的出路完全不同。

| | **个人自付** | **个人自费** |
|---|---|---|
| **在不在医保目录内** | **在**（目录范围内） | **不在**（目录范围外） |
| **医保管不管** | 管，是按规则算给你的份额 | 完全不管，医保基金**不予支付** |
| **具体包括什么** | 起付线以下、乙类先行自付、按比例自付、封顶线以上、目录范围内超限价部分 | 目录外药品、目录外诊疗项目、目录外耗材、非疾病治疗项目、特需服务等 |
| **能不能用医保个人账户的钱付** | **可以**，个人账户余额不足再用现金等补 | **不可以**，只能自掏现金/微信/支付宝等 |
| **对报销的提示** | 免不了，属于制度设计 | **这是一个信号：你能少用就少用** |

权威来源的口径几乎完全一致：

- **深圳市医保局**：个人自付指"在医保目录范围内，按规定需要由参保人个人负担的医疗费金额。（包括起付线以下、乙类先行自付、按比例自付、封顶线以上、目录范围内超限价部分等，这部分费用可由医保个人账户内的余额进行支付，不够的部分再用现金等方式支付。）"；个人自费指"在医保目录范围外的药品、诊疗项目等，由参保人员全额支付"（[来源](https://hsa.sz.gov.cn/gkmlpt/content/11/11952/post_11952753.html)）
- **黑龙江省医保局**："个人自付款可先由医保个人账户内的余额进行支付，不够的部分再用现金等方式支付"；"个人自费指在医保范围外的药品、项目等，由参保人员全额支付，**不能使用医保卡个人账户的资金支付**"（[来源](https://ybj.hlj.gov.cn/ybj/ybrd/202408/c00_31758259.shtml)）
- **福建省（省医保局口径）**："个人自付：参保人发生的属于基本医疗保险目录范围内的医疗费用，扣除基本医疗保险、补充医疗保险和医疗救助等报销后由个人支付的部分"（[来源](http://www.fujian.gov.cn/hdjl/hdjlzsk/sybj/dybz/202301/t20230109_6088720.htm)）

### 记住这三条

1. **记忆口诀：自付=目录内、医保帮忙算过账；自费=目录外、医保一分不出。**
2. **唯一可以用个人账户余额支付的是"个人自付"**，不是"个人自费"。药店刷医保卡买目录外的东西，本质是用个人账户买"目录内可支付范围"的商品，与"个人自费"是两回事——别把两者混着理解。
3. **看到"自费"就多问一句**："这个必须自费吗？有没有目录内的替代？" 尤其是进口耗材、进口原研药、高价自费药，问过之后往往有替代方案。

## 门诊慢特病

### 和普通门诊的区别

国家医保局官方解读：普通门诊一般保障"小病"；门诊慢特病是为"部分医疗费用负担高、诊断明确、适合在门诊治疗的疾病"设的保障，**一般具有较普通门诊更高的报销比例和更高的封顶额度**，医疗机构可开具长期处方（福建最长可达 3 个月）（[国家医保局](https://www.nhsa.gov.cn/art/2025/7/19/art_14_17329.html)）。

常见病种举例（**各地不同，以参保地目录为准**）：糖尿病、高血压、恶性肿瘤门诊治疗、冠心病、慢性肝炎、关节炎、尿毒症透析、器官移植术后抗排异治疗、慢性阻塞性肺疾病、类风湿关节炎、强直性脊柱炎等。武汉市的清单把病种分为"门诊特病"和"门诊慢病"两类共 30 余种（[武汉明白卡](https://ybj.wuhan.gov.cn/zwgk_52/zcfgyjd/zcwd/202404/t20240418_2390457.shtml)）。

### 待遇差多少：官方给的三个对比算例

国家医保局在同一篇解读里用福州市的三组数据说明差距（**这是官方原文数字，可作为量级参考**）：

| 情形 | 普通门诊 | 办了门诊慢特病 | 个人负担减少 |
|---|---|---|---|
| 在职职工 · 高血压 · 一级社区卫生服务中心 · 政策范围内 3150 元 | 报销 88%，报 2622 元，个人负担 528 元 | 报销 90%，报 2835 元，个人负担 315 元 | **213 元** |
| 在职职工 · 恶性肿瘤放化疗 · 三级医院 · 政策范围内 53150 元 | 报销 78%，报 22932 元，个人负担 30218 元 | 起付线 600 元、比例 85%、限额 120000 元（与住院共用封顶线），报 44667.5 元，个人负担 8482.5 元 | **21735.5 元** |
| 居民医保 · 地中海贫血 · 三级医院 · 政策范围内 8630 元 | 因当地居民普通门诊主要依托基层，三级医院普通门诊报销 **0 元**，个人负担 8630 元 | 起付线 400 元、限额 15000 元、比例 60%，报 4938 元，个人负担 3692 元 | **4938 元** |

差别最大的三种情形：**起付线降低、报销比例提高、封顶线提高**。

### 认定流程

1. **是否需要认定**：需要。患了目录内病种不等于自动享受待遇，必须先做**门诊慢特病病种待遇资格认定**。
2. **材料**（医保政务服务清单规定）：《门诊慢特病病种待遇认定申请表》+ **病历资料或检查资料**等。
3. **去哪办**：参保地医保经办机构窗口；大多数地区也支持线上（APP、公众号）。以福建省为例：登录闽政通 APP → 医保服务专区 → 业务经办 → 门诊慢特病病种申请 → 保存提交；进度在"我的医保 → 我的办件"查询。部分定点医疗机构可在院内直接办理。
4. **生效后**：在**有认定资质/已开通该项待遇的定点医疗机构**就诊时，挂号环节要**主动告知你有门诊慢特病待遇**，让医院把待遇与就诊卡绑定，否则系统可能按普通门诊结算。

> 如果你要异地就医：先办待遇认定，再办异地就医备案，然后在**已开通对应病种跨省直接结算**的定点医疗机构才能刷卡。目前全国所有统筹地区均已开通**高血压、糖尿病、恶性肿瘤门诊放化疗、尿毒症透析、器官移植术后抗排异治疗**等 5 种门诊慢特病的跨省直接结算；病种也要对应才能刷卡。

## 医保个人账户与家庭共济

### 钱从哪来

职工医保个人账户的资金来源（[国办发〔2021〕14号](https://www.nhsa.gov.cn/art/2021/4/22/art_37_4921.html)）：

- **在职职工**：个人账户由**个人缴纳**的基本医疗保险费计入，计入标准原则上控制在本人**参保缴费基数的 2%**；**单位缴纳的基本医疗保险费全部计入统筹基金**（这是 2021 年门诊共济改革的核心变化，很多人发现"个人账户的钱变少了"，原因在这里）
- **退休人员**：原则上由统筹基金按定额划入，划入额度逐步调整到统筹地区实施改革当年**基本养老金平均水平的 2% 左右**
- 具体划入比例或标准由**省级医保部门会同财政部门**指导统筹地区确定

**居民医保没有个人账户**——这是很多混淆的来源。

### 能怎么用

- **本人**：支付在定点医疗机构或定点零售药店发生的**政策范围内自付费用**
- **家人**：可以用于支付**本人及其配偶、父母、子女**在定点医疗机构就医发生的由个人负担的医疗费用，以及在定点零售药店购买药品、医疗器械、医用耗材发生的由个人负担的费用
- **探索用途**：个人账户可用于配偶、父母、子女参加**城乡居民基本医疗保险等的个人缴费**（部分地区已落地）
- **明确禁止**：公共卫生费用、体育健身、养生保健消费等不属于基本医疗保险保障范围的支出

### 家庭共济怎么办——先分清三个概念

这三个东西**长得像但完全不同**，国家医保局专门发文讲过（[一文讲清亲情账户、家庭共济和医保钱包](https://www.nhsa.gov.cn/art/2026/5/26/art_14_20723.html)）：

| | **亲情账户** | **家庭共济** | **医保钱包** |
|---|---|---|---|
| 干什么 | 把家人的医保码装进**你的手机**，替老人小孩展码挂号缴费 | 把你的**个人账户余额**授权给家人用 | 跨省的共济通道 |
| 花钱谁的钱 | **花家人自己的钱，走家人自己的待遇** | **花你的个人账户的钱** | 你划给家人的额度 |
| 和报销的关系 | 不涉及资金往来 | 共济的是**个人账户资金的使用权**，**不是统筹报销权** | 同左 |
| 办理 | APP 首页 → 亲情账户 → 填家人姓名身份证号 → 上传材料 → 签名确认 | APP → 首页选地方专区 → 家庭共济 → 填家人信息 → 提交 | APP 首页 → 医保钱包 → 确认开通；可"代家人开通钱包" |
| 地域 | 全国可用 | **目前通常限省内** | 跨省 |

**关键区别一句话**：*绑了亲情账户 ≠ 能用共济资金*。想用你个人账户的钱给家人付，必须**单独做家庭共济备案**。

**共济范围**（国家医保局口径）：配偶、父母、爷爷奶奶、外公外婆、兄弟姐妹、儿子女儿、孙子孙女、外孙子外孙女都行；**公公婆婆、岳父岳母不行，表兄弟姐妹不行**。注意各地细则不完全一致——武汉市门户网站写的范围是"配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女"，与国家医保局表述一致。

**两条易错点**：

1. 家庭共济资金**必须在医保定点医药机构使用**，非定点或被解除医保协议的医院药店都不行。
2. **钱可以共济，码（卡）不能共用。** 无论何时就医，都必须用**患者本人的**医保卡/医保码挂号结算。**用别人的卡挂号就医属于冒名就医**，轻则暂停医保结算，重则违法。共济的是个人账户余额，**统筹基金的报销额度不能共济**。

## 办不成怎么办

按发生顺序对号入座。

### 情况 1：结算时刷不出医保

按顺序排查：

1. **参保状态是否正常**——断缴、单位未申报、居民医保忘记缴费是最常见原因。先在国家医保服务平台 APP 查参保状态。
2. **是不是这家医院/药店的**定点**机构、有没有开通对应结算**（异地就医还要看有没有开通跨省联网结算）。
3. **用错介质**——必须是**医保电子凭证或社保卡**，身份证不能用于结算。
4. **门诊慢特病待遇没绑定**——挂号时没告知，系统按普通门诊走。
5. **系统故障** → 找医院医保办协助，或拨 `区号+12393` 报障。

### 情况 2：已经自费挂了号 / 自费交了费

部分医院支持**退费改医保**：在当天找收费处说明情况，退掉自费单、用医保凭证重新结算。**跨天或已离院通常就改不了了**，只能认账。所以第一句话就要说"我有医保"。

### 情况 3：出院时发现某笔费用被记为自费

当场（在住院收费处、尚未离院时）要求医院医保办核对：该耗材/药品/项目是否真的不在目录内、是否可以用目录内产品替代。**离院后再追讨成本极高。**

### 情况 4：报销比例比你预期的低很多

先看结算单上"个人自费"的金额。多数情况是**目录外费用占比高**，而不是医保算错了。如果"个人自费"很小、比例仍然很低，再核对：

- 是否本年度还没过起付线
- 是否已经用了部分年度限额
- 是否去的是更高级别医院（比例随级别下降）
- 是否本年度第二次住院（起付线可能减半）

### 情况 5：怀疑算错，要申诉

1. 要求医院出具**费用明细清单**，逐项核对。
2. 找医院**医保办**（不是收费窗口）复核。
3. 无果则打 `区号+12393` 或当地 12345 投诉。
4. 保留所有原件：发票、费用清单、结算单、病历、出院小结。

## 常见错误

1. **把"个人自付"和"个人自费"当成一回事** → 自付是目录内该你承担的，自费是目录外完全不管。**这是本文最想纠正的一条。**
2. **以为"报销比例 86%"就是总费用的 86%** → 比例只作用于**目录内、扣完乙类先行自付和起付线之后**的金额，另外还受封顶线限制。
3. **以为目录外的钱也能用个人账户付** → 不能。个人账户只能付目录内的个人负担部分。
4. **以为自己"参保了"看病就一定能报** → 起付线以内不报；居民医保普通门诊在非定点机构可能完全不报。
5. **用身份证挂号就诊** → 结算必须用医保电子凭证或社保卡。
6. **住院期间不看费用清单** → 目录外费用是"能少用就少用"的，出院才发现就晚了。
7. **该做门诊慢特病认定却一直按普通门诊看** → 报销比例和封顶线差出一大截（福州恶性肿瘤的例子差 21735.5 元）。
8. **以为绑了亲情账户就能花自己的钱给家人看病** → 那是家庭共济，要单独备案。
9. **拿自己的医保卡给家人挂号** → 冒名就医，可能被暂停医保结算。
10. **照搬网上看到的比例数字** → 起付线、比例、封顶线**全部由参保地决定**，一城一策，必须查自己的参保地。

## 各地差异

## 信息核实方式

政策会变。**动手前用下面任一条路核实，比信任何一篇攻略（包括本文）都可靠：**

1. **医保服务热线 12393** —— 全国医疗保障服务热线。拨打 `当地区号+12393` 由对应统筹地区经办机构接听；直接拨 12393 也可，按语音提示选择所属参保统筹区。部分地区与 12345 双号并行。
2. **国家医保服务平台** https://fuwu.nhsa.gov.cn —— 可查：全国医保经办机构咨询电话、异地联网定点医药机构、异地就医备案记录、直接结算费用明细。
3. **查某个药是否在目录内**：
   - 国家医保服务平台 APP → 首页 →「药品分类与代码」（可查西药、中成药、中草药、自制剂）
   - 「国家医保局」微信公众号 → 医保服务 →「国家医保药品目录查询」，输入药品名称，能看到**是否在目录内、所属药品分类、具体报销类别（甲类/乙类）**
   - 目录查询直达入口：https://wx.nhsa.gov.cn/#/pages/NRDL/index/index
   - 「国谈药」配备机构查询（哪家医院/药店有谈判药）：https://wx.nhsa.gov.cn/#/pages/negotiatingDrugs/negotiatingDrugs
4. **查诊疗项目、医用耗材是否在目录内**：国家层面**没有**统一的公众查询入口。请查**你参保省/市的医保局官网**发布的《基本医疗保险诊疗项目目录》《医保医用耗材支付管理目录》及政策解读；也可以直接问医院医保办。
5. **参保地医保局官网 / 公众号** —— 起付线、报销比例、封顶线、门诊年度限额、慢特病病种这些细则**只在参保地是权威的**，网上的通用攻略一律不可信。
