# 劳动仲裁：流程、时效、证据准备

> ⏱ 本文信息采集于 **2026-11**。法规与地方口径会变，动手前请用文末的「信息核实方式」确认一次。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 劳动争议先仲裁才能起诉，不收费；受理后 45 日出裁决 |
| **要带什么** | 身份证、劳动合同；没合同带工资流水、社保记录、考勤、聊天、解除通知 |
| **去哪办 / 找谁** | 劳动合同履行地或单位所在地的劳动人事争议仲裁院（设在人社局） |
| **多久 / 多少钱** | 5 个工作日决定受不受理，45 日裁决；仲裁免费，起诉每件 10 元 |
| **最大的坑** | 时效只有一年；离职后讨薪须在离职之日起一年内提出 |

## 一句话结论

**跟公司有劳动争议，不能直接去法院告：先向劳动人事争议仲裁委员会申请仲裁，不收费，受理后 45 日内出裁决。拼的是时效、证据和请求够不够具体。裁决之后怎么起诉、怎么执行，见 5.7。**

## 适用情形

### 仲裁前置：绝大多数劳动争议

《劳动争议调解仲裁法》第五条把顺序写死了：协商 → 调解 → **仲裁** → 诉讼。协商不成、调解不成都可以直接申请仲裁；未经仲裁直接起诉，法院一般不受理。第二条列了六类受案范围：

| 类型 | 典型场景 |
|---|---|
| 确认劳动关系 | 没签合同，公司不认你是员工 |
| 订立、履行、变更、解除、终止劳动合同 | 调岗降薪、不续签、违法解除 |
| 除名、辞退、辞职、离职 | 被劝退、被辞、被迫离职 |
| 工作时间、休息休假、社会保险、福利、培训、劳动保护 | 强制加班、不给年假、不缴社保 |
| 劳动报酬、工伤医疗费、经济补偿、赔偿金 | 欠薪、加班费、补偿金、赔偿金 |
| 其他法定劳动争议 | —— |

### 可以直接去法院、不必先仲裁

- 手里有公司出具的**工资欠条**，且请求不涉及劳动关系的其他争议：法院按普通民事纠纷受理（《解释（一）》第十五条）。
- 在调解组织主持下**仅就劳动报酬**达成调解协议、公司不履行：可持调解协议书向法院申请**支付令**（《劳动争议调解仲裁法》第十六条）；支付令程序终结后，也可依调解协议直接起诉（《解释（一）》第五十一条第二款）。

### 压根不属于劳动争议

《解释（一）》第二条排除六类：请求社保经办机构发放社保金、公有住房转让、对伤残等级或职业病诊断鉴定结论的异议、家庭与家政人员之间、个体工匠与帮工学徒之间、农村承包经营户与受雇人之间。事业单位聘用制人员的争议仍走仲裁（《劳动争议调解仲裁法》第五十二条）。另有三类各地口径不一，**先打电话问**：补缴社保（多走社保稽核或劳动监察）、住房公积金（找公积金管理中心）、补签合同或安排年休假这类无法直接给付的请求。

### 可以并行的一条路：劳动监察投诉

讨薪、追缴社保还可向**劳动保障监察机构**举报投诉（隶属人社局）。走行政责令、不开庭，常比仲裁快，但管不了补偿金、赔偿金、二倍工资。两条路可同时走，**同一请求已被仲裁受理的除外**。

## 需要准备什么

### 三层事实，各有对应证据

| 要证明什么 | 关键证据 |
|---|---|
| 劳动关系（或事实用工）——**地基** | 劳动合同；无合同时：工资流水、社保与公积金记录、个税 APP 收入明细、工作群与钉钉记录、工牌门禁、OA 审批、同事证言 |
| 工资标准、欠薪金额、加班时长 | 银行流水（摘要含「工资」）、工资条、Offer 薪资条款、调薪通知、考勤或排班记录、加班审批单、加班通知 |
| 解除或离职时间与理由 | 解除通知、微信与钉钉辞退消息、录音、离职证明、退工单、**社保停缴记录**（常是离职时间的锚点） |

### 只能抓三样的话

**① 工资银行流水**（同时证明劳动关系和工资水平，盖章打印件真实性高）；**② 社保、个税缴费记录**（第三方生成，公司难否认）；**③ 解除通知或能证明离职时间的记录**（决定补偿金能否成立）。

### 举证责任倒置：哪些证据该公司拿出来

| 规则 | 内容 | 依据 |
|---|---|---|
| 一般倒置 | 证据属于**用人单位掌握管理**的，单位应当提供，不提供承担不利后果；你无法提供时，仲裁庭可要求单位限期提供 | 第六条、第三十九条；《办案规则》第十三条 |
| 处分类争议 | 因单位**开除、除名、辞退、解除劳动合同、减少劳动报酬、计算工作年限**等决定发生的争议，**单位负举证责任** | 《解释（一）》第四十四条 |
| 加班费 | 加班事实原则上由**你先举证**；但你能证明单位**掌握加班事实证据**而不提供，由单位承担不利后果 | 《解释（一）》第四十二条 |
| 兜底 | 法律无规定、也确定不了时，仲裁庭按公平和诚实信用原则，结合双方举证能力确定 | 《办案规则》第十四条 |

**通常属于「单位掌握管理」、可以要求它提供的**：劳动合同文本（解除或终止的文本至少保存二年备查，《劳动合同法》第五十条）、**考勤记录**、**工资支付凭证与工资台账**、社保缴费明细、规章制度的**公示**证据。

> 实操：要求公司提供证据要交**书面申请**并请仲裁庭记入笔录。若连「公司掌握这些证据」的线索都拿不出（比如你从未打卡、公司也从不发工资条），倒置规则很难启动。

### 电子证据（微信、钉钉、录音）怎么固定

规则：《民事诉讼证据的若干规定》**第十五条**——视听资料应提供**原始载体**；电子数据应提供原件，**与原件一致的副本或直接来源于电子数据的打印件等输出介质视为原件**。**第九十三条、第九十四条**——综合系统环境、保存传输提取是否完整、是否在正常往来中形成判断真实性；**经公证**、由中立第三方平台提供或确认、正常业务中形成的电子数据，通常可直接确认真实性。

操作要点：

- **手机别卖、别刷机、别退群、别清聊天记录**——原始载体一毁，截图价值大减。
- **用屏幕录制代替单纯截图**：先点开对方资料页显示**微信号或手机号**，再完整滑过对话，同时证明「对方是谁」和「内容未剪裁」。
- 对方可能删记录、注销账号，或你即将失去账号权限的，**尽早公证或做可信时间戳**。
- **录音保留原始文件**，不剪辑、不只交转录文字。
- **备份一份**（聊天记录迁移、钉钉导出）另存电脑；开庭带**证据清单**（编号、来源、证明目的）加原件，电子证据打印关键页并当庭播放。

## 去哪里办

### 管辖：两地可选，你挑一个

《劳动争议调解仲裁法》第二十一条：由**劳动合同履行地**或**用人单位所在地**的仲裁委员会管辖；双方分别申请的，由**劳动合同履行地**管辖。《办案规则》第八条把概念说清了：**履行地**＝你**实际工作场所**所在地；**单位所在地**＝单位**注册、登记地**或**主要办事机构所在地**（未登记注册的，其出资人、开办单位或主管部门所在地）；有多个履行地的由**最先受理**的仲裁委管辖；履行地不明确的由单位所在地管辖；受理后地点发生变化，**不改变管辖**。

**怎么选**：优先选**你实际工作地**，通勤近、成本低。公司注册在外地、你在本市上班的，原则上可在本市申请。外派、远程办公、多城出差的履行地会有争议，先拨 `12333` 或到窗口确认。管辖异议由对方在**答辩期满前书面提出**（《办案规则》第十条），逾期不影响程序；仲裁委自认无管辖权的会移送并书面通知你（第九条）。

### 找谁

仲裁委员会与「劳动争议仲裁委员会」合设，日常叫**劳动人事争议仲裁院**，一般设在市、区（县）人社局内。三个入口：**当地人社局官网、公众号、人社 APP**（多数地区支持在线申请，菜单多在「劳动关系」「调解仲裁」栏目下）、**`12333` 人社热线**、**立案窗口**（当场问、当场交）。

## 多久办完

### 你有多久：一年，从「知道被侵害之日」起算

《劳动争议调解仲裁法》第二十七条第一款：申请仲裁的时效期间为**一年**，从知道或者应当知道权利被侵害之日起算。

| 争议类型 | 起算点（通常口径） |
|---|---|
| 拖欠某月工资 | 该月工资应发之日届满的次日 |
| 违法解除 | 收到解除通知之日（口头通知的以你能证明的知悉之日） |
| 加班费、二倍工资、未休年假工资、补偿金、赔偿金 | 口径最不统一：加班费多按各月工资应发日分别起算；二倍工资有的按月分别起算、有的从应订立书面合同之日起算；补偿金、赔偿金一般自解除或终止之日起算 |

### 中断：让一年重新开始算

第二十七条第二款、《办案规则》第二十七条规定三种中断情形，任一发生，时效从那时起**重新计算一年**：

**① 你向对方主张权利**（协商、微信催要、发函、申请调解）；**② 你向有关部门请求权利救济**（劳动监察投诉、申请仲裁、起诉、申请支付令）；**③ 对方同意履行义务**（承诺发薪、出具还款计划、聊天中承认欠薪）。

> ⚠️ 关键不是「催没催」，而是**能不能证明催过**：微信留原始记录，电话录音，寄函用 EMS 并在详情单写清文件名，投诉留受理凭证。**没有留痕的催要，等于没发生。**

### 中止：一年暂停

第二十七条第三款、《办案规则》第二十八条：因**不可抗力**，或者无民事行为能力、限制民事行为能力劳动者的法定代理人未确定等其他正当理由，不能申请仲裁的，时效**中止**，原因消除之日起**继续计算**（接着走，不是重新算）。「其他正当理由」空间比想象中小：生病、出差、不知道能仲裁通常不算；时效抗辩一般由**单位提出**，但部分地区立案即以超时效不予受理。

### 劳动报酬的特殊规则（最重要的一条）

第二十七条第四款：

> 劳动关系**存续期间**因**拖欠劳动报酬**发生争议的，劳动者申请仲裁**不受**一年时效限制；但是，**劳动关系终止的，应当自劳动关系终止之日起一年内提出**。

拆成人话：**还在职、还在被欠薪**，不受一年限制，可追讨较久以前的欠薪（仍受举证能力和凭证保存期限限制）；**已离职的**，从**离职之日**起一年内必须提出。

注意它**只管「拖欠劳动报酬」**：经济补偿金、赔偿金、二倍工资、未休年假工资是否算「劳动报酬」各地裁判口径不一，**别因为「公司还欠我工资」就以为所有请求都不受时效限制**。

### 从递材料到裁决：5 个工作日 + 45 日

| 环节 | 时限与要点 | 依据 |
|---|---|---|
| 提交申请 | 书面申请，按被申请人人数交副本；书写困难可口述记入笔录；材料不齐的，应当**当场或五日内一次性告知**需补正的全部材料 | 《办案规则》第二十九条 |
| 受理 | 收到申请起 **5 日内**决定；受理、不予受理都出书面通知并说明理由 | 第二十九条；《办案规则》第三十条、第三十一条 |
| 送达与答辩 | 受理后 5 日内送达申请书副本；被申请人收到后 **10 日内**答辩，不答辩不影响审理 | 第三十条；《办案规则》第三十三条 |
| 开庭通知 | **开庭五日前**书面通知；你有正当理由可在**开庭三日前**请求延期 | 第三十五条；《办案规则》第三十八条 |
| 审理期限 | 自**受理起 45 日内**结束（裁决前先行调解，调解书经双方签收生效）；经主任批准可延期，**最长不超过 15 日** | 第四十三条、第四十二条；《办案规则》第四十五条 |
| 逾期未裁决 | 当事人可就该事项**向法院起诉** | 第四十三条；《解释（一）》第十二条 |
| 裁决与送达 | 裁决书写明请求、事实、理由、结果、救济权利与日期；送达回证**签收日期**为送达日；拒收，或企业停业无法送达且劳动者十人以上的，**留置、张贴并拍照录像，满三日视为送达** | 《办案规则》第二十条、第五十三条 |
| 先予执行 | 追索劳动报酬等，权利义务明确且不先予执行严重影响生活的可申请；**劳动者无需提供担保** | 第四十四条；《办案规则》第五十一条 |

一句话节奏：**5 个工作日决定受不受理、45 日出裁决（最多 60 日）、开庭前 5 日通知你。**表里的「5 日」「10 日」是工作日，「45 日」是自然日（《办案规则》第八十条）；超期未裁决可直接起诉。

## 费用

### 仲裁不收费

《劳动争议调解仲裁法》第五十三条：**劳动争议仲裁不收费。劳动争议仲裁委员会的经费由财政予以保障。**立案窗口不收案件受理费、处理费。

### 可能要自己出的钱

| 项目 | 说明 |
|---|---|
| 鉴定费 | 由申请方**先行垫付**，结案后由**鉴定结果对其不利的一方**负担；结果不明确由申请方负担（《办案规则》第四十条） |
| 公证费、交通打印邮寄误工 | 电子证据、录音公证按公证处标准自付；立案、开庭、领文书也要跑 |
| 律师代理费 | 一般自己承担，不属可向对方主张的项目（法律另有规定的除外） |
| 诉讼阶段受理费 | 对裁决不服起诉的，劳动争议案件**每件 10 元**，**追索劳动报酬的案件可以不预交**（《诉讼费用交纳办法》第十三条第（四）项、第二十条）；确有困难可申请缓交、减交、免交（第四十四条；追索社会保险金、经济补偿金的可缓交，第四十七条第（一）项） |

> ⚠️ 张口「包赢」「打赢抽三成」、收「内部关系费」的，先看执业证和收费依据——请求给付劳动报酬类案件在收费上有明确限制。

### 免费的法律援助与咨询

- **法律援助中心**（县区司法局下设）：可免费获得**代拟法律文书、调解与仲裁代理、诉讼代理**（《法律援助法》第二十二条）。因经济困难没有委托代理人，**请求确认劳动关系或支付劳动报酬**可申请（第三十一条第五项）；**申请支付劳动报酬的进城务工人员免予核查经济困难状况**（第四十二条第三项）；经济困难标准由各省确定（第三十四条）。法律援助机构**七日内**审查决定，决定给予的**三日内**指派（第四十三条）；距时效或期限届满不足七日、需立即申请保全或先予执行的，可**先行提供援助**（第四十四条）。
- **`12348` 公共法律服务热线**：免费法律咨询。
- **工会法律援助**：各级总工会的法律援助中心、职工服务中心常配驻场律师。
- **`12333` 人社热线**：去哪、带什么、办到哪步等流程性咨询。

## 办不成怎么办

### 情况 1：申请书被退回、材料不齐

**必须一次性告知。**《办案规则》第二十九条规定，申请书不规范或材料不齐的，应当**当场或五日内一次性告知**需补正的全部材料。常见补正项：请求不明确或缺金额、缺公司主体信息、证据没副本、身份证明不全。

### 情况 2：不予受理

不予受理出书面通知并说明理由。三条路：**① 补救后重交**（如把「补发工资」改成「支付 2026 年 3 月至 5 月工资共 24,000 元」）；**② 告错地方**——不属本委管辖的，会书面告知去有管辖权的仲裁委（《办案规则》第三十一条）；**③ 直接去法院**——对不予受理不服或仲裁委逾期未决定的，可就该事项起诉（第二十九条；《办案规则》第三十一条第二款）。

### 情况 3：公司不应诉、不到庭

**不影响你的案子。**被申请人收到书面通知无正当理由拒不到庭的，可以**缺席裁决**（第三十六条；《办案规则》第三十九条），不交答辩书也不影响审理。**但反过来**：你若无正当理由不到庭，可能被**按撤回处理**，重新申请仲裁**不予受理**（《办案规则》第三十九条）——务必到场，去不了提前书面申请延期。

### 情况 4：公司跑路、注销、停业

| 情形 | 应对 |
|---|---|
| 未办营业执照、被吊销、执照到期继续经营、被责令关闭、解散歇业且不能担责 | 把**用人单位和其出资人、开办单位或主管部门列为共同当事人**（《办案规则》第六条） |
| 与**个人承包经营者**发生争议 | 把**发包的组织和个人承包经营者列为共同当事人**（第七条） |
| 送达不到、对方拒收 | 可**留置、张贴并拍照录像，满三日视为送达**；还可参照民事诉讼的公告送达 |
| 公司已注销、或担心赢了拿不到钱 | 注销后一般转向**股东、清算义务人**主张（各地口径差异大，先问属地仲裁委或法律援助）；同时尽早申请**财产保全**，经济困难或有欠薪逃匿可能的可减轻或免除担保（《解释（一）》第四十九条） |

先查清对方状态：**国家企业信用信息公示系统**（`gsxt.gov.cn`）能查注册地、经营状态、股东，决定被申请人怎么写，也影响管辖。

### 情况 5：已经超过仲裁时效

按顺序试，不要直接放弃：

1. **找中断证据**：微信催要、邮件、通话录音、催告函与 EMS 记录、投诉受理凭证、对方承认欠薪的记录——有一处成立，时效从那时重算。
2. **区分请求**：**存续期间的拖欠劳动报酬**本就不受一年限制，只有离职后讨薪受一年限制。
3. **换路径**：劳动监察投诉另有查处规则，社保补缴可走社保稽核。
4. **借力协商**：超时效只失去强制力，不等于拿不到钱，工会或街道调解组织出面仍可能回款。

### 情况 6：对方一路拖时间

| 对方动作 | 你的应对 |
|---|---|
| 提管辖异议、申请延期开庭 | 管辖异议须在**答辩期满前书面**提出，逾期不影响程序；延期开庭需正当理由，有异议可当庭提出 |
| 拖到审限届满 | 仲裁庭须在**受理起 45 日内**结案、最长延 15 日；**逾期未裁决你可直接起诉**（第四十三条） |
| 裁决后继续拖、拒不付钱 | 一裁终局案件对方只能申请撤销，拖延空间小；不付钱怎么执行、要不要限高失信，见 5.7 |

生活受严重影响的，可申请**先予执行**，劳动者**无需提供担保**（第四十四条）。

## 常见错误

1. **没走仲裁直接去法院** → 一般不予受理，白跑还耽误时效。
2. **只口头催要** → 时效中断无证据，等于没催。
3. **以为「公司欠我工资，什么时候都能要」** → 例外只限**存续期间**，离职后须在一年内提出。
4. **请求写得太笼统**（只写「补发工资」） → 容易被要求补正，甚至不予受理。
5. **把公司掌管的证据责任全扛在自己身上** → 考勤、工资台账、制度公示等属单位掌握管理，可书面申请要求其提供。
6. **离职时清空手机、退群、删聊天，或把录音剪掉一段** → 原始载体灭失或被动过，证明力大打折扣。
7. **无视开庭通知** → 你无正当理由不到庭按撤回处理，重新申请不予受理；务必到场或提前书面申请延期。

## 各地差异

| 事项 | 各地做法 | 来源 |
|---|---|---|
| 二倍工资、加班费的时效起算 | **全国**：加班费属劳动报酬，存续期间不受一年限制，终止的自终止之日起一年内提出；未签书面合同二倍工资**按月计算**，实务上多按月分别起算时效；**北京市**：二倍工资分两段——正常工作时间劳动报酬部分适用第二十七条第四款，增加一倍的惩罚性部分适用第一款，可自主张权利之日起向前一年按日计算、实际给付不超过十二个月 | 全国：人社部函〔2021〕90号案例10；《解释（二）》第六条（https://www.court.gov.cn/fabu/xiangqing/472691.html）；北京：京高法发〔2024〕534号第41条（https://rsj.beijing.gov.cn/xxgk/tzgg/202404/t20240430_3648905.html） |
| 补缴社保是否受理 | **全国**：因单位未办社保手续、经办机构不能补办致无法享受待遇而索赔的，法院应予受理（《解释（一）》第一条第（五）项）；单纯要求补缴社保费（已办手续但欠缴、基数不足）国家层面未统一，多地导向社保费征收机构或劳动保障监察；**北京市**：未建立社保关系、欠缴社保费或未按工资基数足额缴纳，主张补缴的**不属于劳动争议受理范围**，告知通过劳动行政部门解决 | 全国：《解释（一）》第一条第（五）项（https://www.court.gov.cn/fabu/xiangqing/282121.html）；北京：京高法发〔2024〕534号第1条（https://rsj.beijing.gov.cn/xxgk/tzgg/202404/t20240430_3648905.html） |
| 单位注销后的主体确定、诉讼阶段才提时效抗辩 | **全国**：未办执照、被吊销、执照到期继续经营、被责令关闭、解散歇业且不能担责的，把用人单位与出资人、开办单位或主管部门列为共同当事人（已注销后列谁未统一）；仲裁期间因自身原因未提时效抗辩、到一审二审才提的，法院不予支持；**北京市**：自动歇业、被撤销、被吊销执照的仍列该用人单位为当事人，由清算组负责人或原法定代表人代表；未办执照、被吊销或营业期限届满仍继续经营的，用人单位不存在或无力担责时由**出资人**承担相应责任并列为被告 | 全国：《办案规则》第六条（https://www.mohrss.gov.cn/SYrlzyhshbzb/ztzl/ldrszytjzc/fgzc/202207/t20220714_457861.html）；《解释（二）》第二十条（https://www.court.gov.cn/fabu/xiangqing/472691.html）；北京：京高法发〔2024〕534号第27条、第28条、第41条（https://rsj.beijing.gov.cn/xxgk/tzgg/202404/t20240430_3648905.html） |

> 📌 一行一个事项、逐行自带来源，便于将来拼出「按城市看」的索引。

## 信息核实方式

法规与地方口径都会变。**动手前用下面任一条路核实，比信任何攻略（包括本文）可靠：**

1. **`12333` 人社服务热线**（拨「当地区号+12333」）——问管辖、材料、进度。
2. **当地仲裁委、仲裁院**（一般设在市、区县人社局）——官网、公众号或立案窗口。
3. **`12348` 公共法律服务热线 + 当地法律援助中心**——免费咨询，符合条件可申请免费代理。
4. **基层法院诉讼服务中心、人民法院在线服务小程序**——起诉材料、缓减免诉讼费、财产保全（细节见 5.7）。
5. **`flk.npc.gov.cn`**（国家法律法规数据库）核对法条原文，**`mohrss.gov.cn`** 查《办案规则》等部门规章。
6. **`gsxt.gov.cn`（国家企业信用信息公示系统）** 查注册地、经营状态、股东；**`si.12333.gov.cn`（国家社会保险公共服务平台）** 与个税 APP 可下载打印社保与收入记录，本身就是证据。

## 行动清单

- [ ] 判断争议类型：先仲裁，还是可直接走法院或别的渠道
- [ ] **算时效**：定起算点，核对是否属于「存续期间拖欠劳动报酬」的例外
- [ ] 收集并固定证据：工资流水、社保与个税记录、考勤与加班记录、聊天与录音、解除通知；电子证据屏幕录制并备份
- [ ] 查清单位登记与经营状态（`gsxt.gov.cn`）定管辖；拨 `12333` 或到窗口确认材料清单
- [ ] 写仲裁申请书：请求明确到「期间＋金额」，附证据清单与副本；提交后留好受理通知书
- [ ] 有欠薪逃匿风险或生活受严重影响的，同步申请**先予执行**或**财产保全**；经济困难的申请法律援助
- [ ] 开庭务必到场，去不了提前书面申请延期
