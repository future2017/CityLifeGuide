# 住院费用与结算

> ⏱ 本文信息采集于 **2026-09**。政策调整频繁，动手前请用文末的「信息核实方式」确认一次。

> **医保的基本概念**（起付线、目录、自付与自费的区别）见 [4.3 医保结算流程与自费部分](medical-insurance-settlement.md)。

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 账单超预期的通常不是床位费、药费，而是耗材、目录外药品、特需服务——自费栏一分不报 |
| **要带什么** | 出院必收齐：发票原件、费用总清单、出院小结、诊断证明、医保结算单；手工报销还需病历复印件 |
| **去哪办 / 找谁** | 出院结算在医院窗口（多地一站式）办完；有异议找医院医保办、物价/财务科，再打区号+12393 |
| **多久 / 多少钱** | 直接结算当场结清，只付个人自付+自费；手工报销有时限（如上海 6 个月）；病历复印收工本费 |
| **最大的坑** | 发票原件只有一份，用了报销就交出去了——要报商保或二次报销的，先复印留底再交原件 |

## 一句话结论

> 住院账单里真正会超出你预期的，**通常不是床位费和药费，是耗材、目录外药品和特需服务**。你在住院期间签的每一张「自费知情同意书」，最后都会变成账单上的一个数字。

这一节只讲钱：**费用由什么构成 → 出院怎么结算 → 结算单怎么核对 → 报销出问题找谁。**

## 费用构成拆解

### 官方分类：住院费用就是这些条目

国家医保局的《医疗保障基金结算清单》是全国统一的收费分类口径，住院医疗收费信息分这几项（[来源](https://www.nhsa.gov.cn/module/download/downfile.jsp?classid=0&filename=f46c5c96e954469c9eda6755cab9f4e9.pdf)）：

| 收费项目 | 里面装的是什么 | 常见超预算风险 |
|---|---|---|
| **床位费** | 病床、被服洗涤、开水供应、病区清洁消毒等 | 低（政府指导价）。**但特需/单间/套间按市场调节价，差价巨大** |
| **诊察费** | 医生查房、接诊、开具医嘱等 | 低 |
| **护理费** | 分级护理（特级/一级/二级/三级） | 中（ICU 按小时累计，天数一长就显著） |
| **检查费** | 影像（CT/MRI/超声）、内镜、心电图、病理等 | 中（大型设备检查单价高，重复检查要问为什么） |
| **化验费** | 血、尿、便、生化、免疫、微生物培养等 | 中（项目多而碎，靠一日清单核对） |
| **治疗费** | 输液、换药、吸氧、理疗、透析等 | 中 |
| **手术费** | 各类手术服务费（**麻醉服务费在多数医院的费用清单上单列，在国家结算清单里并入手术类申报**） | 中高（复杂手术单价高） |
| **卫生材料费（医用耗材）** | 缝合线、导管、支架、人工关节、止血材料、防粘连材料等 | **最高** ⚠️ |
| **西药费 / 中成药费 / 中药饮片费** | 药品 | **高**（目录外/进口药） ⚠️ |
| **一般诊疗费 / 挂号费** | 门诊性质的基础费用 | 低 |
| **其他费** | 血液制品、氧气、陪护等 | 中 |

> 📌 **医院自己的「一日清单」通常比这张表更细**，会把麻醉费、血液费、监护费等单列。**以医院清单为准，以结算清单的分类为理解框架。** 各地对「麻醉费」是否单列的做法不一致（见「各地差异」）。

### 最容易超预算的三项

**第一：医用耗材（卫生材料费）—— 头号超支项**

高值耗材动辄上千到几万元：支架、人工关节、吻合器、防粘连材料、进口缝线。

- **能做的：** 要求医生告知耗材**名称和价格**；问**有没有集采中选产品**（集中带量采购后价格常降到原价的十分之一以下）；确认是否属于**植入类或Ⅲ级耗材**（这类**必须签知情同意书**）。
- **不能忍的：** 医院以「病组或病种费用限额」为由，**要求你在院外购买或自备药品、医用耗材**。国家医保局明确规定，**因自身配备等原因要求患者院外购买或自备药品、耗材的，原则上应计入按病种付费费用及医疗机构医保总额**（[2025-05-28 通知](http://www.nhsa.gov.cn/module/download/downfile.jsp?classid=0&filename=655ddb9acbb1449d857036bcd12f7f10.txt)）。

**第二：目录外药品，尤其是进口药 / 创新药**

- 同通用名的国产仿制药通常便宜很多且可报销。**先问有没有目录内的替代。**
- 有些药（如部分靶向药、丙类目录药品）疗效确实更好但全额自费。这是**价值判断**，不是对错判断——但**你必须先知道价格再决定**。
- 计划性长期用药（化疗、免疫治疗），**在第一次用药前就把整个疗程的账算清楚**，不要一次一次地被通知缴费。

**第三：特需服务（特需门诊／特需病房／点名手术／全程护理）**

- 政策定位：特需医疗费用**由患者自行负担，不纳入基本医疗保险支付范围**（使用个人账户资金的除外）；价格实行**市场调节价**，由医院自主定价并向医保部门备案；服务规模**不得超过全部医疗服务的 10%**；特需病房原则上为单人间或套间（[山东省 2026 年意见](http://www.ny.gov.cn/art/2026/9/14/art_228254_10364107.html)）。
- 病房床位费的分野：**普通多人间、单人间、双人间、层流洁净病房、ICU 病房**等实行**政府指导价**；**特需单人间、套间病房**实行**市场调节价，由医院自主定价**，且**自主定价床位数不得超过登记总床位数的 10%**，坚持**患者自愿选择，不得强制或误导患者入住**（[岳阳市价格通知](https://www.yueyang.gov.cn/yyyb/57568/57570/content_1785755.html)）。
- **普通床位费到底多贵？** 参考重庆市政府指导价：三级医院普通病房床位费 **47 元/日**，二级 **31 元/日**，一级 **19 元/日**；临时加床三级 43 元、二级 28 元、一级 18 元（[重庆市医保局](https://ylbzj.cq.gov.cn/zwgk_535/zfxxgkml/zcwj_291934/gfxwj/202107/W020220719638085923020.pdf)）。这个价格本身就是**医保甲类**。
  ⚠️ 这是**重庆的政府指导价**，不是全国价。普通床位费各地不同，但量级相近；**特需病房则完全没有上限参照**。

### 算一笔账：钱是怎么被拆开的

以内蒙古医科大学附属医院公示的公式为例：

> **统筹基金支付 =（住院医疗费 − 起付线 − 个人自付 − 个人自费）× 基金支付比例**

其中：

- **个人自付**：目录**范围内**由个人负担的部分。包括起付线以下、乙类先行自付、按比例自付、封顶线以上、目录内超限价部分。
- **个人自费**：目录**范围外**的药品、医用耗材、项目，**由参保人员全额支付**。

**举个算例**（数字为示意，比例与起付线各地不同）：

| 项目 | 金额 |
|---|---|
| 住院总费用 | 50,000 元 |
| 减：起付线 | −1,000 元 |
| 减：个人自付（乙类先行自付 + 按比例自付） | −3,000 元 |
| 减：个人自费（目录外耗材 + 目录外药品） | −8,000 元 |
| 可报销基数 | 38,000 元 |
| × 报销比例 80% | **统筹基金支付 30,400 元** |
| **你实际要付** | **19,600 元**（= 1,000 + 3,000 + 8,000 + 38,000×20%） |

**看明白这笔账的关键：那 8,000 元自费不进报销基数，一分都报不了。** 它才是预算失控的真正来源。

## 出院结算

### 两种结算路径，待遇可能不一样

| | 医保**直接结算** | **先自费、后手工报销** |
|---|---|---|
| 什么时候发生 | 出院时在医院窗口一次办完 | 先全额付款，再回参保地医保经办机构申请 |
| 你要先垫多少 | **只付个人自付 + 个人自费部分** | **全额** |
| 到账时间 | 当场结清 | 上海规定可在开具收据之日起 **6 个月内**申请；其他地区时限不同 |
| 待遇 | 按正常待遇 | 备案过的直接结算失败（如系统故障）按正常待遇；**未备案**的多数地区降比例 |
| 需要什么 | 医保凭证 | **发票原件**、费用总清单、出院小结、诊断证明等 |

**核心事实：** 国家医保局明确，实行直接联网结算后，**参保患者出院时只缴纳个人自付费用**，医保报销部分由医保经办机构与医院结算，患者不需要垫资（[来源](https://www.nhsa.gov.cn/art/2025/1/13/art_14_15457.html)）。

**「一站式结算」在多地已经实现：** 排一次队即可办理医保报销、结算补退款、诊断书盖章全部手续；医保与商业保险（如惠民保）也能同步结算，结算单和费用明细可在医保小程序查询。

**什么时候会走不了直接结算：** 医保卡故障（过期未换、已挂失、欠费欠缴被封锁）、备案有效期没有覆盖整个住院时间段、医院未开通跨省异地联网结算、系统故障。**这类情况先自费结算、再回参保地手工报销；备案过的按正常待遇。**

### 结算单怎么看

出院时拿到的是**结算单（医保结算单 / 费用结算单）**。对照国家结算清单的字段，你只要认清左右两栏：

**左栏：钱花在哪（收费分类）**

床位费 / 诊察费 / 检查费 / 化验费 / 治疗费 / 手术费 / 护理费 / 卫生材料费 / 西药费 / 中药饮片费 / 中成药费 / 一般诊疗费 / 挂号费 / 其他费 → **金额合计**

**右栏：谁付钱**

- **基金支付**：医保统筹基金支付 + 大病保险 + 医疗救助 + 其他支付（公务员医疗补助、大额补充、企业补充……）
- **个人支付**：**个人自付 + 个人自费** → 个人账户支付 / 个人现金支付

> 📌 **一眼看懂的判断法：**
> - 「**个人自费**」= 目录外，**一分不报**。这一栏是钱漏掉的地方。
> - 「**个人自付**」= 目录内但要你自己承担的部分（起付线、乙类先行自付、按比例自付）。
> - **两者相加 = 你掏的现金**（若不动用个人账户）。

### 核对报销明细：四个动作

1. **对总额。** 结算单的「金额合计」是否等于你在住院期间从一日清单累计看到的费用？差额大就要求调明细。
2. **挖自费。** 把所有「自费」行拉出来，逐项回忆：**这项我签过知情同意书吗？签字的时候我知道价格吗？**
3. **查起付线。** 起付线是按**年度内第几次住院**递减的（多地规定：第一次最高，第二次降，第三次及以上再降甚至为零）。医院是否按你本年度第几次住院正确计算？本年度在其他医院住过院的，要提醒结算窗口。
4. **看封顶。** 基本医保有年度最高支付限额，超出部分由大额补充/大病保险接着走（各地名称不同）。如果你的费用接近封顶线，**主动问结算窗口「超额部分怎么走」。**

**核对不出来的，走这条路径：** 医院医保办（现场）→ 医院物价/财务部门（收费争议）→ 参保地医保经办机构 `区号+12393`。

## 大病保险与二次报销的衔接

（本节只讲**衔接动作**；制度细节、救助渠道与慈善资源见本书 **4.10 大病保险与医疗救助**。）

**先记住一句话：大病保险通常不需要你单独申请，也不需要额外缴费。**

- 大病保险的保障对象是**全体城乡居民医保参保人**，保费已包含在基本医保缴费中，**无需额外缴费、无需单独申请**；结算时由系统自动计算，符合条件的直接报销（[武汉市医保局](https://ybj.wuhan.gov.cn/zwgk_52/ybdt/ybyw/202009/t20200921_1452790.shtml)）。
- 触发条件：**一个年度内，基本医保报销后个人负担的「政策范围内」医疗费用累计超过起付线**的部分，进入大病保险分段报销。

**几个关键概念，出院结算是必须分清的：**

| 概念 | 含义 | 能否进大病保险 |
|---|---|---|
| **政策范围内费用 / 合规医疗费用** | 使用医保目录内药品、耗材、项目产生的费用 | ✅ 是计算基础 |
| **个人自费** | 目录**外**的费用 | ❌ 不进 |
| **起付线以下部分** | 基本医保起付线内自己承担的部分 | ❌ 不进（多地规定） |
| **乙类先行自付费用** | 乙类药品/项目先自付的那部分 | ❌ 不进（多地规定） |
| **超支付标准自付费用** | 超出医保支付标准的部分 | ❌ 不进 |
| **跨省异地就医降比例部分** | 因未备案/未转诊而降低报销比例产生的差额 | ❌ 不进 |

*（以上「不纳入」的口径见铜陵市医保局 2026 年政策明白纸，各地细则不同。）*

**起付线与分段比例：完全由各统筹区自定，不能照搬。**

| 地区 | 大病保险起付线 | 分段报销比例（示例） |
|---|---|---|
| 安徽铜陵（居民） | 1.7 万元 | 0–5 万 60%；5–10 万 65%；10–20 万 75%；20 万以上 80%；年度限额 30 万 |
| 湖北武汉（居民，2020 年口径） | 1.2 万元 | 1.2–3 万 60%；3–10 万 65%；10 万以上 75%；年度限额 30 万 |
| 北京（居民，2020 年口径） | 3.0404 万元 | 5 万以内 60%；5 万以上 70%；上不封顶；**一年报销一次，次年报销上年度** |

**出院结算时你要做的衔接动作：**

1. **问结算窗口：「这次住院走完基本医保后，大病保险有没有自动算进去？结算单上哪一行是大病保险？」** 如果是**一站式同步结算**，结算单上会单独列出。
2. **如果是「年度事后报销」的（如北京）**，你不需要申请，但要**保留全部票据原件**，等经办机构按年度结算后打款到社保所或个人银行账户。
3. **把你的「个人自费」部分记住。** 大病保险、医疗救助、惠民保、慈善援助，很多都对自费部分另设规则——4.10 会展开。
4. **对困难群体有倾斜**：多地规定低保、特困、返贫致贫人口起付线**降低 50%**、报销比例**提高 5 个百分点**、**取消封顶线**。如果你或家人属于这类身份，**出院时主动向医院医保办说明**。

## 出院后要拿到的材料

**出院当天就要把所有材料收齐。** 出院后再回医院补，成本高得多。

| 材料 | 说明 | 是否收费 |
|---|---|---|
| **医疗收费票据（发票）原件** | 手工报销的**必需项**，且多数地区要求**原件** | 否。现在多地已推行**电子票据** |
| **住院费用总清单 / 结算汇总清单** | 全部费用的逐项明细，手工报销必需 | 否 |
| **出院小结 / 出院记录** | 主治医师对本次住院的总结。按规定应当在**患者出院后 24 小时内**完成（《病历书写基本规范》） | 否 |
| **诊断证明书（出院诊断证明）** | 请假、工伤、商保、单位报销都要用。**通常需要医院盖章** | 否 |
| **医保结算单** | 直接结算的会有；手工报销可替代 | 否 |
| **病历复印件（病案）** | 商保理赔、二次报销、异地就医、纠纷时要用 | **要钱**（工本费，见下） |

**手工报销的材料清单（多地口径一致）：**

- 苏州：① 医保电子凭证或有效身份证件或社会保障卡 ② **医院收费票据原件（即发票原件）** ③ **住院费用清单** ④ **诊断证明或出院小结**
- 北京房山（住院类）：出院诊断证明、**住院费用结算汇总清单**、**全额结算证明**（异地费用除外）、病历复印件（外伤、异地就医及审核需核实项目时使用）
- 上海一网通办：医保卡、**疾病诊断证明书**、**住院期间的医疗费用汇总清单**、**出院（观）小结**
- 辽宁抚顺：完整的**住院病志**、住院费用收据、费用明细清单、二代医保卡复印件

> ⚠️ **发票原件只有一份。** 如果你同时要报**商业保险**和**基本医保**，先确认商保能否接受**复印件+盖章**或**电子票据**，否则先报基本医保、再拿医保结算后的分割单去报商保。

### 病历复印件怎么弄、要不要钱

**制度依据（全国适用）：**《医疗机构病历管理规定（2013 年版）》（国卫医发〔2013〕31 号，2014-01-01 起施行，同时废止 2002 年版）明确，**住院病历由医疗机构负责保管**，患者本人或其代理人有权申请复制，医院应当**在申请人在场的情况下复印**，**经申请人核对无误后加盖证明印记**（[来源](https://www.nhc.gov.cn/yzygj/c100068/201312/c9955f0471c04450a9f9ab74648fbdd4.shtml)）。

**申请需要什么：**

| 谁办 | 要带什么 |
|---|---|
| 患者本人 | **本人有效身份证明** |
| 患者代理人 | 患者及代理人的有效身份证明 + **代理关系的法定证明材料** |
| 已故患者近亲属 | 死亡证明 + 近亲属身份证明 + **亲属关系法定证明** |
| 保险机构 | 保险合同复印件 + 承办人身份证明 + 患者或代理人同意的法定证明 |

**什么时间能办：** 不能出院当天立刻拿到。**病历需要归档**。四川大学华西医院的做法是：**出院 15 天后**到病案科现场复印；也可以**预约登记复印**并留下邮寄地址，病案归档后由医院寄出（[来源](https://www.wchscu.cn/public/hospitalized/371.html)）。

**要钱吗：**

- **《医疗机构病历管理规定（2002 年版）》第十八条明确：「医疗机构复印或者复制病历资料，可以按照规定收取工本费。」** 工本费标准由医院按规定制定并公示，**没有全国统一价**。
- 现场复印通常**按实际复印张数收费**；预约复印因登记时张数未知，有的医院**按住院天数测算的平均张数**预收复印费，快递费另计。
- **复印时要主动告知用途**，医院会默认按「医保报账」类复印（病案首页、出入院证、出院记录、大病历、检查检验、手术麻醉记录、材料合格证、护理体温等），不同用途复印内容不同，**少印了要当场要求补印**——离开窗口后再提可能要走一遍流程。

## 办不成怎么办

### 结算单金额比预期高很多

- 先要**费用总清单**（出院时医院应提供），逐项核对：有没有没做过的项目、有没有重复计费、耗材单价与用量是否吻合
- 找**住院处或医保办**要求逐项解释；有异议要**书面**提出，不要只口头说
- 涉嫌乱收费 → 向医院医务科 / 价格管理科投诉，或打 12345、向当地医保局反映

### 医保登记出了问题 / 结算失败

- 先确认入院时**是否刷了医保登记**（没登记就只能事后手工报销，待遇通常更差）
- 确认是否因**异地就医未备案**导致降比例（见 [4.4 异地就医备案](cross-province-medical-filing.md)）
- 系统故障导致无法直接结算 → 保留全部票据，回参保地手工报销，**备过案的按正常待遇核算**，与非备案不同

### 手工报销被退回

- 常见原因：发票不是原件、缺费用总清单、缺出院小结、超过报销时限
- 补齐后重新提交；**被拒时要求书面告知理由**

### 医院以「医保额度」催出院

- 医保**没有住院天数上限，也没有费用上限**；以此强制患者中途出院本身就是要排查的违规行为
- 要求主治医师**书面说明出院理由**；必要时向医务科、卫健委或医保局反映

## 常见错误

- **以为预交金交得多就报得多** —— 预交金只是押金，和报销比例没有关系
- **从不看一日清单** —— 出院才发现多收的项目，这时举证已经变难
- **自费知情同意书不看就签** —— 签字即认可，事后主张「不知道要自费」很难成立
- **发票原件丢了** —— 医保手工报销、商业保险理赔、单位二次报销，全都需要原件
- **把「个人自付」和「个人自费」混为一谈** —— 算错自己能报多少（区别见 [4.3](medical-insurance-settlement.md)）
- **相信「住院有天数上限／费用上限」** —— 医保没有这两项上限，以此催你出院属于违规行为

## 行动清单

- [ ] 入院时确认**已刷医保登记**（没登记就只能事后手工报销）
- [ ] 住院期间每天看一次**一日清单**
- [ ] 签任何自费同意书前，问清项目名称、单价、是否在医保目录内
- [ ] 出院时索取：**发票原件、费用总清单、出院小结、诊断证明**
- [ ] 结算单上的自付 / 自费金额**自己复算一遍**
- [ ] 出院约 15 天后回医院**复印病历**（商保理赔与复查都要用）
- [ ] 要报商业保险或二次报销的，**先复印留底再交出原件**
