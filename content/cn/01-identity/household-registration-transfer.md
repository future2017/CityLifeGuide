# 户口迁移（本地迁移 / 跨省 / 人才引进）

> ⏱ 本文信息采集于 **2026-09**。落户门槛、材料清单、办理时限各城市不同且常调整，动手前请用文末的「信息核实方式」确认一次。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 户口迁移不是一个动作，是四条路：市内迁移、跨省迁移、人才引进、投靠亲属——门槛依次不同 |
| **要带什么** | 身份证、户口簿、迁入地同意的证明（准迁证或落户资格材料）；投靠类还要亲属关系证明 |
| **去哪办 / 找谁** | 迁入地公安派出所或政务服务网户籍窗口；已开通跨省通办的迁移可「一站式」办，不必回原籍 |
| **多久 / 多少钱** | 跨省通办类当场受理、多地已实现「一站式」；法规未设迁移收费项目，工本费以当地公布为准 |
| **最大的坑** | 先辞工作、先退租、先给孩子转学，再发现落户条件不满足——**先拿到落户资格，再动其他事** |

## 一句话结论

**户口迁移的第一步不是去派出所，是先确认自己在目标城市「有没有资格落户」。**

资格来自四条通道，门槛差别很大：**市内／省内迁移**最简单（换住处即办）；**跨省迁移**技术上已不难（多地实现一站式），难在迁入地是否接收；**人才引进**是门槛最明确的快通道，学历、职称、技能三档对应不同年龄上限；**投靠亲属**门槛固定但容易被忽略（婚龄、年限都有要求）。

而这一切的上位依据，是 2014 年以来的户籍改革分档——**城市越小越松，越大的城市越依赖积分**。

> 落户这件事的顺序很重要：**先够条件，再谈材料**。反过来的顺序，通常意味着白跑三趟。

---

## 先看清道路：四条通道分别适合谁

| 通道 | 适合谁 | 难度 | 主要看什么 |
|---|---|---|---|
| **市内 / 省内迁移** | 在同一城市换住处、跨市县迁到本省另一城市 | 最低 | 合法稳定住所 |
| **跨省迁移** | 有迁入地接收资格、要办跨省手续的人 | 中（手续已简化） | 迁入地是否开具准迁或纳入通办 |
| **人才引进** | 应届毕业生、有学历／职称／技能等级的人 | 中（门槛明确） | 学历、职称、年龄、社保 |
| **投靠亲属** | 夫妻、子女、父母之间 | 中（门槛固定） | 亲属关系 + 年限要求 |

## 落户门槛怎么分档：先判断你所在的城市属于哪一档

这是最关键的一步——**同一个条件，在 300 万人口的城市和 800 万人口的城市，结果完全不同**。

| 城市规模（按城区常住人口） | 政策方向 |
|---|---|
| 城区常住人口 300 万以下 | **全面取消落户限制** |
| 城区常住人口 300 万至 500 万 | **全面放宽落户条件** |
| 城区常住人口 500 万以上的超大特大城市 | **完善积分落户政策，鼓励取消年度落户名额限制** |

上表的依据是 2024 年的《深入实施以人为本的新型城镇化战略五年行动计划》，同一文件还提出「**推行以经常居住地登记户口制度**」——这是户籍改革的方向词，但各地落地进度不一，**不要拿它当作已经能办的政策**。

更早的《国务院关于进一步推进户籍制度改革的意见》（2014 年）确立的框架是：全面放开建制镇和小城市落户限制、有序放开中等城市、合理确定大城市落户条件、严格控制特大城市人口规模。两相对照可以看出十年的变化：**表述从「严格控制」转向「鼓励取消名额限制」**。

## 现有制度：1958 年的条例还在生效

户口登记的基本制度，至今仍由 1958 年的《中华人民共和国户口登记条例》规定：

- 一个公民**在经常居住地登记一处常住户口**；
- 迁出、迁入都要向户口登记机关**申报并办理迁移证件**；
- 户口登记内容需要变更、更正时，应当申报办理。

**一个值得注意的现象**：这部 1958 年的条例**条文至今未作修改**，其中关于农村迁往城市的一些限制性表述仍留在原文里；但实践中，这些内容已被 2014 年以来的户籍改革政策和各城市现行落户条件所取代。

这就是典型的「**条文还活着，适用已经变了**」。办户口时不要去背条例原文的限制性条款——**以迁入地现行政策为准**。

## 先把名词理清：户籍、常住户口、集体户、公共户

这几个词在窗口和文件里来回出现，含义并不相同：

| 名词 | 是什么 | 对你的影响 |
|---|---|---|
| **户籍** | 你在户口登记机关登记的法定身份关系 | 决定你在哪座城市享受户籍人口待遇 |
| **常住户口** | 在经常居住地登记的那一处户口 | 一个公民**同一时间只能登记一处** |
| **家庭户** | 以亲属关系为基础、有独立住所的户口 | 最常见的形态，子女入学等事项通常认可 |
| **集体户** | 单位、学校、人才服务机构设立的集体户口 | **部分事项受限**——例如上海的投靠类规定明确不适用于本市集体户口人员 |
| **社区公共户** | 无自有住房、又无集体户可落时的过渡形态 | 多数城市可作为过渡，住房落实后再迁入家庭户 |

**以上海为例**，立户、分户的顺序是先家庭户、其次单位集体户或部队集体户、最后社区公共户。这个顺序其他城市大体相同——**有房优先落家庭户**，它带来的便利最多。

**一句实话**：如果你是应届生或刚换城市的租房族，落在**集体户或社区公共户**是正常状态，不影响你正常上班、交社保，但办投靠类事项、部分入学事项时会受限。知道这一点，能避免在窗口白排一次队。

---

## 三个手续环节：准迁、迁移、落户

户口迁移看着复杂，其实就是三段手续，顺序是固定的：

| 环节 | 在哪办 | 办什么 |
|---|---|---|
| **① 取得准迁资格** | **迁入地** | 迁入地公安机关审批并出具《准予迁入证明》；人才引进类通常是人社部门批复 + 公安核验 |
| **② 办理户口迁移证** | **迁出地** | 持准予迁入证明回原户籍地开《户口迁移证》。**走跨省通办的由两地公安网上流转，你不用两头跑** |
| **③ 落户登记** | **迁入地** | 持户口迁移证及相关材料到派出所办理落户，打印新户口簿，或落集体户／社区公共户 |

**一个容易吃暗亏的地方**：**《户口迁移证》有有效期**。拿到证之后先看有效期，期限内必须完成落户登记；逾期未落户的，通常需要重新办理迁出，等于白跑一趟。

所以正确的做法是：**第 ① 步批下来之后，再安排第 ② 步的行程**，并且尽量在第 ③ 步之前不要出长差。

---

## 落户之后要接着办的四件事

户口落下不等于事情结束，还有四件事等着你，且多数有办理时限的期待：

1. **换领居民身份证。** 户籍地址变了，旧证上的住址信息就不一致了。异地换领、补领居民身份证本身就要用到本地居住凭证，现在你有了更硬的凭证。多数城市可就近办理。
2. **社保与公积金关系转移。** 跨省换城市的，养老保险、医疗保险关系需要单独办理转移接续（见第 3 部分），公积金同理。这一步和落户是两件事，**户口办好不等于社保自动跟过来**。
3. **随迁家属的登记与证件更新。** 配偶、子女的户口登记、身份证、学籍材料要同步更新，否则入学、就医时会出现「人户不一致」的麻烦。
4. **与原户籍地相关的登记事项。** 驾驶证、机动车登记、职业资格注册等按属地要求的项目，需要确认是否随户籍变化而需要变更。

**顺序建议**：落户 → 换身份证 → 转社保公积金 → 更新家属与车辆学籍类信息。身份证要放在最前面，因为后面几件事大多要用它。

## 需要准备什么

### 通用材料

| 材料 | 说明 |
|---|---|
| 本人居民身份证 | 原件 |
| 户口簿 | 现户籍地的户口簿原件 |
| 迁入地同意的凭据 | 准予迁入证明，或迁入地出具的落户资格材料（人才引进的批复、投靠审批件等） |
| 迁移证件 | 户口迁移证（走「跨省通办」一站式办理的，通常由两地公安网上流转，不需要你自取） |

### 按通道补充

| 通道 | 额外材料 |
|---|---|
| **市内 / 省内迁移** | 合法稳定住所证明（产权证明、租赁备案、单位出具的住宿证明等） |
| **人才引进** | 学历学位证书或职称证书、技能等级证书；与用人单位签订的劳动合同；社保缴纳记录 |
| **夫妻投靠** | 结婚证；部分城市对婚龄有明确年限要求 |
| **子女投靠** | 出生医学证明或亲属关系证明；部分城市要求父母本地户口登记满一定年限 |
| **父母投靠** | 亲属关系证明；年龄条件（各地不同） |

**哪些其实不需要**：不需要户籍地出具的「同意迁出」审批件（迁出手续由两地公安办理）；不需要你自己在两个城市之间送材料（跨省通办已实现网上流转）。

## 去哪里办

| 渠道 | 说明 |
|---|---|
| **迁入地公安派出所** | 主渠道。落户的受理、审核发生在**迁入地**，不是迁出地 |
| **政务服务网 / 公安 App** | 多数城市可在线预约、预审、上传材料；人才引进类常见「全流程网办」 |
| **跨省通办** | 已纳入跨省通办的迁移类型，可在**迁入地一次申请、两地联办** |

**上海的做法值得参考**：当地规定明确，外省市人员落户可以在「**持准予迁入证明、回原籍开户口迁移证**」与「**选择户口迁移『跨省通办』**」之间**二选一**。也就是说——如果你所在城市已经开通跨省通办，回原籍那一趟是可以省掉的。

**办事话术**：进门第一句可以直接问——「**这项迁移现在能不能走跨省通办？**」很多地方的窗口不会主动提，但你一问就知道要不要买回原籍的票。

## 多久办完

| 环节 | 说明 |
|---|---|
| 落户资格审批 | 各城市不同，人才引进多为固定工作日数，投靠类可能按批次审批 |
| 迁出与迁入登记 | 走跨省通办的一站式办理；未开通的需两地分别办理 |
| 省内迁移 | 公安部规范要求省内迁移与已纳入跨省通办的迁移实行**一站式办理** |

**现实提醒**：真正耗时的不是公安手续，是**前面拿资格那一段**（学历认证、社保年限累积、投靠年限）。这些等不了的环节，应该最先启动。

## 费用

| 项目 | 说明 |
|---|---|
| 户口迁移、准予迁入证明、户口迁移证 | 法规未规定收费项目 |
| 户口簿换发、补发 | 部分地区按地方标准收取工本费，以当地公布为准 |

**提醒**：户口迁移本身不属于收费事项。遇到「落户服务费」「加急费」这类名目，先问收据和依据。

## 办不成怎么办

| 卡在哪 | 怎么办 |
|---|---|
| **不满足落户条件** | 别硬报。先判断差在哪一项（学历、社保年限、居住年限），这一项通常只能靠时间累积——把它当成提前一年的计划，而不是当月的任务 |
| **材料在老家、人不回去** | 走跨省通办；确需原件的，多数城市可委托他人代办，需委托书与双方身份证件 |
| **单位不配合出具材料** | 劳动合同、社保记录可通过官方渠道自行查询打印；如单位拒不出具必要证明，可向人社部门反映 |
| **投靠年限不够（如婚龄、父母户口登记年限）** | 这类年限不能补，只能等。先按现有通道办其他事项，不要为了落户做形式上凑年限的操作 |
| **集体户转家庭户受阻** | 家庭户需要合法稳定住所；无自有住房的可先留在单位集体户或社区公共户，住房落实后再迁 |
| **落户后配偶子女随迁被卡** | 多数城市允许配偶及未成年子女随迁，条件与主申请人绑定；确认材料是否需同时提交，避免二次审批 |

## 常见错误

1. **把「落户」和「居住证」当成一回事。** 居住证是在居住地享受公共服务的凭证；落户是取得本地户籍。先有居住年限，才谈得上积分落户——顺序不能反。
2. **先辞工作、先退租、先给孩子转学，再去查落户条件。** 一旦条件不满足，这几件事全部变成沉没成本。**先落户资格，后生活安排。**
3. **背 1958 年条例的限制性条款。** 见上——条文未改但适用已变，以现行政策为准。
4. **以为「人才引进」只看学历。** 多数城市同时看年龄上限、社保状态、劳动合同期限；缺一项就不受理。
5. **跨省迁移自己跑两趟。** 先问能不能走跨省通办，能省一趟差旅。
6. **忽略集体户与家庭户的区别。** 集体户人员通常在投靠类、子女入学等事项上受限（例如上海的投靠规定明确不适用于本市集体户口人员）。

| 事项 | 各地做法 | 来源 |
|---|---|---|
| 落户门槛的分档方向 | **全国**：城区常住人口 300 万以下城市全面取消落户限制；300 万至 500 万城市全面放宽落户条件；500 万以上超大特大城市完善积分落户政策、鼓励取消年度落户名额限制 | 国发〔2024〕17号《深入实施以人为本的新型城镇化战略五年行动计划》 |
| 人才引进入户的条件 | **广州**：博士或高级职称 50 周岁以下、硕士 45 周岁以下、全日制本科并获学士学位或中级职称 40 周岁以下；技术技能人才分档；配偶及未成年子女可随迁；**深圳**：人才引进可走「高效办」全流程网办，无需到公安部门办理准迁、无需回原籍办理迁出 | 穗府办规〔2025〕9号《广州市引进人才入户管理办法》第七条；深圳市人社局 2025-07-03 人才引进入户通知 |
| 投靠类户口迁移的门槛 | **上海**：子女投靠要求父母在本市户口登记满 5 年；夫妻投靠中，支内知青子女婚龄满 5 年、与少数民族或华侨婚龄满 7 年；该规定**不适用于本市集体户口人员** | 《上海市公安局关于执行本市投靠类户口迁移政策的若干规定》（修改决定） |
| 跨省迁移的办理方式 | **全国**：省内迁移与已纳入跨省通办的迁移，实行「一站式」办理；**上海**：外省市人员落户可在「持准予迁入证明回原籍办理户口迁移证」与「选择户口迁移『跨省通办』」之间二选一 | 公通字〔2021〕12号《户口居民身份证管理工作规范（试行）》（第四十二条）；《上海市常住户口管理规定》第三十七条 |
| 户口事项的办理程序 | **上海**：户口事项（立户分户、出生登记、迁移注销恢复、项目变更、证件签发）由《上海市户口事项办理程序规定》统一规定，2024-07-01 施行、有效期至 2029-06-30；本人无法到场时可委托代理人，并可用「随申办」亮证授权 | 《上海市户口事项办理程序规定》 |

## 信息核实方式

| 你想核什么 | 去哪核 |
|---|---|
| 目标城市的落户条件与档位 | 该市「户籍」政策专栏（多在市政府门户网站），或市公安局户政部门官网 |
| 人才引进的具体条件与材料 | 市人力资源和社会保障局官网发布的当年度入户办法与通告 |
| 投靠类政策的年限要求 | 迁入地市公安局户政栏目；必要时直接到派出所窗口问 |
| 是否已开通跨省通办 | 迁入地派出所或政务服务网户籍事项页面最直接 |
| 户口登记的基础制度 | 国家法律法规数据库 `flk.npc.gov.cn` 查《户口登记条例》效力；公安部规范可在中国政府网政策文件库核 |

> **本文不能作为最终依据。** 落户政策是各城市自主事项，调整频繁且常以年度通告形式发布——请以迁入地受理部门的现行口径为准。

## 行动清单

- [ ] 先查清**目标城市的落户档位与条件**，判断自己走哪条通道
- [ ] 差的如果是「年限类」条件（社保、婚龄、居住年限），**把它转成提前一年的计划**
- [ ] 走人才引进的，先确认学历认证、社保状态、劳动合同三项是否齐备
- [ ] 打电话问一句「**能不能走跨省通办**」，省掉回原籍那一趟
- [ ] 材料按「通用 + 通道专属」两张清单各备一份，原件复印件分开装
- [ ] **所有手续办完再安排退租、转学、社保转移等后续动作**
- [ ] 落户后同步办理：身份证换领（地址变更）、社保与公积金关系转移、随迁家属的登记
