# 住院流程：从开住院证到出院

> ⏱ 本文信息采集于 **2026-09**。政策调整频繁，动手前请用文末的「信息核实方式」确认一次。

> 📎 本节讲流程。**账单怎么构成、结算怎么核对、报销出问题找谁，见 [4.9 住院费用与结算](hospitalization-costs-and-settlement.md)。**

## 一句话结论

**住院花钱，钱不是花在「住院」上，而是花在三件可以当场管住的事上：入院当天就刷医保登记、每天看一日清单、签字前看清自费项目。**

三句话记住：

- **住院登记必须在住院期间办**，不能等出院再补。多数医院给的时限是**入院后 3 日内**（各院不同），逾期可能被按自费处理。
- **预交金不是「押金」的概念，也不是全国统一价。** 2025 年 6 月 30 日起，公立医院对医保患者收取的住院预交金**不得超过同病种、同保障类别的个人自付平均水平**——具体金额由每家医院按病种测算后公示，所以隔壁病床交得和你不一样很正常（[来源](http://wsjkw.xingtai.gov.cn/content.php?id=8553)）。
- **真正把预算撑爆的是三样：医用耗材、进口／目录外药品、特需服务。** 这三样都在「自费」一栏，医保一分不报。而它们**都必须在你签字同意后才能用**。

> 「住院超过 15 天医保就不给报了」是**错的**。国家医保局明确：医保从来没有住院天数上限，也没有费用上限，强制患者中途出院本身就是要排查的违规行为（[答记者问](https://www.nhsa.gov.cn/art/2022/12/23/art_105_9915.html)）。

## 从门诊到住院

住院有两条门：**自己走进去的（择期）**和**被推进去的（急诊）**。两条门的钱和节奏完全不同。

### 第一步：拿到「住院证」

门诊医生判断你需要住院，会开一张 **《住院证》（有的医院叫《入院通知单》《住院申请单》）**。这张纸上通常写着：

- **初步诊断**、拟住科室
- **需要缴纳的预交金金额**（部分医院会把金额印在住院证上，见东胜区人民医院的公示流程）
- 联系电话、住院处位置

> 📌 **住院证不等于床位。** 它只说明「医生认为你该住院」，拿到证之后你仍然要去**住院处（入院准备中心）**登记排队。
> 有些医院还要求先建档：首次在该院住院的，需持住院证到挂号室建立门诊大病历；再次住院的，需到病案室调取原病历。

### 择期住院：床位要排队

**床位不是先到先得，是按病情优先级排的。** 这一点必须说清楚，否则你会在等待中反复打电话而无所得。

| 排队顺序 | 谁在前 |
|---|---|
| 最优先 | 急危重症、需要限期手术的（如恶性肿瘤限期手术、急性发作） |
| 其次 | 病情明确、手术指征明确、等待时间长的 |
| 再次 | 可择期、可推迟的（如白内障、部分良性肿物、择期关节置换） |

**实用做法：**

1. 在住院证上留下**能随时接听的手机号**，并在科室护士站/住院处**主动登记**。
2. 直接问医生一句话：「我这个病**大概等多久**？如果一直没床，有没有**加床**或者**日间手术**的路子？」
3. 很多三甲医院有**「预住院」或「入院准备中心」**：先在门诊把术前检查做完，正式入院当天就手术。这能把住院天数压下来，费用和误工都省。
   *这是各地医院的常见做法，不是全国统一制度，办之前问清楚。*

### 急诊直接入院与择期入院的差别

| | 急诊入院 | 择期入院 |
|---|---|---|
| 怎么进 | 急诊科医生评估后开住院证，直接送病房或 ICU | 门诊开住院证 → 住院处排床 → 等通知 |
| 时间 | 通常**当天甚至当时** | 几天到几周不等 |
| 术前检查 | 来不及做完，边治边查 | 一般提前做完（预住院） |
| 家属准备 | 手足无措：证件、钱、陪护都没带 | 可以从容准备材料 |
| 医保登记 | 常见「**先抢救、后补登记**」 | 入院当天办 |
| 费用节奏 | 抢救类项目多，单日费用高 | 相对平稳，术前检查费用先出 |

⚠️ **急诊入院最容易出问题的地方是医保登记。** 人忙着抢救，没人去窗口刷卡，等到出院才发现没登记。**住院第二天就派一个家属去做这件事**，别拖。

## 入院办理与预交金

### 必须带的材料

各家医院清单略有出入，把下面这些全带上，一样不落：

| 类别 | 具体 | 票据原件要求 |
|---|---|---|
| 身份 | **患者本人身份证**（+ 代办人身份证） | 原件 |
| 医保 | **社保卡 / 医保电子凭证**（二者其一，**住院期间反复要用，别收起来**） | 原件 |
| 凭证 | **住院证 / 入院通知单** | 原件 |
| 钱 | 预交金（现金 / 银行卡 / 移动支付，以窗口提示为准） | — |
| 其他 | 既往病历、门诊病历、近期检查报告、影像片子；异地就医者带上**备案凭证** | — |
| 支付 | 出院结算时通常还需**银行卡及持卡人身份证** | 原件 |

**内蒙古医科大学附属医院住院须知列明的出院结算材料（可作为清单模板）：** ① 电子医保凭证或医保卡 ② 所有预缴金凭证 ③ 结算单（护士站出具）④ 诊断书 ⑤ 银行卡及持卡人身份证（[来源](https://www.nmgfy.com/znNews/info/206.html)）。

> ⚠️ **预交金收据（押金条）千万别丢。** 多家医院明确：它是办理退费的**唯一有效凭证**，遗失可能影响退费。

### 预交金交多少：**没有全国统一标准**

**先把 2025 年的新规记住：**

- 自 **2025 年 3 月 31 日**起，公立医疗机构**全面停止收取门诊预交金**；存量门诊预交金须在 **2025 年 12 月 31 日**前完成资金清算、退款。
- 自 **2025 年 6 月 30 日**起，**医保患者住院预交金降至同病种、同保障类别个人自付平均水平**。测算方法是参考该院**同病种前 3 年度实际发生的次均住院费用和个人自付费用**。
- 计算示例（官方口径）：某医院测算城乡居民医保「阑尾切除术」患者过去 3 年平均住院费用 9000 元、医保报销后个人平均自付 3000 元，则该院向此类患者收取的预交金**不得超过 3000 元**。
- 文件同时要求：**原则上医疗机构要在患者出院后 3 个工作日内完成住院费用结算，逐步实现 24 小时内结算**；探索「一站式结算」「床旁结算」「线上结算」。
- 非公立医疗机构**可参照执行**。

**但金额本身各家医院、各个病种都不一样。** 下面是真实公示的一个例子（鄂尔多斯市东胜区人民医院，2025-06-30 起执行，[来源](http://dsqrmyy.cn/h-nd-667.html)）：

| 病种 | 预交金（元） |
|---|---|
| 头位顺产 | 1,000 |
| 支气管肺炎 | 1,500 |
| 早期人工流产 | 1,000 |
| 2 型糖尿病性周围神经病 | 2,000 |
| 细菌性肺炎 | 2,500 |
| 甲状腺肿物 | 2,500 |
| 经选择性剖宫产术的分娩 | 2,500 |
| 急性阑尾炎 | 3,500 |
| 胆囊结石伴胆囊炎 | 3,500 |
| 心力衰竭 | 3,500 |
| 前列腺增生 | 3,500 |
| 胃/直肠肿物 | 3,500 |

**怎么用这张表：** 它只能告诉你**量级**（常见病几千元），**不能当标准**。同一种病在一线城市三甲医院、在县域医院、在自费身份下，预交金可以差好几倍。

**怎么查你自己要交多少：**

1. 打**就医医院住院处 / 医保办**电话，问：「我诊断是 XX，**走医保的话预交金收多少**？」
2. 查医院官网/公众号的**「预交金收费标准公示」**——这是 2025 年政策明确要求的公示项。
3. 已经拿到住院证的，**住院证上往往直接写了金额**。

> 📌 **预交金是「预付」，不是「花掉」。** 出院结算时**多退少补**。费用低于预交金，余额按原支付方式退回；费用超出，结算时补齐。

### 住院期间的补交与退费

- **补交：** 住院期间费用超过预交金，医院会通知补交。可以到住院处「入院窗口」现场补缴，多数医院也支持**微信公众号等线上补缴**（线上补缴通常无纸质押金条，出院时告知工作人员即可）。
- **退费：** 按原支付方式退回。现金支付现场退现金，现金不足时提供患者身份证及银行卡信息，若干工作日内退回账户；非现金支付的退回原支付账户。
- **办理住院后未产生费用的**，持预交金收据原件到入院窗口办理退费。

### 医保登记：**住院时就要刷，不能等出院**

这是整篇最重要的一句话。

**参保患者入院时应主动出示身份证、医保卡或医保电子凭证，办理医保登记，出院时才能直接结算。** 如果因为病情紧急（急诊入院）没来得及登记，可以在**规定时限内补办**。

| 医院 | 医保登记时限 | 逾期后果 |
|---|---|---|
| 内蒙古医科大学附属医院 | **入院后 3 日内**携医保卡、押金票到一站式窗口补办 | 医院须知写明「逾期未办理者，费用自理，医院将不予进行费用报销」 |
| 中山大学附属第三医院岭南医院 | 广州医保、异地医保、省市区属医保：**入院 3 日内**；海珠/越秀/荔湾公医：**入院 5 日内** | 未明示 |

> ⚠️ **「能不能补登记」和「多久内能补」各地各院差别很大，没有全国统一时限。** 上面的 3 日 / 5 日只是两个真实例子。**默认做法是：入院当天就登记，把这件事当成住院的第一项任务。**

**还没办异地就医备案的：** 见本书 4.4 节。备案**可以在出院结算前补办**，别因为「人已经住院了」就放弃。

**登记完成后确认两件事：**

1. **你的医保身份在系统里是「参保」状态**（护士站或住院处可查）。
2. 拿到一张**医保患者住院登记凭证 / 结算单（护士站出具）**，记住存放位置，出院要用。

## 住院期间要盯什么

住院是「按项目计费、实时累积」的，你不看，钱就一直往上走。**下面四件事，每天花 10 分钟就能做完。**

### 一、一日清单：每天都看

**制度依据（全国适用）：**《医疗机构内部价格行为管理规定》（国卫财务发〔2019〕64 号）第十六条要求，医疗机构应当建立**费用清单（含电子清单）制度**，以多种形式向患者提供医疗服务、药品、医用耗材等费用清单，并在患者需要时提供打印服务。清单内容应包括：**名称和编码、单价、计价单位、使用日期、数量、金额**（[来源](http://www.natcm.gov.cn/bangongshi/zhengcewenjian/2020-01-03/12312.html)）。

**在哪看：** 以北京协和医院的制度为例——**住院患者可在病房护士站、住院处窗口查询住院费用日清单及总费用**；结算时应主动提供医疗服务项目、药品、医用耗材等费用清单（[来源](https://www.pumch.cn/detail/14945.html)）。很多医院还提供**自助查询机、医院 APP／公众号**。

**每天看的时候，重点盯三类：**

1. **「自费」或「全自费」标记的行**——这些医保一分不报。
2. **数量对不对**：用了几支药、几卷敷料、几片耗材。数量错了很难追，当天发现当天改。
3. **有没有不该出现的项目**：你没做过的检查、没见过的耗材。国家医保局明令禁止**重复收费、超标准收费、分解项目收费**，以及**串换药品、医用耗材、诊疗项目和服务设施**。

**发现疑问怎么问：** 不要问护士「这钱对不对」。直接说：

> 「这张清单上第 X 项「XXX」，**是哪个医生开的、用在哪一天**？麻烦帮我调一下医嘱。」

医嘱是可追溯的。查不到对应医嘱的收费，你有权要求核实。

### 二、自费项目知情同意书：**签字前必须看清**

**这是你的法定保护，也是唯一能在花钱之前拦住的关口。**

**全国性依据有两层：**

1. **《定点医疗机构医疗保障服务协议范本（2024 版）》第十九条**：除急诊、抢救等特殊情形外，医疗机构提供**医疗保障基金支付范围以外的医药服务**的，**应当经参保人员或其近亲属、监护人签字同意确认**（[来源](https://file.m12333.cn/upfile/download/0c5c9e18-c753-82b3-4f4f-3820cadd2df0.pdf)）。2026 年 9 月，国家医保局已印发 2026 版协议范本，进一步细化了协议处理措施与负面清单（[来源](http://www.nhsa.gov.cn/art/2026/9/14/art_14_22112.html)）。
2. **《医疗机构医用耗材管理办法（试行）》第三十五条**：医疗机构**使用Ⅲ级或植入类医用耗材时，应当签署知情同意书**（[来源](http://www.natcm.gov.cn/bangongshi/zhengcewenjian/2019-06-21/10070.html)）。

**实践中，你要在三种文书上签字：**

| 文书 | 什么时候签 | 你要看什么 |
|---|---|---|
| **自费药品/耗材/诊疗项目/服务设施告知同意书** | 使用前 | **项目名称、单价、使用数量、疗程、预计总费用** |
| **手术同意书** | 术前 | 手术名称、麻醉方式、风险、替代方案 |
| **特殊检查（治疗）同意书 / 输血同意书** | 操作前 | 项目内涵、费用、风险 |

⚠️ **签字前必须问出口的三句话：**

1. 「这个东西**是不是在医保目录里**？如果不在，**一共大概多少钱**？」
2. 「**有没有目录内的替代品**？效果差多少？」
3. 「这个耗材/药**是一次性用到底，还是按天/按次计费**？大概用几次？」

> ⚠️ **集中签字是个危险信号。** 有的医院为了省时间，让患者入院时一次性把所有知情同意文书签完、一个签名拓印到多份文书上。这种做法已被主管部门点名批评为**不合法**（辽宁卫健委《医务人员应知应会法律知识——知情同意电子签名，要方便更要合法》）。**你有权要求逐项说明、逐项签字。**
> 紧急抢救等特殊情形下可以先救治、后补签——这是规则允许的例外，但事后应当补齐。

### 三、药品和耗材在不在医保目录里

**目录规则（全国统一，国家医保局令第 1 号）：**

- **甲类药品**：临床治疗必需、使用广泛、疗效确切、同类中价格较低。**按医保规定的支付标准直接结算。**
- **乙类药品**：可供临床选择使用、疗效确切、同类中价格略高。**先由个人自付一定比例，剩下的再按比例报销。** 这个「先行自付比例」由**省级或统筹地区**确定，所以各地不一样。
- **目录外（俗称丙类／自费）药品**：**全额自费。**

**怎么查（动手前查一次，比问谁都准）：**

1. **国家医保服务平台 APP** → 「药品目录查询」/「医保找药」 → 输入**药品通用名**，能看到是否在目录内、甲类还是乙类、是否属于商保创新药目录（[来源](https://www.nhsa.gov.cn/art/2026/1/5/art_14_19235.html)）。
2. **国家医保局微信公众号** → 公共查询 → 基本医保药品目录。
3. **问医生**：「这个药的**通用名**是什么？在不在医保目录？」

**注意三个坑：**

- **同通用名不同商品名，报销待遇相同。** 目录按**通用名**管理，同一通用名的药自动属于支付范围——所以「进口原研」和「国产仿制」只要通用名一致，制度上都可报，差价主要来自**支付标准**（超出支付标准的部分需自付）。
- **限定支付范围。** 目录内部分药品对适应症、疗程有**医保限定支付条件**，不符合的按自费处理。
- **耗材目录看当地。** 医用耗材的报销范围由**就医地**执行，与药品目录不完全同步。

### 四、医生查房时该问什么

**查房时间很短，问题要提前写在纸上。** 主治医师首次查房记录按规定应当在**患者入院后 48 小时内**完成（《病历书写基本规范》），所以入院头两天是关键窗口。

**建议问这六句：**

1. 「**我的诊断**确定了吗？**依据**是什么？」
2. 「**接下来几天打算做什么**？哪些检查、哪些治疗？」
3. 「**有没有医保目录外的项目**？如果有，大概多少钱？我能不能选目录内的？」
4. 「**预计住多少天、大概花多少**？」
5. 「**手术/操作的风险和替代方案**是什么？不做会怎么样？」
6. 「费用单上第 X 项我不明白，**能不能帮我解释一下**？」

**带家属一起听，并当场记下来**（手机备忘录即可）。查房说的话，如果没写进病程记录，第二天可能就没人记得。

## 办不成怎么办

按发生顺序对号入座。

### 情况 1：预交金不够，被反复催缴费

**这是正常的，不是事故。** 住院费用超过预交金，医院会通知补交。处理方式：

1. **先要清单。** 直接说：「我要看补交金额对应的**费用明细**。」补交前知道钱花在哪，是基本权利。
2. **别只补钱，要问原因。** 如果超支来自某个自费项目，追问：「这个项目**后续还要用多久**？总共大概多少钱？」避免一次次被动补交。
3. **付不出全款时，主动谈，不要躲。** 到住院处/医务科说明情况，问三件事：能不能**降低预交金标准**（对已按病种公示的医保患者，医院本就不该超收）？能不能**分期或延后到出院结算**？有没有**医疗救助**衔接？
4. **脱贫人口有「先诊疗后付费」政策**（预交金通知第四条明确要求严格执行）。
5. ⚠️ **拖欠医疗费会影响出院手续和病历材料的领取。** 但医院**不能**因为欠费就扣留你依法应当拿到的病历复制件——遇到这种情况走医院医务科和当地卫健委投诉。

### 情况 2：医保登记没办 / 办不了 / 登记后刷不出来

**排查顺序：**

1. **是不是超了本院登记时限**（多数医院 3 日内）→ 立刻去医保办/住院处说明，请求补办。
2. **社保卡故障**：过期未换、已挂失、欠费欠缴被封锁 → 出示**医保电子凭证**（跨省异地就医**必须**用医保电子凭证）或先解决参保状态。
3. **异地就医备案有效期没覆盖整个住院时间段** → 补办或延长备案（见 4.4）。
4. **这家医院没开通跨省异地联网结算** → 只能先自费、后手工报销。
5. **系统故障** → 让医院医保办协助，或拨 `区号+12393` 报障。

**最终兜底：先自费结算出院，再补办备案，回参保地手工报销**（多地明确允许，如云浮市云安区医保提示：「参保人员自费结算出院的，可补办备案登记手续后，按参保地规定申请医保手工报销」）。

⚠️ **注意两个坑：** ① **发票原件只有一份**，垫付后务必保管好。② **手工报销有申请时限**（上海为开具收据之日起 6 个月内），**别拖**。

### 情况 3：医院要你出院 / 要你转院

**先分清是谁的决定。**

**如果是医院以「医保额度用完」「住院天数到了」为由要求你出院或自费住院：**

- 这是**违规**。国家医保局在《关于全面排查并取消医保不合理限制的通知》中明确要排查「**导致推诿病人、分解住院**」「对患者住院天数作出具体限制」等做法，并指出**绝大多数情况下当地医保部门并无此类规定**（[答记者问](https://www.nhsa.gov.cn/art/2022/12/23/art_105_9915.html)）。
- 《定点医疗机构医疗保障服务协议范本》第十八条也明确：**不得以医保支付、管理政策为由推诿拒收参保患者**，**不得要求未达到出院标准的参保人员提前出院或自费住院**，**不得以病组和病种费用限额为由要求患者院外购买或自备药品、医用耗材，要求患者出院或减少必要的医疗服务**。
- **怎么办：** 要求医生把「建议出院」的理由写进病历；直接问「**按诊疗规范，我的出院标准是什么，我达到了吗**」；如确属违规，向医院医务科、当地卫健委、`12393` 逐级反映。

**如果确实需要转院：**

- 医保协议要求医院为符合规定的参保患者提供**转诊转院服务**。请医院开具**转诊转院证明**并盖章。
- **跨省转院要办备案**，多数地区转诊备案的报销比例比「非急诊未转诊」高（见 4.4）。
- **市内住院一般不需要转诊手续**，可以直接去定点医院住院（深圳明确：本市参保人在市内定点医疗机构产生的住院合规医疗费用，直接由统筹基金按比例支付，不需要办理转诊）。
- ⚠️ **转院是「出院 + 再入院」，会产生新的起付线。** 如果当地按「年度内第几次住院」递减起付线，第二次的起付线会低一些，但**仍然要交**。转院前先问清楚。

### 情况 4：你自己要求出院（自动出院 / 患者要求出院）

**你可以要求出院，但后果必须知道。**

- **病历上会记为「非医嘱离院」。** 国家医保结算清单的「离院方式」字段分四类：**1. 医嘱离院 2. 医嘱转院、转社区、转卫生院 3. 非医嘱离院 4. 死亡**。你自己要求走的，属于**非医嘱离院**。
- **医院一般会让你签《自动出院（拒绝继续治疗）知情同意书》或《劝阻无效离院告知书》**，写明已告知风险和后果、医院不承担责任。**签之前读完**，不要当形式。
- **结算清单还有一个字段：「是否有出院 31 天内再住院计划」。** 提前出院再短期入院，会被系统记录——这也是医保识别「分解住院」的抓手。
- **医保不会因为你提前出院就拒付已经发生的费用**（按实际发生的合规费用结算）；但**未完成治疗的中断由你自己承担医疗风险**。研究显示自动出院患者 **30 天内再住院的概率更高**。
- **实务建议：** 如果只是对费用或方案不满，**先谈，不要走**。要求与主管医生、科主任沟通，必要时找医务科。**走之前一定要拿到**出院小结、费用清单、发票，否则后续报销和复诊都会更麻烦。

### 情况 5：结算时发现金额对不上

1. **当场别签字。** 要求在窗口调取费用明细。
2. **按「四、费用构成拆解」的分类逐项核对**，重点是「卫生材料费」和「西药费」。
3. **向医院物价/财务部门提出书面核对请求**（保留提交时间证据）。
4. **医院不解决 → 参保地医保局 `12393` / 当地卫健委**。医保部门明确禁止**重复收费、超标准收费、分解项目收费**。
5. **已经结清后才发现问题的**：先保存全部票据原件——**一旦用于报销，原件就交出去了**，所以先复印留底。

## 常见错误

1. **等出院时才想起用医保。** → 住院登记**住院期间就要办**，多数医院 3 日内，逾期可能按自费处理。
2. **不知道预交金是「多退少补」的预付金，以为交了就花了。** → 出院结算多退少补，**押金条要留好**。
3. **照搬别人说的预交金金额。** → 金额**按病种、医院、保障类别**测算公示，**没有全国统一数**。
4. **一日清单从来不看，出院才发现一堆自费。** → 每天 10 分钟，重点看「自费」行和数量。
5. **在自费项目知情同意书上直接签。** → 签字前必问三句：**在不在目录内 / 一共多少钱 / 有没有替代**。
6. **以为「住院超过 15 天医保就不给报」。** → 医保**没有住院天数上限**；以天数逼出院是违规的。
7. **发票原件随手花掉 / 只拿到复印件。** → 手工报销多数地区要求**原件**；要报商保的，先确认能否接受盖章复印件或电子票据。
8. **出院当天就想拿病历复印件。** → 病历要归档，通常**出院后若干天**（如华西为 15 天后）才能复印。
9. **以为大病保险要单独去申请。** → 多数地区**不用申请、不用额外缴费**，系统自动算；但「年度事后报销」型的要**保留票据原件**。
10. **医院让去院外自购耗材/药品，就自认倒霉。** → 因医院配备原因要求院外购买自备药品、耗材的，**原则上应计入医院医保总额**；这是有明文规定的。
11. **被要求「先出院再入院」以便继续报销。** → 这叫**分解住院**，是明确的违规行为，不要配合。

## 各地差异

> 📌 本节是**跨地区横向对照**的样板，与第 12 部分「城市差异」的格式一致。
> **凡涉及金额、比例、时限的，一律以你就医医院和参保地的口径为准，不要用本文数字去争论。**

| 事项 | 各地做法 | 来源 |
|---|---|---|
| **住院预交金标准** | 全国统一原则：医保患者不高于「同病种同保障类别个人自付平均水平」（2025-06-30 起）。**具体金额由各医院按病种测算公示**，例：东胜区人民医院头位顺产 1000 元、急性阑尾炎 3500 元、心力衰竭 3500 元 | 国家卫健委等 6 部门通知；东胜区人民医院公示 |
| **门诊预交金** | 全国统一：2025-03-31 起全面停收；存量须于 2025-12-31 前清算退款 | 同上 |
| **医保登记时限** | 内蒙古医科大学附属医院：入院 3 日内补办，**逾期写「费用自理」**；中山三院岭南医院：广州/异地/省市区属医保 **3 日内**，海珠/越秀/荔湾公医 **5 日内** | 各院官网 |
| **住院费用结算时限** | 全国要求：原则上**出院后 3 个工作日内**完成结算，逐步实现**24 小时内**；探索一站式/床旁/线上结算 | 国家卫健委等 6 部门通知 |
| **普通床位费** | 实行**政府指导价**。重庆三级医院 47 元/日、二级 31 元/日、一级 19 元/日 | 重庆市医保局 |
| **特需床位费** | 实行**市场调节价**，医院自主定价并报医保部门备案；床位数不超过登记总床位的 **10%**；**不纳入基本医保支付**（个人账户除外） | 岳阳价格通知；山东省 2026 年特需医疗意见 |
| **乙类先行自付比例** | 由**省级或统筹地区**确定，各地不同 | 《基本医疗保险用药管理暂行办法》 |
| **大病保险起付线** | 铜陵 1.7 万元；武汉 1.2 万元（2020）；北京 3.0404 万元（2020） | 各地医保局 |
| **大病保险结算方式** | 多数地区**一站式自动结算**；北京居民大病保险为**年度事后报销**（次年报上年度） | 北京东城区 |
| **手工报销申请时限** | 上海：开具收据之日起 **6 个月内**；其他地区规定不同 | 上海一网通办 |
| **病历复印费用与等待时间** | 无全国统一定价，由医院按规定收取工本费并公示。华西医院：出院 15 天后现场复印，可预约登记邮寄 | 《医疗机构病历管理规定》；华西医院 |
| **「麻醉费」是否单列** | 国家结算清单的收费分类中**未单列**麻醉费（并入手术类申报）；但**医院自己的费用清单通常单列** | 医疗保障基金结算清单 |
| **市内住院是否需要转诊** | 深圳明确：**不需要**，直接按比例结算 | 深圳市卫健委 |

## 信息核实方式

政策会变，各家医院的做法差异也大。**动手前用下面任一条路核实，比信任何一篇攻略（包括本文）都可靠：**

1. **就医医院的医保办 / 住院处**（最直接）——问三件事：预交金多少、医保登记时限多久、自费项目怎么签。
2. **就医医院官网 / 官方公众号** —— 搜「**预交金收费标准公示**」「**入院须知**」「**住院指南**」「**病历复印须知**」。2025 年新政要求公示预交金病种标准，这一项现在通常能直接查到。
3. **医保服务热线 `区号+12393`** —— 全国医疗保障服务热线。可问：住院报销比例、起付线、大病保险标准、手工报销时限与材料。
4. **国家医保服务平台 APP** https://fuwu.nhsa.gov.cn —— 查医保药品目录、医用耗材目录、异地联网定点医药机构、结算记录、费用明细。
5. **参保地医保局官网 / 公众号** —— 起付线、报销比例、大病保险、手工报销材料清单的**唯一权威来源**。
6. **当地卫健委** —— 病历复制、医疗收费、医患纠纷的投诉与主管部门。

## 行动清单

**入院前**

- [ ] 确认住院证上的**科室、诊断、预交金金额**
- [ ] 打电话给住院处问清：**预交金多少、医保登记时限多久**
- [ ] 准备：身份证、社保卡、**医保电子凭证（提前激活）**、住院证、既往病历与检查报告
- [ ] 异地就医的，先做**异地就医备案**（见 4.4），确认备案有效期覆盖整个住院时间段
- [ ] 带够预交金，并留出后续补交的余量

**入院当天**

- [ ] 到住院处办入院登记，**缴预交金，保管好押金条**
- [ ] **当场刷医保卡 / 医保电子凭证做医保登记**——这一步绝对不能拖
- [ ] 确认系统里你的医保身份是「参保」状态
- [ ] 拿到护士站出具的**结算单/登记凭证**，记住放哪

**住院期间（每天）**

- [ ] 看**一日清单**，重点看「自费」行和数量
- [ ] 任何**自费项目、自费药品、自费耗材**，**签字前问清三句**：在不在目录内／一共多少钱／有没有替代
- [ ] 手术/特殊检查前，看清**手术同意书、麻醉同意书、耗材知情同意书**
- [ ] 主动问查房医生六句话，**当场记录**
- [ ] 每天把花掉的钱记一笔（手机备忘录即可）

**出院当天**

- [ ] 办出院结算，核对**金额合计、个人自付、个人自费**三项
- [ ] 确认**本年度第几次住院**对应的起付线算对了
- [ ] 把**发票原件、费用总清单、出院小结、诊断证明、医保结算单**全部收齐
- [ ] 需要病历复印件的，当场**登记预约**，问清费用和领取时间
- [ ] 确认**大病保险是否已自动结算**，结算单上看得到对应行

**出院后**

- [ ] 7 日内核对一次全部材料，缺的补
- [ ] 要报商业保险的，**先复印留底再交出原件**
- [ ] 需要二次报销 / 大病保险 / 医疗救助的，见 **4.10**
- [ ] 保存本次全部材料至少 **2 年**（商保、工伤、纠纷都可能用到）
