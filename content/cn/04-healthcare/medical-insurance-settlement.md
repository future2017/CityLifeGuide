# 医保结算流程与自费部分

> ⏱ 本文信息采集于 **2026-11**。政策调整频繁，动手前请用文末的「信息核实方式」确认一次。

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 医保按目录筛、扣乙类自付、扣起付线、乘比例、撞封顶线；目录外一分不报 |
| **要带什么** | 医保电子凭证或社保卡；出院留好发票、费用清单/结算单、出院记录 |
| **去哪办 / 找谁** | 门诊挂号缴费窗口、住院收费处当场结算；对账找医院医保办 |
| **多久 / 多少钱** | 挂号与出院均即时结算，不必先垫全款；自己付自付＋自费两笔 |
| **最大的坑** | 把个人自费当个人自付：前者在目录外，医保不报、个人账户也不能付 |

## 一句话结论

**医保不是「花多少报多少」。** 一笔费用进结算，先按三大目录筛一遍：目录外的一分不报；目录内的先扣乙类先行自付，再扣起付线，剩下的乘报销比例，最后撞年度封顶线。决定你掏多少的是四件事：目录外项目多少、起付线、报销比例、封顶线。

这个口径已经写进法律。《中华人民共和国医疗保障法》第十三条：参保人发生的符合药品、医用耗材、医疗服务项目等目录的医药费用，以及法律规定或国务院确定的其他费用，按规定从基金支付；待遇标准由省级医保、财政部门确定。该法 2026-08-28 通过，**2027-01-01 施行**。

**本文只回答两件事：结算怎么算、自费从哪来。** 门诊慢特病待遇与个人账户共济见 4.4。

## 适用情形

| 你的情况 | 走哪条结算 | 结算前先确认 |
|---|---|---|
| 职工医保，普通门诊 | 定点医院挂号、缴费窗口刷码，即时结算 | 门诊起付线按年度累计；年度限额可能分在职、退休 |
| 居民医保，普通门诊 | 到本人选定的门诊统筹定点机构 | 多数地区「单定点」，非定点可能整单不报 |
| 拿处方去定点药店买药 | 药店刷码，走门诊统筹或个人账户 | 该店是否开通门诊统筹、按几级机构比例报 |
| 住院 | 入院登记医保身份，出院时一次结算 | 先看目录外项目占比，再看起付线与比例 |
| 已认定门诊慢特病 | 挂号时主动告知，待遇与就诊卡绑定 | 没绑定会按普通门诊结算（见 4.4） |
| 跨省或跨市就医 | 先备案，在联网定点机构直接结算 | 就医地目录、参保地政策（见 4.5） |

## 需要准备什么

| 材料 | 什么时候用 | 注意 |
|---|---|---|
| 医保电子凭证或社保卡 | 挂号、缴费、出院结算 | **身份证不能用于医保结算**；电子凭证全国通用，刷码即可 |
| 入院登记时的医保身份 | 办理住院第一天 | 没登记，整次住院可能被记为自费 |
| 医疗收费票据（发票） | 出院时领取 | 商业保险、单位二次报销要用原件 |
| 住院费用清单、医保结算单 | 出院时领取 | 核对下面「结算单四行」那一节 |
| 出院记录、诊断证明 | 出院时领取 | 手工报销、复诊要用 |
| 异地就医备案记录 | 异地结算前 | 没备案可能不能直接结算，比例也可能降 |

## 去哪里办

### 门诊：三句话

1. **挂号时**说「我有医保」，用医保电子凭证或社保卡挂号。用身份证或自费卡挂号，这笔费用很可能整单变成自费。
2. **医生开药、开检查时**问一句：「这些在目录内吗？是甲类还是乙类？有没有目录外的？」医生一般能答，也可以自己查（见「信息核实方式」）。
3. **缴费时**出示凭证，系统即时结算，你只付个人自付和个人自费两笔，发票与清单会分开列。

### 住院：出院结算四步

1. **入院登记**：办住院时出示医保电子凭证或社保卡登记医保身份。没登记，整次住院可能按自费处理。
2. **住院期间**：医院每天给费用清单。逐日看，看到疑似自费项目（进口耗材、自费药、特需服务）当场问护士站或医保办。**这时改还来得及，出院后再改很麻烦。**
3. **出院结算**：到住院收费处办理，很多医院已支持病区内一站式结算。系统自动完成目录筛选、扣乙类自付、扣起付线、按比例计算、比对封顶线，只收你应付的部分。
4. **拿凭证**：医疗收费票据、住院费用清单或医保结算单、出院记录或诊断证明。三样都留好。

### 对账找医保办，不找收费窗口

收费窗口只负责收钱，解释待遇口径的是医院**医保办**（也叫医保科、医保管理处）。数字对不上、某笔被记为自费、怀疑算错，都去医保办复核；医院解决不了，拨 `区号+12393`，或找参保地医保经办机构。需要回参保地手工报销的（未备案、系统故障、非联网机构），材料交经办机构，也可通过国家医保服务平台或当地 APP 线上提交。

## 多久办完

- **门诊挂号、缴费**：当场结算。
- **出院结算**：出院当天在收费处或病区办完，多数医院当场出结算单。
- **退费改医保**：当天找收费处办，退掉自费单用医保凭证重结；跨天或已离院通常改不了。
- **医保办复核**：当场能查系统，涉及目录争议要调明细，按医院告知的时限等。
- **手工报销**：回参保地办理，受理时限、到账时间各地不同，以经办机构告知为准。

## 费用

### 三大目录：医保只对目录内负责

报销范围实行**目录管理**：目录内由基金和个人按比例分担，目录外基金一律不予支付。三份目录合称医保「三目录」（[国家医保局](https://www.nhsa.gov.cn/art/2024/10/21/art_52_14344.html)）。

| 目录 | 管什么 | 谁定、多久调整 |
|---|---|---|
| **药品目录** | 西药、中成药、协议期内谈判药品、中药饮片 | 国家统一制定、动态调整，**原则上每年调整一次**；省级可按权限增补民族药、医疗机构制剂、中药饮片 |
| **诊疗项目目录**（医疗服务项目） | 挂号、检查、检验、手术、治疗等项目 | 国家定准入与管理政策、划定不予支付和部分支付范围，**具体目录原则上由省级确定**；国家正分批制定全国目录，首批 13 类，先用于跨省异地就医结算 |
| **医用耗材目录** | 一次性医用材料、支架、人工关节、起搏器等 | 国家定政策（医保发〔2023〕23号），**省级按准入法建立本省目录**，动态调整 |

> 💡 甲乙分类是目录内的费用分类，不是医院等级。

### 甲乙分类：决定有没有「先行自付」

《基本医疗保险用药管理暂行办法》第二十四条、第二十五条：

| 类别 | 含义 | 你要承担什么 |
|---|---|---|
| **甲类** | 临床治疗必需、使用广泛、疗效确切、同类中价格较低的药品 | 直接按参保地比例结算，**没有先行自付** |
| **乙类** | 可供临床选择、疗效确切、同类中比甲类价格略高的药品；**协议期内谈判药品纳入乙类管理** | 先由个人自付一定比例（比例由省级或统筹地区定），余额再按比例报 |
| **目录外** | 不在目录内（滋补类、保健药品、预防性疫苗、主要起美容减肥增强性功能等作用的药品，按办法第八条不纳入） | **全自费，医保不报** |

**诊疗项目**国家层面采用「**排除法**」：只列「不予支付」和「支付部分费用」两张清单，各省可增补不予支付项目、**不得删减**。部分统筹地区在本地目录里写「甲类项目/乙类项目」，含义一样。规则仍以劳社部发〔1999〕22号为依据，国家医保局 2026-05-28 的解读确认该文仍在适用；国家正分批制定统一的服务项目目录，出台后暂不强制全国立即施行，先从跨省异地就医结算用起。

### 明确不报的典型项目

劳社部发〔1999〕22号附件列的全国口径清单：

- 挂号费、院外会诊费、病历工本费、出诊费、检查治疗加急费、点名手术附加费、自请特别护士等特需医疗服务
- 美容、健美、非功能性整容、矫形、减肥增胖增高、健康体检、预防保健性诊疗
- 就（转）诊交通费、急救车费、空调费、电视费、电话费、陪护费、护工费、洗理费、门诊煎药费、膳食费、文娱活动费
- **超标准床位费**：实际床位费高于当地支付标准，超出部分由个人自付

两处要留意：22号文把「各种不育（孕）症的诊疗项目」列为不予支付，但**自 2025-01-01 起，31 个省份及新疆生产建设兵团均已将适宜的辅助生殖项目纳入医保**，属后续国家统一调整；各地对清单也有增补。

**基金整体不予支付的六类情形**（《国家医疗保障待遇清单（2020 年版）》）：应当从工伤保险基金支付的；应当由第三人负担的；应当由公共卫生负担的；在境外就医的；体育健身、养生保健消费、健康体检；国家规定的其他情形。肿瘤人群筛查属公共卫生范畴，也不走医保。

### 门诊：先有门诊统筹，才有得报

门诊共济改革后，普通门诊费用由统筹基金报销，不再只靠个人账户。国家底线是：**普通门诊统筹覆盖职工医保全体参保人员，政策范围内支付比例从 50% 起步**，待遇可向退休人员倾斜，起付标准和最高支付限额由各地测算（国办发〔2021〕14号）。居民医保门诊统筹的支付比例**不低于 50%**（医保发〔2021〕5号）。

三个要自己确认的点：

1. **起付线与年度限额**：差别极大。武汉职工门诊起付 0 元、年限额在职 3500 元；北京职工门诊起付 1800 元，但上不封顶。
2. **要不要选定点**：职工普通门诊在统筹区内定点机构一般直接刷卡，不要求提前选定点；居民门诊统筹在很多地方是「**单定点**」——须选一家社区卫生服务机构或乡镇卫生院。济南就是如此，2026 年度变更登记只在 1 月 1 日至 31 日办，且 1 月已在原定点发生门诊统筹费用的不能变更。
3. **药店能不能报**：国办发〔2021〕14号要求把符合条件的定点零售药店用药保障纳入门诊保障，支持外配处方在定点药店结算。武汉明确定点零售药店的门诊统筹报销比例按**一级医疗机构**执行；开通与否看参保地。

### 起付线、比例、封顶线：三个闸门

三者**串联**工作，不是各算各的。东城区医保局对起付线的定义是：*参保人员在享受医疗费用报销之前需要自己先行支付的费用额度*。

```
医疗总费用
  ├─ 目录外部分 ──────────────────────────→ 全自费（医保 0 报销）
  └─ 目录内部分（政策范围内费用）
        ├─ 乙类先行自付部分 ──────────────→ 个人自付
        └─ 剩余部分
              ├─ 起付线以内 ──────────────→ 个人自付
              └─ 起付线以上
                    ├─ 按比例报销 ────────→ 医保统筹支付
                    ├─ 按比例自付 ────────→ 个人自付
                    └─ 超过封顶线部分 ────→ 个人自付
```

1. **起付线**：线以下全自付。门诊和住院**按年度分别设置、单独累计**。
2. **报销比例**：起付线以上的目录内费用按比例由统筹基金支付。比例与医院级别、参保类型、在职或退休、费用分段都有关。
3. **封顶线**（最高支付限额）：一个年度内统筹基金最多报多少，超出部分不管，可走大病保险、补充医疗等第二重保障。

> ⚠️ **这三个数没有全国统一值**，由参保地定。下面的数字只是有官方来源的地区示例，不要照搬。

### 两组官方数字

**北京**（[市医保局待遇表](https://ybj.beijing.gov.cn/2020_zwfw/2020_bmcx/202004/t20200409_1798870.html)、[首都之窗政策问答](https://www.beijing.gov.cn/zhengce/zcjd/zcwd/tzylbx)）

- 职工门诊：起付在职 1800 元、退休 1300 元；2 万元以下在职医院 70%、社区 90%，退休医院 85%（70 岁以上 90%）、社区 90%；2 万元以上在职 60%、退休 80%
- **2023-01-01 起不再设职工门诊最高支付限额**，原来一年 2 万元封顶，2 万元以上上不封顶
- 职工住院：起付本年度第一次 1300 元、第二次及以后每次 650 元；比例按费用段与医院级别从 85% 到 99.1%；住院封顶 50 万元
- 居民医保：门诊起付 100 元（一级）/550 元（二级），报 55%/50%，门诊封顶 5000 元；住院起付 300/800/1300 元，报 80%/70%/75%–78%，住院封顶 25 万元

- 职工门诊统筹起付 **0 元**；一级机构在职 85%、二级 65%、三级 55%；退休 90%/75%/65%；年限额在职 3500 元、退休 4500 元
- 职工住院起付：三级 800 元、二级 600 元、一级 400 元、社区卫生服务中心 200 元；同年度两次以上住院**减半**（社区除外）

### 结算单上的四行

| 结算单上的词 | 含义 |
|---|---|
| **医疗费总额** | 这次一共花了多少 |
| **医保统筹基金支付** | 医保实际替你付的钱，这才是真正的「报销额」 |
| **个人自付** | 目录内、按规则由你承担的部分 |
| **个人自费** | 目录外、你全额承担的部分 |

**校验公式：医疗费总额 = 统筹基金支付 + 个人自付 + 个人自费。** 对不上就当场要求医保办解释。

三个必须知道的机制：

- **乙类先行自付单独一笔**，先扣再乘比例。武汉：乙类药品和乙类诊疗项目个人先付 10%，余额走正常比例。
- **起付线按次、按年度**。北京本年度第一次住院 1300 元，第二次及以后每次 650 元；武汉同年度两次以上住院减半。
- **封顶线可能含个人自付**。武汉「年度限额 24 万元（含统筹基金支付和个人自付）」——它不是你实际能报 24 万。

### 算例：5 万元住院费逐项拆解

设定：武汉市职工医保在职、三级医院住院、本年度第一次住院，起付线 800 元、比例 86%、乙类先行自付 10%，未触及年度限额，不考虑大病保险。**目录外与乙类金额是假设值，真实数值看费用清单。**

| 项目 | 金额 | 说明 |
|---|---|---|
| **A. 医疗费总额** | **50,000 元** | 医院开的账 |
| **B. 目录外费用** | **6,000 元** | 进口耗材、目录外自费药、超标准床位费、特需服务 |
| **C. 目录内费用（政策范围内）** | **44,000 元** | A − B |
| **D. 其中属于乙类的部分** | **20,000 元** | 乙类药品 + 乙类诊疗项目 |
| **E. 乙类先行自付 = D × 10%** | **2,000 元** | ① 个人自付 |
| **F. 进入统筹计算的费用 = C − E** | **42,000 元** | |
| **G. 起付线** | **800 元** | ② 个人自付 |
| **H. 可报销基数 = F − G** | **41,200 元** | 起付线以上、封顶线以下 |
| **I. 医保统筹基金支付 = H × 86%** | **35,432 元** | 医保真金白银付的 |
| **J. 按比例自付 = H × 14%** | **5,768 元** | ③ 个人自付 |
| **K. 个人自付合计 = E+G+J** | **8,568 元** | 目录内你承担的部分 |
| **L. 个人自费 = B** | **6,000 元** | 目录外，一分不报 |
| **M. 你实际要掏的钱 = K+L** | **14,568 元** | |

**校验**：35,432 + 8,568 + 6,000 = 50,000 ✅

两个口径的「报销比例」别混：

- **按总额算**：35,432 ÷ 50,000 = **70.9%**，这是你的体感
- **按政策范围内费用算**：35,432 ÷ 44,000 = **80.5%**，这是医保局宣传常用的口径

差额全来自那 6,000 元目录外费用。同样 5 万元，目录外涨到 15,000 元，你掏的钱会明显增加——**这就是盯费用清单的意义。**

### 个人自付与个人自费

| | **个人自付** | **个人自费** |
|---|---|---|
| **在不在目录内** | **在**（目录范围内） | **不在**（目录范围外） |
| **医保管不管** | 管，是按规则算给你的份额 | 完全不管，基金不予支付 |
| **具体包括什么** | 起付线以下、乙类先行自付、按比例自付、封顶线以上、目录内超限价部分 | 目录外药品、诊疗项目、耗材，非疾病治疗项目、特需服务 |
| **能不能用个人账户付** | **可以**，余额不足再用现金补 | **不可以**，只能自掏现金或移动支付 |
| **对报销的提示** | 免不了，属制度设计 | **这是信号：能少用就少用** |

三地官方口径几乎一致：

- **深圳**：个人自付指「在医保目录范围内，按规定需要由参保人个人负担的医疗费金额。（包括起付线以下、乙类先行自付、按比例自付、封顶线以上、目录范围内超限价部分等，这部分费用可由医保个人账户内的余额进行支付，不够的部分再用现金等方式支付。）」；个人自费指「在医保目录范围外的药品、诊疗项目等，由参保人员全额支付」（[来源](http://hsa.sz.gov.cn/gkmlpt/content/11/11952/post_11952753.html)）
- **黑龙江**：「个人自付款可先由医保个人账户内的余额进行支付，不够的部分再用现金等方式支付」；「个人自费指在医保范围外的药品、项目等，由参保人员全额支付，**不能使用医保卡个人账户的资金支付**」（[来源](https://ybj.hlj.gov.cn/ybj/ybrd/202408/c00_31758259.shtml)）
- **福建**：「个人自付：参保人发生的属于基本医疗保险目录范围内的医疗费用，扣除基本医疗保险、补充医疗保险和医疗救助等报销后由个人支付的部分」（[来源](http://www.fujian.gov.cn/hdjl/hdjlzsk/sybj/dybz/202301/t20230109_6088720.htm)）

**记住这三条：**

1. **自付＝目录内、医保帮忙算过账；自费＝目录外、医保一分不出。**
2. 唯一能用个人账户余额支付的是**个人自付**，不是个人自费。拿个人账户在药店买目录外商品，是个人账户支付范围问题，与「个人自费」是两回事。
3. 看到「自费」就多问一句：「这个必须自费吗？有没有目录内的替代？」进口耗材、进口原研药、高价自费药问过之后往往有替代。

## 办不成怎么办

**情况 1：结算时刷不出医保。** 按顺序查：参保状态是否正常（断缴、未申报、漏缴最常见）；机构是否定点、是否开通对应结算（异地看有没有联网）；介质是否用错（必须电子凭证或社保卡）；门诊慢特病待遇是否没绑定；都不对就是系统故障，找医保办或拨 `区号+12393`。

**情况 2：已经自费挂号、自费缴费。** 部分医院支持退费改医保：当天找收费处，退掉自费单用医保凭证重结。**跨天或已离院通常改不了**，所以第一句话就要说「我有医保」。

**情况 3：出院时某笔费用被记为自费。** 趁没离院，在收费处或医保办要求核对：该项目是否真不在目录内、能否用目录内产品替代。离院后再追讨成本极高。

**情况 4：报销比例比预期低很多。** 先看结算单上「个人自费」的金额，多数情况是目录外占比高，不是算错了。若自费很小、比例仍很低，再核对：本年度是否还没过起付线；是否已用掉部分年度限额；是否去了更高级别医院；是否属于同年度第二次住院。

**情况 5：怀疑算错要申诉。** 要费用明细清单逐项核对；找医保办复核；无果拨 `区号+12393` 或 12345；保留发票、费用清单、结算单、病历、出院小结原件。

## 常见错误

1. **把个人自付和个人自费当一回事。** 自付是目录内该你承担的，自费是目录外完全不管，后者连个人账户都不能用。
2. **以为「报销比例 86%」就是总费用的 86%。** 比例只作用于目录内、扣完乙类先行自付和起付线之后的金额，还受封顶线限制。
3. **以为目录外的钱也能用个人账户付。** 不能，个人账户只解决目录内的个人负担部分。
4. **以为参保了看病就一定能报。** 起付线以内不报；居民门诊在非定点机构可能完全不报。
5. **用身份证挂号就诊。** 结算必须用医保电子凭证或社保卡。
6. **住院期间不看费用清单。** 目录外费用是「能少用就少用」的，出院才发现就晚了。
7. **把「年度限额」当成「能报这么多」。** 有的地方限额含个人自付，实际到手的报销额更低。
8. **照搬网上的比例数字。** 起付线、比例、封顶线全部由参保地定，一城一策。

## 信息核实方式

政策会变。动手前用下面任一条路核实，比信任何一篇攻略（包括本文）可靠：

1. **打 12393**：全国医保服务热线。拨 `参保地区号+12393`，由对应统筹地区经办机构接听；直接拨 12393 也可按语音提示选参保地。部分地区与 12345 双号并行。
2. **国家医保服务平台** https://fuwu.nhsa.gov.cn ：查参保状态、全国经办机构电话、异地联网定点医药机构、备案记录、直接结算费用明细。
3. **查某个药在不在目录内**：国家医保服务平台 APP →「药品分类与代码」；「国家医保局」微信公众号 → 医保服务 →「国家医保药品目录查询」，输入药名可看是否在目录内、药品分类和甲乙类别。直达入口 https://wx.nhsa.gov.cn/#/pages/NRDL/index/index 。
4. **查诊疗项目、耗材在不在目录内**：国家层面没有统一的公众查询入口，查参保省、市医保局官网发布的诊疗项目目录、耗材目录及解读，或直接问医院医保办。
5. **查本地待遇口径**：起付线、报销比例、封顶线、门诊年度限额只在参保地权威。参保地医保局官网、公众号，或打 12393 问一句，比通用攻略准。
