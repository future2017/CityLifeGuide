# 住院流程：从开住院证到入院登记

> ⏱ 本文信息采集于 **2026-11**。政策调整频繁，动手前请用文末的「信息核实方式」确认一次。

> 📎 本节只讲「拿到住院证到住进病房」这一段：排队等床、带什么材料、交多少预交金、怎么把医保登记办成。**住院期间每天该盯什么、出院怎么走，见 [4.10 住院期间与出院](hospitalization-stay-and-discharge.md)；账单怎么构成、结算怎么核对，见 [4.11 住院费用与结算](hospitalization-costs-and-settlement.md)。**

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 入院只有五件事：拿住院证、到住院处登记排床、带齐证件、交预交金、入院当天办医保登记 |
| **要带什么** | 身份证、社保卡或医保电子凭证、住院证、既往病历与检查报告；异地就医还要带备案凭证 |
| **去哪办 / 找谁** | 就诊医院住院处（不少医院叫入院准备中心）；问事找医院医保办或区号+12393 |
| **多久 / 多少钱** | 排床几天到几周；预交金按病种公示，常见病几千元；登记当天办完 |
| **最大的坑** | 医保登记必须在住院期间当场办，多数医院限入院 3 日内，逾期可能被按自费处理 |

## 一句话结论

住院这一步最容易白花钱的地方不在治疗，而在**手续**：医保登记没在住院期间办成、预交金按自费身份交、排床时没问清要等多久。这三件事都在你手里，都能在入院当天办完。

三句话记住：

- **住院证不等于床位。** 它只说明医生认为你该住院，之后还要到住院处登记排队；床位按病情优先级排，不是先到先得。
- **预交金是预付，不是花掉。** 2025 年 6 月 30 日起，医保患者的住院预交金不得超过同病种、同保障类别的个人自付平均水平；具体金额由每家医院按病种测算后公示，全国没有统一数字（[国卫办财务发〔2025〕5号](https://www.gov.cn/zhengce/zhengceku/202503/content_7016268.htm)）。
- **医保登记必须在住院期间办。** 多数医院给的时限是入院后 3 日内，逾期可能按自费处理。人送来抢救、家属手忙脚乱时，最容易漏掉的就是这一步。

> 「住院超过 15 天医保就不给报了」是错的。国家医保局明确：医保从来没有住院天数上限，也没有费用上限，以天数逼患者出院本身就是被要求排查的违规行为（[答记者问](https://www.nhsa.gov.cn/art/2022/12/23/art_109_9914.html)）。

## 适用情形

同一个「住院」，三种人的手续完全不同，先对号：

**择期住院（自己走进去的）。** 门诊看完、医生开住院证、回家等床位。手续最从容，也最容易拖——只拿着住院证回家等电话、没去住院处登记，床永远排不到你。

**急诊住院（被推进去的）。** 急诊科医生评估后直接开住院证、送病房或 ICU，通常当天甚至当时入院。材料往往没带齐，医保登记也常常来不及，属于「先抢救、后补登记」，但家属必须在第二天补上。

**异地就医或自费就医。** 异地就医的，入院前先确认备案是否有效、是否覆盖整个住院时间段（见 [4.5 异地就医备案](cross-province-medical-filing.md)）；备案可以在出院结算前补办。自费就医的，预交金按医院对自费人员的规定交，通常高于医保患者；登记环节可以省，材料一样要带。

急诊与择期的差别，一张表看清：

| | 急诊入院 | 择期入院 |
|---|---|---|
| 怎么进 | 急诊医生评估后开住院证，直接送病房或 ICU | 门诊开住院证 → 住院处排床 → 等通知 |
| 时间 | 通常**当天甚至当时** | 几天到几周不等 |
| 术前检查 | 来不及做完，边治边查 | 一般提前做完（预住院） |
| 家属准备 | 证件、钱、陪护都没带 | 可以从容准备 |
| 医保登记 | 常见「**先抢救、后补登记**」 | 入院当天办 |

⚠️ **急诊入院最容易出问题的地方就是医保登记。** 人忙着抢救，没人去窗口刷卡，等到出院才发现没登记。**住院第二天就派一个家属专门去做这件事**，别拖。

## 需要准备什么

### 住院证上通常写着什么

一张《住院证》（有的医院叫《入院通知单》《住院申请单》）通常写着：**初步诊断、拟住科室、需要缴纳的预交金金额**（部分医院直接把金额印在证上）、联系电话、住院处位置。

📌 **有些医院还要求先建档：** 首次在该院住院的，需持住院证到挂号室建立门诊大病历；再次住院的，需到病案室调取原病历。建档窗口和住院处常不在同一层，问一句能省一趟。

各家医院清单略有出入，把下面这些一次带齐，别指望回一趟家：

| 类别 | 具体 | 票据原件要求 |
|---|---|---|
| 身份 | **患者本人身份证**（+ 代办人身份证） | 原件 |
| 医保 | **社保卡 / 医保电子凭证**（二者其一，住院期间反复要用，别收起来） | 原件 |
| 凭证 | **住院证 / 入院通知单** | 原件 |
| 钱 | 预交金（现金 / 银行卡 / 移动支付，以窗口提示为准） | — |
| 其他 | 既往病历、门诊病历、近期检查报告、影像片子；异地就医者带**备案凭证** | — |
| 支付 | 出院结算时通常还需**银行卡及持卡人身份证** | 原件 |

**医保电子凭证要提前激活。** 跨省异地就医结算必须用医保电子凭证，社保卡不行；临时在医院激活，往往卡在人脸识别或密码上。出发前在国家医保服务平台 APP 里试一次。

**押金条（预交金收据）千万别丢。** 多家医院明确：它是办理退费的唯一有效凭证，遗失可能影响退费。

**这些其实不用带：** 单位介绍信、亲属关系证明（患者本人办理时）、纸质照片。住院登记只认身份证、社保卡或医保电子凭证、住院证这三样。

## 去哪里办

- **住院处 / 入院准备中心**：办入院登记、缴预交金、刷医保登记。把这三件事放在一个窗口的医院越来越多，一次能办完。
- **科室护士站**：床位、陪护、探视、每日费用清单都在这里问。
- **医院医保办**：登记失败、异地结算报错、结算单看不懂，都归它管。
- **电话**：就医医院住院处（官网「入院须知」页通常有号码）、医保服务热线 `区号+12393`。

**办事话术**（三句话问完，别客套）：

1. 「我诊断是 XX，走医保的话预交金收多少？」
2. 「医保登记要在入院后几天内办？超了怎么补？」
3. 「我这个病现在排床大概等多久？有没有预住院或者日间手术的路子？」

## 多久办完

**排床没有统一时限。** 床位按病情优先级排：

| 排队顺序 | 谁在前 |
|---|---|
| 最优先 | 急危重症、需要限期手术的（如恶性肿瘤限期手术、急性发作） |
| 其次 | 病情明确、手术指征明确、等待时间已经较长的 |
| 再次 | 可择期、可推迟的（如白内障、部分良性肿物、择期关节置换） |

等一两周很常见，等一个月也不稀奇。**别只打电话催**——到科室护士站和住院处各登记一次，留一个随时能接听的号码。

**登记本身当天办完。** 交材料、缴预交金、刷医保卡，通常半小时到一小时。

**医保登记时限由医院定。** 内蒙古医科大学附属医院要求入院 3 日内携医保卡、押金票到一站式窗口补办，逾期写明「费用自理」；河北霸州的规定是 48 小时内办理入院登记。全国没有统一时限，按你就医医院的规定办。

**结算时限是全国要求。** 原则上医疗机构应在患者出院后 3 个工作日内完成住院费用结算，逐步实现 24 小时内结算——这是 2025 年预交金新规同步提的要求（[通知](https://www.gov.cn/zhengce/zhengceku/202503/content_7016268.htm)）。

## 费用

**预交金金额：全国没有统一标准，只有统一上限。**

- 自 **2025 年 3 月 31 日**起，公立医疗机构全面停止收取**门诊**预交金，存量资金在 **2025 年 12 月 31 日**前完成清算退款。例外是急诊、急诊留观、门诊手术、急诊手术以及老年人等确有预交资金需求的群体——在患者自愿前提下可以保留，但要报属地卫生健康部门备案。门诊窗口还跟你要预交金的，问一句「属于哪种例外、备案了吗」。
- 自 **2025 年 6 月 30 日**起，**医保患者住院预交金降至同病种、同保障类别个人自付平均水平**。测算依据是该院同病种前 3 年度实际发生的次均住院费用和个人自付费用。
- 官方算例：某院测算城乡居民医保「阑尾切除术」患者过去 3 年平均住院费用 9000 元、报销后个人平均自付 3000 元，则该院向这类患者收取的预交金不得超过 3000 元。
- 非公立医疗机构**可参照执行**。

**具体金额看医院公示。** 以鄂尔多斯市东胜区人民医院 2025 年 6 月 30 日起执行的公示为例（[来源](http://dsqrmyy.cn/h-nd-667.html)）：

| 病种 | 预交金（元） |
|---|---|
| 头位顺产 | 1,000 |
| 支气管肺炎 | 1,500 |
| 早期人工流产 | 1,000 |
| 2 型糖尿病性周围神经病 | 2,000 |
| 细菌性肺炎 | 2,500 |
| 甲状腺肿物 | 2,500 |
| 经选择性剖宫产术的分娩 | 2,500 |
| 急性阑尾炎 | 3,500 |
| 胆囊结石伴胆囊炎 | 3,500 |
| 心力衰竭 | 3,500 |
| 前列腺增生 | 3,500 |
| 胃/直肠肿物 | 3,500 |

这张表只能告诉你**量级**（常见病几千元），不能当标准：同一种病在一线城市三甲、在县域医院、在自费身份下，预交金可以差好几倍。

**预交金是预付，不是花掉。** 出院结算多退少补：费用低于预交金，余额按原支付方式退回；费用超出，结算时补齐。住院期间超支，医院会通知补交，可以到住院处现场补，多数医院也支持公众号线上补缴（线上补缴通常没有纸质押金条，出院时告知工作人员即可）。办了住院没产生费用的，持预交金收据原件到入院窗口退费。

**真正的成本在别处。** 预交金只是入场券，账单里最贵的三项是医用耗材、目录外药品、特需服务，医保一分不报——这部分见 [4.11 住院费用与结算](hospitalization-costs-and-settlement.md)。

## 办不成怎么办

### 情况 1：一直没床位，等不下去

1. **先确认自己排在哪一档。** 直接问主管医生：「我这个病属于限期还是可择期？大概等多久？」排队不是黑箱，医生说得出来。
2. **问替代路径**：有没有加床、日间手术、预住院（先在门诊把术前检查做完，正式入院当天就手术）。预住院能压缩住院天数，费用和误工都省，但这是各地医院的常见做法，不是全国统一制度，办之前问清楚。
3. **换一家同级医院。** 同级医院之间排床时间差别很大。带上检查资料去另一家门诊重新评估，往往比在原医院干等快。

### 情况 2：预交金不够，被反复催缴

**这是正常现象，不是事故。** 住院费用按项目实时累积，超过预交金医院就会通知补交。处理方式：

1. **先要清单。** 直接说：「我要看补交金额对应的**费用明细**。」补交前知道钱花在哪，是基本权利。
2. **问清是不是自费项目在推高。** 如果是，追问后续还要用多久、总共大概多少钱，避免一次次被动补交。
3. **付不出全款时主动谈，不要躲。** 到住院处或医务科说明情况，问三件事：能不能按病种公示标准降低预交金（医保患者本就不该超收）、能不能延后到出院一并结算、有没有医疗救助衔接。
4. **脱贫人口有「先诊疗后付费」政策**，预交金通知第四条明确要求严格执行。
5. ⚠️ 拖欠医疗费会影响出院手续，但医院**不能**因此扣留你依法应得的病历复制件——遇到扣留，走医院医务科和当地卫健委投诉。

### 情况 3：医保登记办不了、刷不出来

按这个顺序排查，别在窗口反复刷同一张卡：

1. **是不是超了本院登记时限**（多数医院 3 日内）→ 立刻去医保办说明，请求补办。
2. **社保卡故障**（过期未换、已挂失、欠费欠缴被封锁）→ 改用医保电子凭证，或先解决参保状态。
3. **异地就医备案有效期没覆盖整个住院时间段** → 补办或延长备案（见 4.5）。
4. **这家医院没开通跨省异地联网结算** → 只能先自费、后手工报销。出发前在国家医保服务平台 APP 查「异地联网定点医药机构」。
5. **系统故障** → 让医院医保办协助报障。深圳的规定是：因系统故障、社保卡损坏或补办、无法出示医保电子凭证等原因不能直接结算的，可自出院之日起 3 年内到定点医疗机构办理补记账（深医保规〔2023〕7号第十三条）。

**兜底：先自费结算出院，再补办备案，回参保地手工报销。** 多地明确允许。两个坑：① 发票原件只有一份，垫付后务必保管好；② 手工报销有申请时限（上海为开具收据之日起 6 个月内），别拖。

## 常见错误

1. **拿着住院证就回家等电话。** → 必须到住院处登记，留能随时接听的号码，并主动问排在哪一档。
2. **等出院时才想起用医保。** → 登记要在住院期间办，多数医院 3 日内，逾期可能按自费处理。
3. **以为预交金是押金、交了就拿不回。** → 多退少补，押金条务必留好。
4. **照搬别人说的预交金金额。** → 按病种、医院、保障类别测算公示，没有全国统一数。
5. **第一次住院不带既往病历和影像片子。** → 重复检查既花钱又拖时间。
6. **急诊入院后没人管医保登记。** → 第二天派一个家属专门去办，写进分工。
7. **以为社保卡能搞定跨省结算。** → 跨省异地就医结算要用医保电子凭证，提前激活。
8. **在门诊窗口被收预交金就交。** → 2025 年 3 月 31 日起门诊预交金已停收，只有急诊、门诊手术、老年人等例外情形，且需备案。

> 📌 本节是**跨地区横向对照**的样本，与第 12 部分「城市差异」格式一致。**凡涉及金额、时限的，一律以你就医医院和参保地口径为准，不要用本文数字去争论。**

| 事项 | 各地做法 | 来源 |
|---|---|---|
| **住院预交金上限** | 全国：医保患者不高于同病种同保障类别个人自付平均水平，2025-06-30 起执行。鄂尔多斯市东胜区：头位顺产 1000 元、急性阑尾炎 3500 元、心力衰竭 3500 元 | 国卫办财务发〔2025〕5号；东胜区人民医院公示 |

## 信息核实方式

1. **就医医院住院处 / 医保办**（最直接）：问预交金多少、登记时限多久、异地能不能直接结算。
2. **医院官网与公众号**：搜「预交金收费标准公示」「入院须知」「住院指南」。2025 年政策明确要求公示病种预交金标准，这一项现在通常能直接查到。
3. **医保服务热线 `区号+12393`**：问参保状态、报销待遇、手工报销材料与时限。
4. **国家医保服务平台 APP**（https://fuwu.nhsa.gov.cn ）：查异地联网定点医药机构、参保状态、结算记录。
5. **参保地医保局官网**：异地就医备案规则、报销比例、手工报销时限的唯一权威来源。
6. **当地卫健委**：拒收病人、以天数逼出院、违规收费的投诉主管部门。

## 行动清单

**入院前**

- [ ] 确认住院证上的**科室、诊断、预交金金额**
- [ ] 打电话问住院处：**预交金多少、医保登记时限多久、要排多久**
- [ ] 准备：身份证、社保卡、**医保电子凭证（提前激活）**、住院证、既往病历与检查报告
- [ ] 异地就医的，先做**异地就医备案**（见 4.5），确认有效期覆盖整个住院时间段
- [ ] 带够预交金，并留出后续补交的余量

**入院当天**

- [ ] 到住院处办入院登记，**缴预交金，保管好押金条**
- [ ] **当场刷医保卡或医保电子凭证做医保登记**——这一步绝对不能拖
- [ ] 确认系统里你的医保身份是「参保」状态
- [ ] 拿到护士站出具的**结算单或登记凭证**，记住放哪
- [ ] 问清床位医师、责任护士是谁，把手机号存下来
