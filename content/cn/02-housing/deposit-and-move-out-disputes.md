# 押金退还与退租纠纷

> ⏱ 本文信息采集于 **2026-11**。法律与地方细则会变，动手前请用文末的「信息核实方式」确认一次。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 押金不是定金；除欠租、欠费和你造成的实际损坏外，房东应退；不退就书面催告、调解、起诉 |
| **要带什么** | 合同、押金收据或转账记录、退租交接单、带时间的照片视频、水电燃气结清凭证、催告记录 |
| **去哪办 / 找谁** | 先协商；再拨 `12345` 转住建或街道调解；租赁企业违规找住建，消费欺诈找 `12315`；最后去房屋所在地法院 |
| **多久 / 多少钱** | 协商 1–2 周，调解 2–4 周，小额诉讼 2 个月（可延 1 个月）；1 万元以下受理费 50 元，简易程序减半 |
| **最大的坑** | 退租时没做交接清单和带时间水印的视频，事后说不清房屋原状，举证吃亏 |

## 一句话结论

**押金是履约担保，不是定金：退租时，除了你欠的租金、水电物业等费用，以及你确实造成、且有证据证明的损坏，房东都应当退还；合同没约定、也没有实际损失的项目，不能扣。**

不退的正确顺序是：**固定证据 → 书面催告 → 12345/住建/街道调解 → 支付令或小额诉讼 → 申请执行**。不要一开始就报警或起诉，也不要把「押金不退」当成理所当然。

---

## 适用情形

### 1. 合同到期，正常退租

房东应验收、结清费用、退还押金。合同约定的退还时间优先；没约定的，应在合理期限内退还，实践中多为退租后 3–15 日，各地习惯不同。

### 2. 提前退租

定期合同未到期，你单方搬走原则上构成违约。合同常约定「提前 30 天通知」或「押金不退」。注意三点：

- 押金不退条款可能被认定为违约金。明显高于房东实际损失（空置期租金、找房成本）的，可请求法院适当减少（《民法典》第 585 条；司法解释以超过损失 30% 作为「一般可认定过分高于」的参考）。
- 房东有减损义务，应及时再出租，不能一边空置一边让你承担全部剩余租期租金（《民法典》第 591 条）。
- 你协助找下家、经房东书面同意转租，能显著减少争议（《民法典》第 716 条）。

### 3. 房东先违约，或房子不能正常住

房屋危及安全健康（《民法典》第 731 条）、被查封或权属有争议或违反使用条件（第 724 条）的，你可以解除合同并要求退还押金、赔偿损失。房东以断水断电、换锁等方式逼迁的（《住房租赁条例》第 12 条禁止暴力、威胁或其他非法方式；北京、上海条例明确禁止断水断电），可以要求继续履行、赔偿损失；致使不能实现合同目的的，可以解除。

### 4. 合租、转租、二房东

你的合同相对方是跟你签字的人。押金向谁交就向谁要；二房东跑路，原则上向二房东主张。原房东是否承担责任，要看其是否同意转租：知道或者应当知道转租，但在 6 个月内未提出异议的，视为同意（《民法典》第 718 条）。签约前看原房东的书面同意和原合同剩余租期。

### 5. 住房租赁企业、长租公寓

《住房租赁条例》第 10 条、第 19 条对租赁企业另有押金和资金监管要求；北京、上海还有押金托管、监管账户细则。企业不退押金，除民事诉讼外，还可向住建部门投诉其违反押金托管、资金监管规定。

### 不适用本文的情形

公租房、保障性租赁住房、单位宿舍、宅基地房屋另有规定；本文以城镇国有土地上的市场租赁住房为主（《住房租赁条例》第 2 条）。

## 需要准备什么

### 一、签约和入住时就要留的

- **书面合同**：写明押金金额、支付方式、退还时间、可扣减情形。未采用书面形式且无法确定租赁期限的，视为不定期租赁（《民法典》第 707 条），押金条款也难证明。
- **押金凭证**：转账记录（备注「押金」）最稳；现金支付必须让房东写收据并签名。
- **房东身份**：姓名、身份证号、电话；房产证或不动产权证；二房东还要看转租授权。起诉要有「明确的被告」。
- **入住交接清单**：家具家电逐项列数量、品牌、状态；水电燃气表读数；墙面、地板、门窗的原有瑕疵拍照。双方签字，各执一份。
- **入住视频**：从门牌号开始，一镜到底拍全屋，重点拍已有划痕、污渍。

### 二、退租前 7–15 天要准备的

合同、押金收据或转账记录、身份证；退租交接单（打印两份）；最近一期水电燃气、物业、供暖缴费凭证；钥匙、门禁卡、遥控器数量清单；与房东的聊天记录、通话录音、书面通知。

### 三、其实不需要的

- 不需要把租赁合同公证。公证只在担心证据灭失、需要做证据保全时才有必要。
- 不需要房东身份证复印件才能起诉，但起诉状要写清被告姓名、住址、联系方式；能拿到身份证号更好。
- 不需要「押金收据」原件，转账记录、合同、聊天记录可以互相印证；但有收据更省事。

## 退租前的准备：通知、验收、结清

### 提前通知期

- **合同有约定，从约定。** 常见是提前 30 天书面通知；北京条例还要求合同写明「解除合同的合理告知期限」（《北京市住房租赁条例》第 14 条）。
- **合同没约定**：定期租赁提前退租，应给房东合理准备时间，并承担违约责任；不定期租赁可随时解除，但应在合理期限前通知（《民法典》第 730 条）。
- **通知要留痕**：微信发文字（别只发语音），同时用 EMS 寄《退租通知》，面单「内件品名」写清楚，保留面单和签收记录。只口头说「我下个月搬」，等于没通知。
- **写明三件事**：解除日期、交房时间、要求到场验收。可以加一句「逾期不到场，我将录像并请物业或居委会见证交接」。

### 验收怎么做

1. 约房东本人或书面授权的代理人；中介在场可以，但不能代替房东签字。
2. 按入住交接单逐项核对，家电当场通电试机，水龙头、马桶、下水、门窗都试。
3. 对瑕疵当场分类：**正常使用痕迹**、**你造成的损坏**、**入住时就有的旧瑕疵**。三类都写进交接单，附照片。
4. 房东提出扣款，要求他当场写明**项目、金额、依据、凭证**；写不清的，不签字确认。
5. 交接单最后写清：交房日期、表读数、钥匙数量、押金总额、扣除金额、**应退金额、退还日期、收款账户**。

### 结清费用

- 水电燃气：抄表拍照，结清到交房日，保留缴费截图或发票。
- 物业费、供暖费：按合同约定由谁承担；你承担的，留结清证明。
- 宽带、有线电视、垃圾清运：能过户的过户，不能过户的销户并留凭证。
- **不要把钱转给房东「代缴」却不留凭证**，宁可自己缴。

## 正常损耗与人为损坏

《民法典》第 710 条是核心：**按照约定的方法或者根据租赁物的性质使用，致使租赁物受到损耗的，不承担赔偿责任。** 第 733 条又规定，返还时房屋应符合「按照约定或者根据租赁物的性质使用后的状态」。房子住久了自然会旧，这部分不该你赔。

| 通常算正常损耗（不赔） | 通常算人为损坏（可赔） |
|---|---|
| 墙面自然泛黄、轻微污渍、细小裂纹 | 烟头烫痕、大面积涂鸦、打孔未修补 |
| 木地板轻微磨损、局部起翘（非泡水） | 泡水导致地板大面积变形、发霉 |
| 家具正常使用痕迹、轻微松动 | 家具断裂、缺失、宠物抓咬 |
| 家电自然老化、性能下降 | 违规使用导致烧毁、进水 |
| 窗帘、沙发套自然褪色 | 撕裂、染色、烟味难以去除 |
| 卫生间正常水垢 | 人为堵塞、砸裂瓷砖 |

判断要点：

- **看入住时的状态。** 入住照片、视频能证明「原来就有」，这是最有力的抗辩。
- **看使用方式。** 第 711 条：未按约定方法或者未根据房屋性质使用，造成损失的，才承担赔偿。
- **赔偿按修复费用或折旧价**，不是按全新价。房东不能借机翻新。
- **自然老化、原有瑕疵、房屋质量问题**，属于房东维修义务范围（第 712 条，合同另有约定的除外），不能从押金里扣。

## 押金扣减的合法边界

### 可以扣的

1. **欠缴租金**：有合同和转账记录能对账的未付租金。
2. **你实际承担但未缴的费用**：水电燃气、物业、供暖等，以账单为准。
3. **你造成的实际损坏**：有交接单、照片、维修发票或报价证明，且金额合理。
4. **合同明确约定的违约金**：但应区分违约金和损失赔偿，不能对同一件事重复扣。

### 不能扣的

- **把「押金不退」当作无条件没收。** 押金不是定金，不适用「给付方违约就无权要求返还」的定金罚则（《民法典》第 586–588 条只规定定金）。合同写「提前退租押金不退」，通常要按违约金规则审查，过分高于损失的可以请求减少。反过来说，只有合同明确写的是「定金」，才可能适用定金规则。
- **没有合同依据的清洁费、消毒费、管理费、折旧费。** 合同没约定、也没有实际发生的，不能扣。
- **正常损耗**（见上一节）。
- **房东本应承担的维修费**（第 712 条）。
- **重复计算**：既扣一个月违约金，又把同一笔损失从押金里再扣一次。
- **「墙面脏了」就全屋粉刷**：只有实际污损且无法局部修复的部分，才谈得上赔偿。

### 扣减要同时满足三个条件

房东扣钱，至少要同时满足：**合同有约定 + 有实际损失 + 有证据**。缺一项，你都可以要求退还。对方拒绝提供明细和凭证的，在催告和诉讼中明确写「不认可该扣款，要求你举证」。

### 利息

押金被无理占用，可以主张**资金占用损失**，通常按一年期 LPR 计算，从约定退还日届满之次日起算。金额不大，但写进诉求可表明态度，也方便调解让步。

## 退租当天检查清单

- [ ] 提前 3 天书面确认交房时间，要求房东本人或授权代理人到场
- [ ] 带齐合同、押金凭证、身份证、交接单两份、钥匙和门禁卡
- [ ] 进门先拍**门牌号、楼栋单元、当天日期**，再一镜到底拍全屋
- [ ] 逐间拍墙面、地面、天花板、门窗、家具、家电（通电试机）、厨卫、阳台
- [ ] 拍水电燃气表读数，当场结清并留缴费截图
- [ ] 核对入住清单，缺失或损坏当场写明；旧瑕疵注明「入住时已有」
- [ ] 清点钥匙、门禁卡、遥控器数量，当面交接
- [ ] 交接单写明押金总额、扣除项目及金额、应退金额、退还日期、账户
- [ ] 双方签字，各执一份；房东拒签的，录像说明并请物业或居委会见证
- [ ] 当天发微信总结：「今日已交房，押金 X 元，约定 X 月 X 日前退还」，请对方回复确认
- [ ] **钱未到账前，不签「押金已结清、双方再无争议」**
- [ ] 视频和照片备份到云端，原始文件不要删

**拍摄要点**：一镜到底比一堆截图有用；画面里要有能识别房屋的元素（门牌、窗外地标、独特家具）；用手机自带的时间水印，或拍摄时口述日期。不要只拍局部特写，否则说不清是哪个房间。

## 催告话术（可直接复制）

### 微信或短信版（第一次催告）

> X 先生/女士：我是 XX 小区 X 栋 X 单元 X 室的原承租人 XXX。我们已于 2026 年 X 月 X 日终止租赁合同并完成交接，房屋及物品状况见双方交接单和当日视频。按合同第 X 条，你应于 X 月 X 日前退还押金 XXXX 元。你提出扣除 XX 元，但未提供合同依据和费用凭证，我不认可。请于 X 月 X 日前将剩余 XXXX 元退至（账户信息）。逾期我将向 12345、街道人民调解委员会反映，并依法向房屋所在地法院申请支付令或提起诉讼，相关诉讼费、利息由你承担。请书面回复。

### 第二次催告（逾期 7–15 天后）

> X 先生/女士：关于 X 室押金 XXXX 元，我已于 X 月 X 日、X 月 X 日两次催告，你至今未退还，也未提供扣款凭证。现再次通知：请于 X 月 X 日前全额退还。逾期我将直接向 XX 区人民法院起诉，并主张自 X 月 X 日起按 LPR 计算的资金占用损失及诉讼费。为避免双方成本增加，建议你先退还无争议部分。

**注意**：

- 只讲事实、金额、期限、下一步，不骂人、不威胁人身安全。
- 每一次催告都保留原始聊天记录；电话催告可以录音（自己参与的通话，录音一般可作为证据）。
- 用 EMS 寄《押金退还催告函》时，面单「内件品名」写「押金退还催告函」，保留面单、寄件人存联和签收记录。对方拒收也算送达痕迹。

## 去哪里办 / 找谁

押金纠纷没有「一个窗口办完」的地方，按成本从低到高选：

| 渠道 | 能做什么 | 边界 |
|---|---|---|
| 与房东协商 | 最快、成本最低；可谈分期、先退无争议部分 | 没有强制力 |
| `12345` 政务服务便民热线 | 转办住建、街道、市场监管等部门；留下工单号 | 不裁决民事纠纷，只能协调转办 |
| 住建部门（住建委/房管局） | 管住房租赁企业、中介、租赁备案、押金托管和资金监管；可调解 | 对个人房东的押金争议，多数只能调解，不能强制退款 |
| `12315` | 受理消费者为生活消费需要与**经营者**发生的争议 | 个人房东通常不是经营者，押金纠纷多不属受理范围；租赁企业虚假房源、乱收费、霸王条款可以试 |
| 居委会/街道人民调解委员会 | 免费调解，熟悉本地情况；调解协议可申请司法确认 | 一方不同意就调不成；协议本身不能直接强制执行 |
| 人民法院 | 支付令、小额诉讼、简易或普通程序；判决后可执行 | 要交诉讼费、跑流程、耗时间 |
| `12348` | 免费法律咨询；符合条件可申请法律援助 | 押金纠纷通常不在法律援助法定事项清单内，以当地审查为准 |
| `110` | 房东暴力、威胁、非法侵入、故意毁坏财物、换锁断水电时报警 | 押金本身是民事纠纷，警察一般不介入 |

**顺序建议**：先协商并留痕 → 12345、住建或街道调解 → 支付令或起诉。不要一上来就起诉，也不要只打电话不留证据。

## 多久办完

| 途径 | 大致时间 |
|---|---|
| 合同约定的退还期 | 常见退租后 3–15 日；北京租赁企业自返还住房后 3 个工作日内提出退还意见 |
| 协商 | 1–2 周 |
| 12345 转办或住建协调 | 一般 7–15 个工作日，各地不同 |
| 人民调解 | 2–4 周，视双方配合程度 |
| 支付令 | 受理 5 日内通知，15 日内发出，债务人 15 日内提异议；顺利约 1 个月 |
| 小额诉讼 | 立案 7 日内；审限 2 个月，可延 1 个月；一审终审 |
| 简易程序 | 3 个月，可延 1 个月 |
| 普通程序 | 6 个月，可延 6 个月 |
| 强制执行 | 立案后一般 6 个月内执结；无财产会「终本」，发现财产可恢复 |

## 费用

| 项目 | 费用 |
|---|---|
| 协商、12345、人民调解、12348 咨询 | 免费 |
| 小额诉讼或简易程序案件受理费 | 标的 1 万元以下每件 50 元，简易程序减半交纳，多为 25 元 |
| 1–10 万元部分 | 按 2.5% 分段累计，例如标的 2 万元受理费 300 元，减半 150 元 |
| 支付令申请费 | 比照财产案件受理费的 1/3，标的 1 万元以下约 17 元 |
| 执行申请费 | 执行后交纳，1 万元以下 50 元，一般由被执行人负担 |
| 财产保全费 | 1 万元标的约 120 元，另需提供担保 |
| 公证、EMS、打印、交通 | 几十到几百元；证据保全公证几百到上千元 |
| 律师费 | 几千元起；押金金额小的通常不划算，先打 12348 咨询 |

**算一笔账**：押金 6,000 元，小额诉讼受理费 25 元，跑两趟也远低于放弃。真正贵的是时间。

## 办不成怎么办

### 情况 1：房东不到场验收、拒收钥匙

不要直接把钥匙放屋里走人。做法：

1. 书面通知交房时间和地点，写明「逾期不到场将录像并请物业或居委会见证」。
2. 到期仍不到场：全程录像，拍门牌、屋内现状、表读数；请物业或居委会工作人员在场见证，并在交接单上签字。
3. 钥匙可当面交给见证人转交，或用 EMS 寄给房东，面单写「房屋钥匙 X 把」，保留寄送记录。
4. 金额较大或担心对方事后否认，可到公证处做**证据保全公证**。

### 情况 2：房东拒退、少退、拉黑

1. 发第一次催告（微信加短信），给 7–15 天期限。
2. 逾期发第二次催告，明确将起诉并主张利息、诉讼费。
3. 同时向 12345 反映，要求转住建或街道调解，记下工单号。
4. 仍不退，进入支付令或诉讼。

### 情况 3：投诉不受理

- 12345 只转办、不裁决；要求给工单号和承办单位，方便后续跟进。
- 12315 以「不是生活消费」或「不属于市场监管职责」不予受理的，不要纠缠，转人民调解或法院。
- 住建部门对个人房东只能调解的，要求出具调解记录；调解不成不影响你起诉。

### 情况 4：调解失败

- 有书面调解协议但对方不履行：可自协议生效之日起 30 日内共同申请**司法确认**，确认后可申请执行（《人民调解法》第 33 条；《民事诉讼法》第 205 条）。
- 没达成协议：走支付令或诉讼。

### 情况 5：房东反诉，主张你损坏房屋

- 要求他列明损坏项目、位置、金额、维修凭证；没有证据的部分不认。
- 用入住照片、视频、退租交接单、证人证言反驳；强调正常损耗（《民法典》第 710 条）。
- 对「全屋翻新」「全新价赔偿」提出异议，要求按修复费用或折旧价值计算。
- 对明显过高的违约金，请求法院适当减少（《民法典》第 585 条）。
- 需要鉴定时，鉴定费先由申请方垫付，最终由败诉方或鉴定结果不利方负担。

### 情况 6：房东失联、去世、卖房，或二房东跑路

- **失联**：通过物业、居委会、邻居、合同上的地址找；起诉时提供姓名、身份证号、地址，法院可公告送达。
- **去世**：向继承人在遗产范围内主张。
- **卖房**：买卖不破租赁（《民法典》第 725 条）；押金原则上向收钱的房东要，新房东书面承接的可以一并主张。
- **二房东跑路**：向二房东主张；原房东是否担责看是否同意转租（第 718 条）。原房东断水断电逼你搬的，报警并保留证据。
- **租赁企业爆雷**：向住建部门投诉押金托管、资金监管违规；同时申报债权或起诉，必要时联合其他租客。

### 情况 7：胜诉了对方不给钱

- 判决、调解书生效后 2 年内申请强制执行（《民事诉讼法》第 250 条）。
- 提供财产线索：银行账户、微信、支付宝、房产、车辆、租金收入。
- 申请限制高消费、纳入失信名单；对方有履行能力而拒不履行的，可申请罚款、拘留。
- 暂时无财产的会「终本」，以后发现财产可申请恢复执行。

### 情况 8：已经拖过很久

诉讼时效是 **3 年**，从你知道或者应当知道押金该退而未退之日起算（《民法典》第 188 条）。超过 3 年，对方提出时效抗辩，你可能败诉。补救办法：

- 找催告记录、对方承诺退款的聊天、调解申请、投诉记录，证明时效中断（第 195 条）。
- 对方在时效届满后同意履行或者已经部分履行的，不能再以时效抗辩。
- 不要因为拖久了就放弃，先咨询 12348。

## 常见错误

1. **把押金当定金**，以为「我违约了押金就该全没」。押金是担保，结算后有余应退。
2. **退租不做交接、不拍视频**，事后说不清原状，房东说哪坏就哪坏。
3. **只口头通知搬走**，没有书面记录，被认定未提前通知。
4. **钱没到账就签「结清无争议」**，签完再追很难。
5. **现金付押金不要收据**，最后连「交过多少」都证明不了。
6. **房东说扣就认**，不要明细、不要凭证。
7. **以为 12315 或 110 能直接让房东退钱**；前者管经营者消费争议，后者管治安和刑事。
8. **断水断电、换锁、扣留房东物品**对抗，可能反被索赔。
9. **告错法院**：房屋租赁合同纠纷由房屋所在地法院专属管辖，不是随便选一个法院。
10. **告错被告**：二房东、租赁企业、房东是不同主体，谁收押金告谁。
11. **忘记 3 年诉讼时效**，或以为「随时可以告」。
12. **删聊天记录、换手机、清理微信**，原始载体没了，电子证据证明力大打折扣。
13. **只主张押金，不主张利息和诉讼费**，少了谈判筹码。

## 各地差异

| 事项 | 各地做法 | 来源 |
|---|---|---|
| 押金数额上限（住房租赁企业） | **全国**：《住房租赁条例》只要求合同约定押金数额、返还时间和扣减情形，未设统一上限；**北京**：住房租赁合同内容中押金数额一般不超过一个月租金，租赁企业收取押金一般不得超过一个月租金；**上海**：租赁企业收取押金超过一个月租金的部分，应当存入住房租赁交易资金监管专用账户，保障性租赁住房押金不得超过一个月租金 | 全国：《住房租赁条例》第十条（https://www.gov.cn/zhengce/zhengceku/202507/content_7032956.htm）；北京：《北京市住房租赁条例》第十四条、第三十六条（https://gaj.beijing.gov.cn/wsgs/2024zcwj/zcfg/202406/t20240628_3732127.html）；上海：《上海市住房租赁条例》第二十九条、第三十七条（https://shanghai.gov.cn/bzxzlzfjbzcsjzc/20230418/8a0798aa5f444182a33065910f5b272c.html） |
| 押金退还时限（住房租赁企业） | **全国**：国家层面未规定统一退还天数，按合同约定；**北京**：租赁企业应当自承租人返还住房后 3 个工作日内提出押金退还意见，承租人应当在 3 个工作日内确认 | 全国：《住房租赁条例》第十条（https://www.gov.cn/zhengce/zhengceku/202507/content_7032956.htm）；北京：《北京市住房租赁押金托管和租金监管暂行办法》第十条（https://www.beijing.gov.cn/zhengce/zhengcefagui/202408/t20240801_3764440.html） |
| 押金资金监管 | **全国**：从事转租经营的住房租赁企业应当设立住房租赁资金监管账户并向社会公示；**北京**：转租型住房租赁企业的押金应当存入第三方专用托管账户；**上海**：押金超过一个月租金的部分应当存入监管专用账户 | 全国：《住房租赁条例》第十九条（https://www.gov.cn/zhengce/zhengceku/202507/content_7032956.htm）；北京：《北京市住房租赁押金托管和租金监管暂行办法》第九条（https://www.beijing.gov.cn/zhengce/zhengcefagui/202408/t20240801_3764440.html）；上海：《上海市住房租赁条例》第二十九条（https://shanghai.gov.cn/bzxzlzfjbzcsjzc/20230418/8a0798aa5f444182a33065910f5b272c.html） |
| 租赁纠纷调解渠道 | **全国**：因押金返还、住房维修、住房腾退发生纠纷，先协商，协商不成可申请调解、仲裁或提起诉讼；**北京**：可向协会、行业组织、有关部门、人民调解组织申请调解；**上海**：综合运用人民调解、行业调解、行政调解、司法调解 | 全国：《住房租赁条例》第三十五条（https://www.gov.cn/zhengce/zhengceku/202507/content_7032956.htm）；北京：《北京市住房租赁条例》第十一条（https://gaj.beijing.gov.cn/wsgs/2024zcwj/zcfg/202406/t20240628_3732127.html）；上海：《上海市住房租赁条例》第十三条（https://shanghai.gov.cn/bzxzlzfjbzcsjzc/20230418/8a0798aa5f444182a33065910f5b272c.html） |
| 小额诉讼标的额 | **全国**：标的额为各省、自治区、直辖市上年度就业人员年平均工资 50% 以下的简单金钱给付案件，适用小额诉讼程序、一审终审；超过 50% 但在 2 倍以下，双方可以约定适用；具体金额由各省每年公布，各地不同 | 《民事诉讼法》（2023 年修正）第一百六十五条（https://amr.guizhou.gov.cn/zwgk/xxgkml/jcxxgk/zcfg/fl/202401/t20240129_83645867.html） |
| 租赁合同备案 | **全国**：出租人应当通过住房租赁管理服务平台等方式备案，备案免费，未备案不影响合同效力；**北京**：合同订立 30 日内备案，并于 3 个工作日内办理出租登记；**上海**：合同订立 30 日内办理登记备案 | 全国：《住房租赁条例》第八条、《民法典》第七百零六条（https://www.gov.cn/zhengce/zhengceku/202507/content_7032956.htm）；北京：《北京市住房租赁条例》第十五条（https://gaj.beijing.gov.cn/wsgs/2024zcwj/zcfg/202406/t20240628_3732127.html）；上海：《上海市住房租赁条例》第十七条（https://shanghai.gov.cn/bzxzlzfjbzcsjzc/20230418/8a0798aa5f444182a33065910f5b272c.html） |

## 信息核实方式

1. **`12348` 公共法律服务热线**：免费问管辖、材料、诉讼费、时效。
2. **`12345`**：问当地住建部门投诉入口、街道人民调解委员会地址电话。
3. **房屋所在地住建委或房管局官网**：查住房租赁企业备案、押金托管和资金监管政策、租赁合同示范文本。
4. **人民法院在线服务**（微信小程序或网页）、**`12368`** 诉讼服务热线：查立案材料、诉讼费、案件进度。
5. **国家法律法规数据库** `flk.npc.gov.cn`：核对《民法典》《民事诉讼法》原文；**中国政府网** `gov.cn`：查《住房租赁条例》。
6. **中国裁判文书网** `wenshu.court.gov.cn`：搜「房屋租赁合同纠纷 + 押金」，看本地法院同类判决的尺度。

本文不能作为最终依据，动手前用上面任一渠道核实一次，尤其是当地押金监管政策和小额诉讼标的额。

## 行动清单

- [ ] 找出合同、押金收据或转账记录、入住交接单和照片
- [ ] 退租前 7–15 天发书面退租通知，写明交房日期

- [ ] 全程保留原始聊天记录、录音、EMS 面单和视频
