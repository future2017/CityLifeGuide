# 急诊、120 与急救常识

> ⏱ 本文信息采集于 **2026-09**。政策调整频繁，动手前请用文末的「信息核实方式」确认一次。

---

## 一句话结论

**危及生命的情况，先打 120，不要自己开车送——这不是客套话，是有数据支撑的：叫救护车的心梗患者从发病到医院平均 170 分钟，自己去的平均 240 分钟**（中国疾控中心数据）。

三件事记住就行：

1. **救护车要收费，但急救医疗费多数能走医保，车费多数自付**——别为了省这几百块放弃救护车上的抢救设备和随车医生。
2. **急诊是「按病情分级」不是「先来后到」**——国家规定的分级制度里，最轻的一级候诊 2～4 小时是正常现象。
3. **CPR 的数字要背下来：按压频率 100～120 次/分，成人深度 5～6 厘米。** 这两个数字错一个，救回来的概率就掉一大截。

## 什么时候叫救护车、什么时候自己去

### 必须叫 120，不要自己送

出现下面任何一条，**先打 120**：

| 情况 | 为什么必须叫车 |
|---|---|
| 意识不清、叫不醒、昏迷 | 途中可能呕吐窒息、心跳骤停，家属无法处理 |
| 呼吸停止或只有喘息样呼吸 | 需要立即 CPR + AED，车上可以做，私家车不能 |
| 疑似心梗：压榨性胸痛超过 15 分钟、放射到肩背下颌、伴大汗恶心 | 官方数据：自行到院平均比叫救护车晚 70 分钟 |
| 疑似脑卒中：「中风 120」口诀任一阳性（1 张脸不对称、2 只手臂单侧无力、0 聆听讲话不清） | 溶栓时间窗只有 4.5 小时，每分钟约 190 万个脑细胞死亡 |
| 大出血、严重外伤、疑似骨折致不能移动 | 需止血、固定、专业搬抬 |
| 抽搐持续超过 5 分钟，或反复发作，或发作后不醒 | 属于急危重范畴 |
| 呼吸困难、口唇发紫 | 途中可能需要给氧、人工通气 |
| 中毒、触电、溺水、一氧化碳暴露 | 现场处置有专业动作，且可能需要解毒药 |
| 孕妇急产、剧烈腹痛、阴道大出血 | 需产科急救能力对接 |
| 3 个月以下婴儿发热 ≥38℃ 且精神差 | 小婴儿病情恶化快 |

### 可以自己打车/开车去医院

- 明确不危及生命、且能安全移动的：**轻微外伤需要缝针、扭伤、腹痛但能行走、发热但精神尚可、泌尿系统不适、皮疹过敏（无呼吸困难）**
- 医院就在步行/驾车几分钟内，且患者**能自己走、能自己坐**、途中不会失去意识
- 只是去**复诊、取药、换药**

### 为什么有时自己去更快

官方口径（北京市中医药管理局科普）明确说「自行送医可能因路况、缺乏急救设备延误治疗」，这句话针对的是**急危重症**。但把话说全，**在下面这些情形里，自己去确实更快**：

1. **距离极近**。叫车的耗时 = 等调度派车 + 车辆抵达 + 从现场到医院的返程；自己出发没有前两段。
2. **救护车资源紧张或占线**。高峰期、恶劣天气、突发公共事件时，本地急救中心可能无法立即派车（各地急救呼叫满足率并不都是 100%）。
3. **病情明确不危及生命**，车上不需要任何处置和监护。
4. **不适合救护车接手的情形**：只需门诊处理的小问题（比如换药、拆线），叫车属于占用急救资源。

**判断标准只有一条：路上如果病情突然恶化，你（或司机）能不能处理？**

- 不能处理 → **叫 120**。
- 能处理（患者清醒、能对话、能自己坐稳）→ 自己去可以。**但优先打车/网约车，不要自己开车**——自己开车时无人照看患者。
- 拿不准 → **打 120**。调度员在电话里就能判断要不要派车，你不需要自己扛这个决定。

### 救护车真正的价值（不是「更快」，是「路上不会死」）

- 车上配备**除颤仪、呼吸机、监护设备、急救药品**（北京急救中心装备清单），可在途中抢救。
- 随车**执业医师**可现场评估、用药、做 CPR。
- 车辆优先通行，可以使用公交专用道、应急车道，免通行费和停车费。
- 急救人员会**提前联系接收医院**，让医院的卒中中心、胸痛中心提前待命——这一段「绿色通道」是私家车给不了的。

## 怎么打 120

### 号码：就拨 120，不用加区号

《院前医疗急救管理办法》第十三条规定：**全国院前医疗急救呼叫号码为「120」**。用手机直接拨 120 会自动接通你所在城市的急救中心，**不用加区号**。

- 要打**外地**的 120，才需要加区号，比如在北京以外地区拨打北京急救中心是 `010-120`。
- **用手机打，别用座机**：手机一般能让调度台看到你所在的区域（精到区域，不精到门牌号），座机能定位的概率低得多。

### 北京：现在只有 120 一个急救号

很多老攻略还在写「北京有 120 和 999 两个急救号码」，**这个说法已经过期了**。

- 北京市院前医疗急救服务的**专用呼叫号码为「120」**（《北京市院前医疗急救服务条例》第十九条）。
- 原「999」自 **2021 年底**起统一为 120，999 回归红十字会「救灾、救助、救护」职能，**只做非急救转运和航空医疗服务**（新华网报道；北京急救中心「关于我们」也写明北京是全国唯一坚持「120」一个医疗急救号码服务全社会的省市）。
- 也就是说：**急病打 120；出院回家、跨省长途转运这类非急救需求，才去找 999 或当地的非急救转运渠道。** 具体受理范围以北京急救中心和北京市红十字会的最新公告为准。

### 通话顺序：先说「在哪」，再说「怎么了」

官方科普文章里，拨通后要讲的三件事里**位置信息排在第一条**。原因很直接：**地址决定派哪辆车、派去哪家医院**；地址说不清，车出不去。

最高效的一句话是：**「我在 XX 路 XX 小区 X 号楼 X 单元 X 室」**。如果现场有标志物，补一句「XX 加油站对面」「XX 商场 3 楼 X 店铺门口」。

不过也有资深急救专家提示另一种做法同样有效：**不要抢话，接线员问什么答什么**（北京急救中心专家在接受央广网采访时的建议）。两种做法合起来就是：**接通后先主动报清地址，然后跟着调度员的提问回答，别自己讲一长串病史。**

### 五条硬规则

1. **一定留下回拨电话。** 留 1～2 个畅通的手机号。用座机打的，就守在电话旁别占线。**电话如果中途断了，调度员会持续回拨**，也可能联动 110 一起找（北京急救中心机制）。手机号注册地在哪里都不影响拨 120。
2. **不要先挂电话。** 等调度员确认信息说完再挂。很多时候调度员会在电话里**教你现场怎么救**（心肺复苏、止血、海姆立克），这几分钟的指导可能比等车更关键。
3. **派人到路口/小区门口接车。** 老旧小区、复杂商圈、地下车库尤其需要——安排人在门口等，看到救护车立刻引导到患者身边。
4. **说清楼层、单元门牌、门禁、电梯。** 具体到「能不能进单元门」「电梯能不能放平车」「门禁密码是多少」。这些信息直接决定急救人员是 1 分钟还是 10 分钟到床边。
5. **说清病史和现场。** 年龄、性别、最危急的症状、发病时间、既往病史和用药（尤其抗凝药、降压药、硝酸甘油）、现场人数。

### 可直接照念的话术

> 「我要叫救护车。地址是 **XX 市 XX 区 XX 路 XX 小区 3 号楼 2 单元 1502 室**，小区在 XX 加油站对面，门口有人接车。
> 患者是 **68 岁男性，10 分钟前突然胸痛、出大汗，现在坐着、能说话，有高血压和冠心病史**。
> 我的电话是 **138XXXXXXXX**，保持畅通。」

打完电话后：让患者**别动、别自己走**（疑似心梗/卒中尤其如此），解开领口腰带，呕吐的侧头防误吸；准备好患者的**身份证、医保卡或电子医保凭证、常用药清单、现金或能支付的手机**；把楼道门、小区门打开或留人接应。

## 急诊分级与「急诊不急」

### 官方依据：急诊分四级

依据《需要紧急救治的急危重伤病标准及诊疗规范》（国卫办医发〔2013〕32 号），急诊病人**按病情严重程度分四级**：

| 级别 | 名称 | 含义 | 处置 |
|---|---|---|---|
| **1 级** | 濒危病人 | 生命体征极不稳定，随时危及生命 | **立即**进抢救室 |
| **2 级** | 危重病人 | 随时可能出现生命危险，病情易迅速恶化 | 立即监护，**10 分钟内**进抢救区 |
| **3 级** | 急症病人 | 短时间内无危及生命征象，但有潜在加重风险 | 黄区候诊，**一般不超过 30 分钟** |
| **4 级** | 非急症病人 | 无急性发病症状，生命体征稳定 | 绿区候诊，按来诊顺序，**通常 2～4 小时** |

深圳的地方标准 DB4403/T 244—2022《急诊患者分级分诊规范》把处置时限写得更具体：3 级候诊不宜超过 30 分钟，超过要重新评估；亚急症候诊宜在 1 小时内；非急症一般为 2～4 小时，超过 4 小时宜再次分级。**这就是「急诊不急」的全部原因**——分级看的是**病情危险程度**，不是**你等了多久**。

还有一条补充依据容易被忽略：**占用急诊医疗资源的多少也会影响分级**。同样是非急症，如果需要占用 2 个以上急诊资源，级别会从 4 级上调到 3 级。

### 为什么分级不是「欺负人」

- 北京 20 家市属医院 2019 年统一实施急诊分级后的统计：**非急症患者占急诊总量的 47.71%**。也就是说，将近一半的急诊就诊本来不需要用急诊资源。
- 分诊不是一次性判定，**候诊期间病情变化要重新评估**：3、4 级患者在候诊区有护士巡视，生命体征异常会**上调一级**。
- 医院必须**实行首诊负责制，不得以任何理由拒绝或推诿急诊患者**；对危重患者按「先及时救治，后补交费用」的原则抢救（《急诊科建设与管理指南（试行）》卫医政发〔2009〕50 号；《北京市院前医疗急救服务条例》第二十四条也写入首诊负责制）。

### 到急诊以后你的三个动作

1. **先到分诊台，别直接冲诊室。** 分诊护士会量体温、心率、血压、血氧，问症状和病史，然后给你定级别。你挤进诊室也没用——级别不够照样等。
2. **看自己的分级标识。** 多数医院用红 / 黄 / 绿分区和叫号屏显示级别，看清楚自己几级，心里就有数了。
3. **等超过 30 分钟，主动去分诊台要求复评。** 尤其是出现新的症状（胸痛、呼吸困难、意识改变、剧痛加重）时，**随时报告护士，要求重新分级**。这是规定动作，不是麻烦人。

## 急诊费用与医保

### 救护车费用：收，怎么收

**结论：120 是公益性事业，但不免费。**

- 《院前医疗急救管理办法》第二十五条：急救中心（站）**按照国家有关规定收取院前医疗急救服务费用**，但**不得因费用问题拒绝或者延误院前医疗急救服务**。
- 北京急救中心公示的价格（依据京医保发〔2025〕23 号、京医保发〔2026〕6 号，以及京发改〔2016〕514 号）：

| 项目 | 价格 | 医保类别 |
|---|---|---|
| 院前急救费（针对急危重症患者的现场紧急救治） | **80 元/次** | **甲类**（可报销） |
| 救护车转运费 | **基础费 70 元（3 公里内）+ 7 元/公里**（超过 3 公里部分） | **丙类**（基本医保不报） |
| 救护车转运费—高层人力转运 | 基础费 50 元/次，无电梯每层加收 20 元 | 丙类 |
| 院前医疗服务费（针对非急危重症患者） | 120 元/人次 | 丙类 |
| 等候费（因患方原因占用急救资源） | 200 元/小时，半小时内不收 | 丙类 |
| **跨省市长途转运** | **25 元/公里**（按出发地到目的地实际行驶公里计，含过路过桥费和燃油费） | 丙类 |

北京的计价规则还有几条要记住：**计价里程按接到患者起至目的地的实际行驶公里计算，无计价器不得收费**；同时接送 2 名及以上患者，按人数平均分摊；**患者或家属因自身原因拒绝使用已到达现场的救护车，也要收基础费 70 元**。

### 能否医保报销

**拆成两笔看，这是关键：**

| 费用 | 通常怎么算 |
|---|---|
| **急救医疗服务费**（院前急救费、现场抢救、用药、检查、监护） | 多数地区**可纳入医保**。北京列为**甲类**；《北京市院前医疗急救服务条例》第三十四条明确「将院前医疗急救服务产生的**医疗服务费**纳入城镇职工医保、城乡居民医保的报销范围」 |
| **救护车车费 / 里程费 / 回家转运费** | 多数地区**需全额自付**。北京列为**丙类**；上海松江区官方答复也是「救护车里程费、回家转运费需全额自付，**仅院前急救医疗费用**可纳入医保报销，且需满足『突发疾病送医抢救』条件」 |

所以：**叫车前不要为了省钱而犹豫**，先救人；结算后把票据收好，回到参保地按当地政策报能报的那部分。必要时打 `区号+12393` 核实。

### 急诊抢救费用是否「视同住院」

**多数地区对「急危重」的急诊抢救费用按住院政策结算，但这是地方政策，不是全国统一。**

| 地方 | 规定 | 来源 |
|---|---|---|
| **江苏**（全省统一） | 急诊处置为 **1 级濒危、2 级危重**的参保人员，在门（急）诊实施紧急抢救的，**按住院支付政策**享受待遇：**不设起付线**，报销比例按住院结付比例，费用计入住院费用和门诊特殊病支付限额 | 苏医保发〔2022〕42 号 |
| 同上 | **3 级急症**病人门急诊留观后**直接转住院**的，按上一档享受；留观后未转住院的，按门诊政策 | 同上 |
| **新疆** | 符合 1 级濒危、2 级危重标准，或经急诊治疗无效死亡的，按住院支付比例报销，**起付标准按同级住院起付标准的 10%** 确定；急诊过程中提级的，提级前后费用算同一次就医，按最高分级待遇支付 | 新疆维吾尔自治区医疗保障局 |
| **河北保定** | 因危、急、重症在门诊紧急抢救后**立即住院**（急诊抢救与住院时间未间断），紧急抢救费用**并入住院医疗费用**；因突发疾病在**门诊抢救死亡**所发生的医疗费用，**视同一次住院** | 保定市城乡居民医保急诊急救管理办法 |

执行时的具体操作：**国家医保信息平台设有「急危重伤病门（急）诊待遇」医疗类别**，医院通过该类别结算（江苏做法）。医院需要在病历里明确急诊处置级别，依据就是上面提到的国卫办医发〔2013〕32 号。

> ⚠️ 各地起付线、报销比例、覆盖级别（有的地方只认 1、2 级，有的含 3 级）都不一样。**必须查你参保地的规定**，不要照搬外省经验。

### 异地急诊抢救：可以视同已备案

这是最容易被忽略、也最省钱的一条。

按国家医保局《基本医疗保险跨省异地就医直接结算经办规程》**第三十四条**：参保人员因**急诊抢救**就医的，医疗机构在办理「门诊结算」或「入院登记」时会上传「门诊急诊转诊标志」或「住院类型」；凡是系统里标记为**「急诊」**的，**参保人员未办理异地就医备案的，参保地应视同已备案**，允许按参保地**异地急诊抢救相关待遇标准直接结算**相关门诊、住院医疗费用。

**这意味着：出差、旅游途中突发急病进急诊，不用手忙脚乱地先补备案，可以直接刷卡结算。** 备案的完整流程、待遇差幅、补办规则见 [4.4 异地就医备案](cross-province-medical-filing.md)。

### 如果真的付不起

**别因为没钱不敢叫车。** 有两层保障：

- 《院前医疗急救管理办法》明确：**不得因费用问题拒绝或者延误院前医疗急救服务**。
- 疾病应急救助制度（国办发〔2013〕15 号）：在本行政区域内发生急危重伤病、**需要急救但身份不明确或无力支付**的患者，医疗机构对其紧急救治所发生的费用，可以申请**疾病应急救助基金**补助（广东省实施细则等地方文件明确援引）。

## 心肺复苏与 AED

> 下面这些数字来自中国红十字会培训体系和官方科普。**建议去参加一次持证培训，只看文字学不会按压手法。**

### 什么时候做 CPR

**只有一个判断标准：没有反应 + 没有正常呼吸。**

1. **判断意识**：双手轻拍双肩，大声喊「喂！你怎么了？」无反应即为意识丧失。
2. **判断呼吸**：观察胸腹部是否有起伏，**5～10 秒**（心里数 1001、1002…）。
3. **关键区分**：**只有喘息样呼吸（像「倒气」的不规则呼吸）＝ 没有正常呼吸**，同样要立即开始 CPR。反之，**有正常呼吸、有脉搏的晕倒者不需要 CPR**，让他侧卧防误吸、打 120 即可。

### 先打电话还是先救人

按北京急救中心专家的口径：

- **成人非创伤性心脏骤停**（失去知觉、呼吸停止）→ **先拨打 120，再做 CPR**。
- **溺水、电击、异物阻塞气道**导致的呼吸心跳停止 → **先做 2 分钟 CPR，再拨打 120**。

现场有其他人时，指定具体的人分工：「你打 120！你去拿 AED！」——不要喊「谁去打一下电话」。

### 胸外按压：位置 / 频率 / 深度

| 项目 | 成人 | 1 岁以上儿童 | 1 岁以下婴儿 |
|---|---|---|---|
| **位置** | 胸骨下半部，两乳头连线中点 | 同成人（胸骨下半部） | 两乳头连线中点**下缘** |
| **手法** | 双手掌根重叠，十指相扣、掌心翘起，双臂伸直，上半身前倾用**上身重量**垂直下压 | 单手或双手掌根（体型小可用单手） | **两根手指** |
| **深度** | **5～6 厘米** | 至少胸廓前后径的 **1/3（约 5 厘米）** | 至少胸廓前后径的 **1/3（约 4 厘米）** |
| **频率** | **100～120 次/分** | 同成人 | 同成人 |
| **比例** | 30 次按压 : 2 次人工呼吸 | 同成人 | 同成人 |

**四条质量要求：**

1. **每次按压后让胸廓完全回弹**，不要一直压着。
2. **尽量减少按压中断**，任何中断**不超过 10 秒**。
3. 按压时**跟随 100～120 次/分的节奏**（每分钟 100～120 拍的歌都行），数出声更好掌握。
4. **不会或不愿做人工呼吸，就只做持续胸外按压**——徒手 CPR 对未经培训的人同样有效，不要因为顾虑人工呼吸而放弃施救。

**开放气道与人工呼吸**：仰头抬颏法（一手压前额使头后仰，另一手抬起下颏），捏住鼻翼，口对口吹气 2 次，每次约 1 秒，看到胸廓抬起伏即可，**避免过度通气**。婴儿用嘴同时包住口和鼻，轻轻吹气。

### 什么时候可以停止

出现下列任一情况可停止：

- 患者**恢复自主呼吸和脉搏**（有反应、有活动）；
- **专业急救人员接手**；
- 患者被宣布死亡；
- 单人施救且**体力实在难以支撑**（有条件时应轮换，每 2 分钟换人最好）。

不要因为「按了 10 分钟没反应」就停——院外心脏骤停的抢救本来就需要坚持到专业人员到场。

### AED：怎么用

AED（自动体外除颤器）是**唯一被证实能提高心脏骤停生存率的单一干预措施**，约 80% 的心脏骤停由心室颤动引起。操作就四步：

1. **开机**，跟着语音提示走。
2. **贴电极片**：一片贴在**右前胸上部（锁骨下方）**，一片贴在**左胸外侧（腋中线）**。胸部有汗、有水先擦干；有药物贴片先撕掉；有起搏器避开即可。
3. **分析心律**：AED 自动分析时，**所有人不得接触患者**（包括不要做按压），大声喊「离开！」。
4. **需要电击时按电击键**；电击完成后**立即恢复胸外按压**，2 分钟后 AED 会再次分析，如此循环，直到患者恢复或急救人员接手。

**儿童**：优先使用儿童电极片或儿童模式（一般指 8 岁以下、体重低于 25 公斤）；没有儿童配件时，**可以用成人 AED**——不要因为「怕电量太大」而不除颤。

### 哪里找 AED

**线上入口**（AED 地图尚未全国统一，不同平台数据对不上，建议**平时就存好本地那一个**）：

| 类型 | 入口举例 |
|---|---|
| 本地官方小程序 | 北京：微信搜「**北京120**」小程序 →「重点公共场所 AED 电子地图」（已与 120 调度指挥系统联通）；深圳：「**AED导航**」小程序；杭州：「杭州AED在线」；福建：「福建AED地图」 |
| 政务 App | 上海：「随申办」内嵌 AED 电子地图；重庆：集成到「**渝快办**」App（可查 2 公里内点位并导航） |
| 商业地图 | **高德地图、百度地图**（北京可在高德地图 App 内查看附近 AED） |
| 红十字会 | 中国红十字会总会训练中心「**救在身边·应急救护服务平台**」（crcntc.org.cn）设有 AED 查询入口，同时可查持证培训报名 |
| 其他 | 各地还有厂家、公益组织做的地图（如「悦尔救心AED」等） |

**线下怎么找**（地图不可用时的兜底）：AED 通常放在**壁挂式红色/绿色/橙色箱体**中，箱体印有白色心形闪电标识和「AED」字样。常见位置：**地铁站安检口旁、商场服务台和电梯间旁、写字楼大堂、健身房器械区、体育场馆、学校、机场车站、公园景区服务台**。最省事的办法是**直接问保安或前台**，他们通常最清楚设备在哪。

**两个坑要知道**：一是 AED 地图存在**漏标、错标**，不同平台同一位置显示的数量都不一样；二是部分设备**有开放时间限制、或者被锁在柜里/需要扫码开门**。所以——**与其现场现找，不如提前记住你常去的三个地方（家、公司、健身房）的 AED 在哪。**

## 气道梗阻（海姆立克）

### 第一步：先分清轻还是重（这一步最容易做错）

| 程度 | 表现 | 怎么办 |
|---|---|---|
| **轻度梗阻** | 还能**咳嗽、能说话、能呼吸** | **鼓励他继续用力咳嗽**，自主排出。**严禁**立刻拍背或做腹部冲击 |
| **重度梗阻** | **「三不能」：不能咳嗽、不能说话、不能呼吸**，双手掐喉（窒息痛苦表情），口唇发紫 | **立即施救**，并让人打 120 |

> 2025～2026 年更新的急救指引把流程改成了「**先拍背、后腹部冲击**」，并强调**先识别梗阻程度再施救**。原因是背部拍击是无创操作，比直接冲击腹部更安全、异物清除成功率也更高。旧版单一的腹部冲击可能导致肝脾损伤、肋骨骨折。

### 1 岁以上儿童及成人：「背 5 腹 5」交替

1. 让患者**双腿分开与肩同宽、身体前倾**。
2. **背部拍击**：用掌根在**肩胛骨连线中点**用力拍背 **5 次**。
3. 无效 → **腹部冲击**：站到患者身后，双臂环抱其腰部，一只手握拳、**拳眼朝内放在脐上两横指处**，另一只手包裹住拳头，**快速向上、向内用力冲击** **5 次**。
4. 拍背 5 次、腹部冲击 5 次**交替循环**，直到异物排出。

### 1 岁以下婴儿：禁用腹部冲击

**婴儿内脏未发育成熟、位置偏上，腹部冲击容易造成损伤，绝对禁止。**

1. 让婴儿保持**「头低脚高」体位**（施救者前臂托住婴儿，头低于躯干）。
2. **拍背 5 次**：用掌根在**肩胛骨连线中点**力度适中地拍 **5 次**。
3. 无效 → **胸部冲击 5 次**：把**两指**置于婴儿**两乳头连线中点下缘**，快速向下按压**约 4 厘米**，连续 5 次。
4. 拍背与胸部冲击**交替循环**，直到异物排出。

### 孕妇和肥胖人群：改做胸部冲击

由于对这两类人做腹部冲击**风险高、效果差**，操作部位改为**胸骨下半部分（约两乳头连线中点）**：双臂环抱患者胸部（**避开乳房区域**），用掌根快速向后、向内发力，做**胸部冲击**。

### 独自一人被噎住

用自己的拳头按腹部冲击的动作自我冲击；或者**把上腹部压在椅背、桌沿、栏杆等坚硬物体边缘上**，快速向内上方冲击。

### 排出之后仍要去医院

气道梗阻解除不算结束。**应立即就医**，通过 CT 等排查**异物残留、内脏损伤、迟发性出血**。拍背和冲击是急救手段，本身也可能造成损伤。

## 常见急症的现场处置要点

| 急症 | 要做的 | 千万不要做 |
|---|---|---|
| **疑似心梗** | 立即停止一切活动，**坐下或半卧位**休息；解开衣领腰带；既往确诊心绞痛且有医嘱的，**舌下含服硝酸甘油**（5 分钟不缓解可再含 1 片，最多 3 片）；**立即打 120**；出现意识丧失、呼吸停止时做 CPR | **不要自己开车送医院**（官方口径明确「不要自行驾车」）；不要自行服用阿司匹林（除非医生明确建议）；不要扶患者走动 |
| **疑似卒中（中风）** | 用「中风 120」口诀识别；**立即打 120**；让患者**平卧，头略抬高 15～30 度或偏向一侧**；解开领口；清理口腔异物；**准确记录症状出现的时间**（决定溶栓时间窗） | **不要喂水、喂食、喂药**（易呛咳窒息）；不要随意搬动、晃动头部；不要抱着「睡一觉就好」的心态观察 |
| **抽搐（癫痫大发作）** | 移开周围硬物、软垫护头；**侧卧位**防误吸；松开衣领；**记录发作持续时间**；发作停止后让他安静休息并就医 | **不要往嘴里塞任何东西**（不要塞筷子、手指、毛巾）；不要强行按压四肢制止抽搐；不要掐人中 |
| **昏迷** | 判断呼吸和脉搏；**无正常呼吸 → 立即 CPR**；有人打 120、有人取 AED；有呼吸的侧卧防误吸 | 不要摇晃、不要喂水喂药 |
| **大出血** | 直接**加压止血**（用干净敷料用力按在出血点）；四肢出血可用止血带（记录上带时间）；打 120 | 不要反复揭开敷料查看；不要用绳子当止血带 |
| **烧烫伤** | **流动冷水冲洗 15～20 分钟**；剪开（不要撕）粘住的衣物；干净敷料覆盖 | 不要涂牙膏、酱油、蛋清；不要挑破水疱；不要用冰块直接敷 |
| **中毒（含一氧化碳）** | 先**保证自身安全**再救人；一氧化碳中毒立即开窗、转移至通风处；**带上可疑药物/容器**去医院 | 不要盲目催吐（腐蚀性物质、石油类会二次损伤）；不要在现场开灯、打火（燃气泄漏） |
| **中暑/高热** | 转移到阴凉通风处，松开衣物，**物理降温**（凉水擦拭、冰袋放在颈部/腋下/腹股沟），补水（意识清醒时） | 意识不清者不要强行喂水 |

## 儿童与夜间就医的实用提示

### 儿科急诊怎么走

- 全国二、三级公立综合医院、妇幼保健院基本都能提供儿科服务；深圳的地方标准还要求**儿科急诊提供独立适合患儿就诊的诊室**。
- 儿童疾病高发期，**很多医疗机构会开夜间门诊、周末门诊**（国家卫生健康委新闻发布会）。就诊前**先打医院电话确认当晚有没有儿科急诊/夜诊**，别白跑。
- 常见感冒发热其实**就近到社区就诊更省时，医保报销比例也更高**（国家卫生健康委口径），还能接上家庭医生的健康管理。

### 发热：什么时候必须去

**先记住两条硬线，再看别的信号：**

1. **3 个月以下婴儿，体温 ≥38℃** → **尽快就医，不要在家观察**。这个月龄的婴儿即使发生严重感染，最初也可能只有吃奶减少、异常烦躁、呼吸加快或越来越嗜睡等轻微表现。
2. **有下面任一信号** → **立即就医，必要时打 120**：

   - 明显嗜睡、难以唤醒、反应明显下降
   - 呼吸困难、呼吸急促、吸气时胸部凹陷、发出咕噜声
   - 口唇或皮肤发青、面色苍白、皮肤花斑、手脚冰冷
   - 惊厥（抽搐）
   - 持续/异常哭闹、不好安抚
   - 不吃不喝、呕吐、没有眼泪、尿量明显减少
   - 出现皮疹
   - 家长明显觉得孩子**「和平时不一样」**

3. **发热持续超过 3 天没有好转**，或**退烧后精神依然不好** → 就医（北京儿童医院专家提示；国家卫健委发布会口径为「超高热或持续发热超过三天、频繁咳嗽影响正常生活、精神状态不好甚至出现嗜睡」）。
4. **发热持续 5 天以上** → 必须就诊（需排查川崎病等）。
5. **6 个月以上、发热但能喝水、能正常排尿、呼吸平稳、退烧后能玩能互动** → 可以先在家密切观察、补液、按体重用退热药，但**要持续监测**，变差就就医。

**热性惊厥**（6 个月～5 岁常见，多由体温骤升引起）：让孩子**侧卧**、清空周围硬物、**记录发作时间**，不要往嘴里塞东西、不要按压四肢，**不要掐人中**。出现下列情况**立即打 120**：发作持续**超过 5 分钟**、短时间内反复发作、发作后**长时间不醒或呼吸困难**、**6 个月以下婴儿**发作。发作很快停止且孩子逐渐恢复的，也**应尽快带孩子去儿科急诊检查**。

### 夜间就医清单

- 出发前**打电话确认**该院有儿科急诊、且当晚有相应专科（有些医院夜间没有眼科、口腔、耳鼻喉急症）。
- 带齐：**医保电子凭证或社保卡、身份证、既往病历和检查报告、正在吃的药、退烧药和水、一件外套**（夜间急诊等候区往往冷）。
- 夜间急诊人手更少，**分级差异比白天更明显**——你的孩子如果被定为 3 级，等 30 分钟属于正常。**但孩子一旦出现新的危险信号，立刻找分诊护士要求复评。**
- **不要因为「夜间怕排队」就把不紧急的问题拖到白天**——出现上面那份危险信号清单里的任何一条，当晚就走。

## 办不成怎么办

正常流程卡住时，按出事顺序对号入座。

### 1. 120 打不通、占线、无人接听

- 连续重拨；让身边人换手机、换运营商一起拨。
- 同时拨 **110**：国办发〔2022〕12 号要求各地 110、12345 与 119、120、122 建立应急联动机制，110 可派警协调急救。119 能打通，但不替代转运。
- 患者能坐能走，立刻自己送回最近急诊。
- 搬不动又打不通：请邻居、物业、保安、网格员拨号并帮忙抬人，另派人跑到最近急诊科求援。
- 记下拨号时间次数，事后向卫健委或 12345 反映。

依据：《院前医疗急救管理办法》第二十一条（每天 24 小时受理 120 呼叫）、第二十二条（不得因指挥调度拒绝、推诿或延误）。

### 2. 救护车迟迟不来

- 别挂断：调度员会回拨，也可能在电话里教你做心肺复苏。
- 按指令先救人，不自行搬动（疑似心梗、卒中、脊柱损伤）；呕吐者头侧向一边。
- 一次备齐：身份证、医保电子凭证或社保卡、病历、正在吃的药、过敏史、支付方式。
- 打开单元门和小区门，派人到路口接车；车辆若拒载、乱要价，记下车牌和随车人员姓名，事后投诉。

依据：国卫医发〔2020〕19 号要求 120 电话 10 秒接听率、3 分钟出车率、呼叫满足率均达 95%，达不到就可投诉。

### 3. 到了医院被拒收、被推诿

- 当场就说：「我要求按首诊负责制接诊，先做急危重评估；如认为本院不具备救治条件，请书面说明理由并帮我联系有能力的医院和转运，在此之前先做必要急救处置。」
- 找对人：分诊台 → 急诊科主任 → 医务科；按《医疗纠纷预防和处理条例》第十八条，医院必须设统一投诉部门并公布投诉途径。
- 要求把「不具备 XX 救治能力」「建议转往 XX 医院」写进病历，并索取复制件。
- 事后向卫生健康委投诉举报或打 12345。

依据：《医师法》第二十七条（不得拒绝急救处置）、《医疗机构管理条例》第三十条（危重病人应立即抢救）、《急诊科建设与管理指南（试行）》与《医疗质量安全核心制度要点》确立的首诊负责制。

### 4. 急诊让先交钱才看

- 先分清顺序：危重急诊患者按「先及时救治、后补交费用」原则救治（《急诊科建设与管理指南（试行）》）；《基本医疗卫生与健康促进法》第二十七条明确急救中心（站）不得以未付费为由拒绝或拖延急危重症急救（深圳等地条例即「先救治、后收费」）。
- 要求走急危重绿色通道；家属分头交费，别让排队耽误用药和检查。
- 押金不够：找急诊科护士长、主管医师，再到医务科或医保办申请绿色通道。可让医院申请**疾病应急救助基金**——国办发〔2013〕15 号规定，急危重伤病、需急救但身份不明或无力付费者可获补助（急救期以当地细则为准）。
- 低保、特困等身份可问当地民政部门医疗救助。

### 5. 转院：谁说了算，转不出去怎么办

- 能否转院由经治医师、科主任按病情判断，但必须说明病情、风险与替代方案（《医师法》第二十五条）；限于设备或技术条件不能诊治的病人，医院应及时转诊（《医疗机构管理条例》第三十条）。不认可理由可要书面说明。
- 你不想转：可明确要求继续救治，转出医院义务不因拒绝而消失；但本院做不了关键处置时不转就是赌时间，宜先做必要急救处置、请上级医院会诊。
- 你想转却被卡：《医疗质量安全核心制度要点》要求为非本机构诊疗范围内的急危重患者转诊提供必要帮助；你已联系好接收医院仍不被配合的，深圳等地立法规定首诊医院不得拒绝。
- 走前必答：谁派车、谁护送、送到哪层、途中出事谁负责。医院认为不宜转而你坚持转，一般要签《自动出院/转院告知书》，风险原则上由患方承担。
- 车辆：院际转诊、出院回家属「非急救转运」，120 多数只管院前急救；请转出医院安排或找当地渠道（北京 999、上海 962120）。

### 6. 费用争议、报销失败

- 先要明细：《医疗机构管理条例》第三十六条要求按规定收费、详列细项并出具收据。有异议先找医院物价、医保办核对，再向当地医保局、市场监管部门或 12345 反映；救护车收费争议同样凭票据反映。
- 异地急诊没备案：系统标为「急诊」的，参保地视同已备案、可直接结算（国家医保局经办规程第三十四条）；没成功就补办备案后走手工报销，流程见 [4.4 异地就医备案](cross-province-medical-filing.md)。
- 手工报销带发票原件、费用清单、急诊病历或出院小结、诊断证明、社保卡或医保凭证；备案过但结算失败按正常待遇，未备案可能降比例。
- 核实：区号+12393、12345、国家医保服务平台 https://fuwu.nhsa.gov.cn。

### 7. 地址说不清、定位不准

- 平时就做：手机开定位、允许紧急呼叫；「医疗急救卡」里填好住址门牌；给老人随身带写清地址、联系人和病史的卡片。
- 接通后先说地址再说病情：「小区名+几号楼几单元几室」加周边标志物；说不清把电话递给能说清路的人。
- 说不了话或听不见：部分城市有自动上传定位的急救小程序（乌海「120 视频呼救」含视频、听障呼救；福建已全覆盖），微信搜「城市名+120」找本地那款并平时存好；《无障碍环境建设法》要求急救等紧急呼叫系统实现一键呼救等无障碍功能。
- 用手机拨：《院前医疗急救管理办法》第十四条要求通讯系统具备位置显示功能。
- 地址更正立刻回拨，留人接车并保持手机畅通。

## 常见错误

1. **为了省钱不打 120，自己开车送心梗/卒中患者** → 官方数据：自行到院平均比叫救护车晚 70 分钟，而且路上没有除颤仪和随车医生。
2. **在北京还拨 999 叫急救** → 999 早已统一为 120，只做非急救转运和航空医疗（**以北京急救中心最新公告为准**）。
3. **打通 120 先讲一大段病史，说不清地址** → 地址决定派车和派医院，**先说在哪**。然后是「不要抢话，问什么答什么」。
4. **打完 120 就先挂电话** → 调度员可能正在教你做 CPR、止血。
5. **打完电话没人去路口接车** → 老旧小区、复杂商圈极易耽误几分钟。
6. **没说清楼层、单元、门禁、电梯** → 急救人员可能被挡在一楼门外。
7. **在急诊跟分诊护士吵「凭什么后来的人先看」** → 四级分级是国家级制度，**先来后到不是急诊规则**。
8. **等到心凉了也不去找分诊台复评** → 规定动作：等超过 30 分钟、或症状加重，**主动要求重新分级**。
9. **以为救护车能全报销，或者以为一定要全额自付** → 分两笔：**医疗服务费多数可报，车费/里程费多数自付**。收好票据。
10. **看到人晕倒就上去按胸** → 先确认**没有反应 + 没有正常呼吸**，有呼吸有脉搏的人不需要 CPR，侧卧就行。
11. **怕做错不敢做 CPR 或不敢用 AED** → 对心脏骤停的人，**不做才是最大的错**。AED 有语音提示，不会用错。
12. **噎住了先拍背/先压肚子** → 新版流程是**先判断轻重**：还能咳嗽就鼓励咳嗽，别干预；重度梗阻才「**先拍背、再腹部冲击**」。
13. **给婴儿做腹部冲击** → **绝对禁止**，婴儿只能「拍背 + 胸部冲击」。
14. **异物排出后就没事了** → 仍需就医排查异物残留、内脏损伤和迟发性出血。
15. **哮喘、抽搐、昏迷时往嘴里塞东西 / 掐人中** → 都是无效且可能造成伤害的操作。

| **急救号码** | 全国统一 120；**北京已统一为 120 一个号码**，原 999 转为非急救转运与航空医疗（2021 年底起） | 《院前医疗急救管理办法》、北京市院前医疗急救服务条例、新华网 |
| **救护车收费标准** | **全国无统一价，由地方价格主管部门定**。北京：院前急救费 80 元/次 + 救护车转运费 70 元（3 公里内）+ 7 元/公里；上海：起步 30 元 + 超过 3 公里后 7 元/公里，另收等候费、院前急救费 | 北京急救中心价格公示；上海市政府英文门户（Emergency medical services in Shanghai） |
| **急救车费能否医保报销** | 北京：院前急救费为**甲类**（可报），救护车转运费为**丙类**（自付）；上海松江：**仅院前急救医疗费用**可报，里程费、回家转运费全额自付 | 北京急救中心价格公示；上海市松江区人民政府 |
| **急诊抢救费用视同住院** | 江苏：1 级濒危、2 级危重门急诊紧急抢救**按住院支付政策、不设起付线**，3 级留观后直接转住院同样适用；新疆：按住院比例，起付线为住院的 **10%**，含经急诊无效死亡；保定：急诊抢救与住院未间断则费用并入住院，门诊抢救死亡视同一次住院 | 苏医保发〔2022〕42 号；新疆医保局；保定市城乡居民医保办法 |
| **异地急诊抢救备案** | **全国统一**：系统标记为「急诊」的，未备案也**视同已备案**，直接按参保地异地急诊抢救待遇结算 | 国家医保局经办规程第三十四条 |
| **分诊候诊时限** | 全国层面只规定分级原则；**深圳有地方标准**明确时限（3 级≤30 分钟，亚急症≤1 小时，非急症 2～4 小时），其他城市多为医院自行规定 | DB4403/T 244—2022 |
| **AED 位置查询入口** | 未全国统一。北京：「北京120」小程序；深圳：「AED导航」小程序；上海：「随申办」；重庆：「渝快办」；杭州、福建各有本地小程序；此外高德/百度地图、中国红十字会「救在身边」平台 | 各地卫健委、红十字会 |
| **跨省长途转运** | 无全国统一价；北京公示为 **25 元/公里**（丙类自付，含过路过桥费和燃油费）；多数长途/非急救转运由社会化机构或有资质的非急救转运单位承担 | 北京急救中心价格公示 |
| **非急救转运号码** | 北京：999（红十字会）；上海：962120（**医保不报销**，与 120 不同） | 新华网、解放日报 |

## 信息核实方式

急救政策和收费都可能变，**动手前用下面任一条路核实，比信任何一篇攻略（包括本文）都可靠**：

1. **本地急救中心官网 / 微信公众号** —— 收费价目、派车规则、急救培训报名只在这里是权威的。
   例：北京急救中心 https://www.120beijing.cn （「急救指南 → 院前医疗服务项目价格查询」可查完整价目表）。
2. **医保服务热线 12393** —— 拨打 `当地区号+12393` 找参保地经办机构，问清急诊抢救待遇、救护车费用能否报销、异地急诊结算。
3. **政务服务热线 12345** —— 不清楚归哪个部门时打这个，一般会转卫健委或医保局。
4. **国家医保服务平台** https://fuwu.nhsa.gov.cn —— 查全国医保经办机构咨询电话、异地联网定点医药机构、异地就医备案记录、直接结算明细。
5. **本地卫生健康委官网 / 公众号** —— 查急诊分级办法、AED 配置与电子地图、儿科诊疗服务机构名单。
6. **就诊医院官网或急诊科电话** —— 夜间出发前先确认有没有儿科急诊、有没有你要的专科急诊。
7. **中国红十字会总会训练中心「救在身边·应急救护服务平台」** https://www.crcntc.org.cn/ —— AED 查询、救护员/CPR+AED 持证培训报名、证书查询。
8. **看现场价格公示牌 + 索取票据** —— 救护车应安装计价器并在明显位置公示价格（《北京市院前医疗急救服务条例》第二十八条）；无计价器不得收取救护车转运费。对收费有异议，事后凭票据向价格主管部门或 12345 反映。

## 行动清单

**现在就做（不用等出事）**

- [ ] 把 `120` 存进手机**紧急联系人 / 医疗急救卡**，设置好锁屏可拨
- [ ] 教家里老人和小孩：**地址怎么说、手机怎么拨 120**
- [ ] 存好本地 AED 查询入口（北京→微信「北京120」小程序；其他城市见「各地差异」表）
- [ ] 走一遍家到最近三甲医院急诊的路线，记住**卒中中心 / 胸痛中心**在哪家医院
- [ ] 把家里的**门牌号、单元号、门禁密码**写一张纸贴在门口（给急救人员看）
- [ ] 记下家人的**既往病史、常用药、过敏史**，放一份在钱包或手机备忘录
- [ ] 报名一次**红十字救护员**或 **CPR+AED** 持证培训（4～16 学时）

**出事时按顺序做**

- [ ] 判断：危及生命吗？→ 是，立刻 **120**；否且能安全移动 → 可以自己去
- [ ] 拨 120，**先说地址**，再答病情，留回拨电话，**不先挂电话**
- [ ] 派人到路口/小区门口**接车**；说清楼层、门禁、电梯
- [ ] 需要时按调度员指导做 CPR / 止血 / 海姆立克
- [ ] 准备好**医保电子凭证或社保卡**、病历、常用药

**到急诊后**

- [ ] 先到**分诊台**测量生命体征，拿分级号
- [ ] 看清自己的分级；等待超过 30 分钟或症状加重 → **主动要求复评**
- [ ] 保留**救护车和急诊的全部票据**，用于医保和事后核对
