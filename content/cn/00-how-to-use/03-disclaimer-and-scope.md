# 免责声明与内容边界

> ⏱ 本文信息采集于 **2026-09**。这一篇讲的是本指南的自我定位与授权，本身不涉及会变的政策。

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 本文是办事流程指南，**不是法律意见、医疗建议、投资建议** |
| **它能帮你什么** | 少跑一趟、少带一份材料、知道办不成时该找谁 |
| **它不能帮你什么** | 替代律师、替代医生、替代窗口的最终口径 |
| **授权** | CC BY-SA 4.0，可自由转载、改编，包括商用，但须署名并以相同协议共享 |
| **最大的坑** | 把「一般情况」当成「你的情况」——个案差异需要专业人士判断 |

## 一句话结论

**本指南解决的是「怎么办」，不解决「你的情况在法律上该怎么认定」。**

前者是可以写清楚的：带什么材料、去哪办、多久、多少钱、办不成怎么办。后者依赖你的具体事实、当地现行口径和专业判断，任何一本通用指南都不该假装能替你决定。

> 遇到利益重大、时间紧迫、或者对方已经有律师的事——去看专业人士，别翻指南。

## 本文是什么

一本**办事流程工具书**。目标只有一个：让你在办事之前知道该带什么、去哪里、大概多久，以及失败了该往哪走。

它刻意不写「什么是社会保险」这类概念介绍——那不是你会带着问题来翻的内容。每一节都假设你已经决定要办这件事，现在只想知道怎么把它办成。

## 本文不是什么

三件事，本指南明确不做：

| 不做 | 说明 |
|---|---|
| **不出具法律意见** | 涉及诉讼、合同效力、财产分割、责任认定等，必须由执业律师结合你的具体事实判断。本指南只能告诉你流程长什么样 |
| **不做医疗建议** | 涉及症状、用药、诊断、治疗选择，必须由医疗机构和执业医师判断。本指南只写「怎么挂号、怎么结算、怎么维权」 |
| **不做投资或理财建议** | 涉及买卖时点、产品选择、收益预期，本指南不评价、不推荐 |

## 内容边界：哪些话题本文不写

| 不写的话题 | 原因 |
|---|---|
| 情感与关系建议 | 本指南只处理法律与流程问题（财产、登记、分割、抚养、保护令） |
| 个案可行性判断 | 「我这种情况能赢吗」——需要看证据和当地裁判口径，通用指南答不了 |
| 具体的机构与服务推荐 | 不推荐律所、中介、装修队、保险产品；只写官方渠道与辨别方法 |
| 灰色操作与「变通办法」 | 不教规避监管、不教如何走捷径绕过法定条件 |
| 未经核实的传闻与「经验帖」 | 来源规则是硬性的，见 0.2 |

## 关于准确性：我们做了什么，没做什么

**做过的：**

- 政策与数字**必须附官方来源**，且优先引发文机关的原文页；
- 每条标注**采集日期**（`collected`）与**复核期限**（`review_by`）；
- 首版定稿前对全部引用做过一轮**逐条时效复核**：这份文件是否仍有效、所引条号是否仍成立、链接是否指向官方原文；
- 全库链接**全量实测**，不抽样；
- 确实查不到官方原文的，**如实写「查不到」**，不编造来源、不拿聚合站或商业法规库凑数；
- 只能找到媒体转载的，保留链接但**明确标注「媒体来源，官网未检得原始页面」**。

**没做的、也做不到的：**

- **不保证实时。** 本指南的更新周期以月计，政策可以以周为单位变；
- **不保证覆盖你的城市。** 「各地差异」一节是取证，不是穷举；
- **不代替官方口径。** 窗口受理人员依据的现行文件，永远优先于本指南。

## 授权与转载

本指南采用 **Creative Commons Attribution-ShareAlike 4.0 International（CC BY-SA 4.0，署名—相同方式共享 4.0 协议国际版）** 授权。

**你可以自由地：** 复制、发行、修改、改编，**包括商业目的**。

**惟须遵守：**

- **署名（BY）**——给出适当署名、附协议链接，并**注明是否作了修改**；
- **相同方式共享（SA）**——你的演绎作品必须以**相同协议**分发；
- **不得增加额外限制**——不得用法律或技术手段限制他人做本协议允许的事。

**署名格式：**

```text
《城市生活指南》 作者：future2017
来源：https://github.com/future2017/CityLifeGuide
协议：CC BY-SA 4.0 — https://creativecommons.org/licenses/by-sa/4.0/
```

如果作了修改、删减或整合，须加注一句，例如：

```text
本文基于《城市生活指南》原文修改，原作者 future2017，CC BY-SA 4.0。
```

> 协议要求署名方式「适当」——**建议放在正文里能看见的位置，而不是藏在页脚链接中**。
