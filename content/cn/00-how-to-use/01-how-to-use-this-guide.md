# 这本指南怎么用

> ⏱ 本文信息采集于 **2026-09**。这一篇讲的是阅读方法，本身不涉及会变的政策；但正文每一条都会变，动手前请用条目末尾的「信息核实方式」确认一次。

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 这不是一本从头读到尾的书，是一本「遇到事再翻」的工具书 |
| **两个入口** | 知道要办什么事 → 看正文章节；只知道出了问题 → 看附录 C 场景索引 |
| **先看哪一节** | 刚搬到一座城市，从第 1 部分「身份与证件」看起，其余按需查 |
| **读一条要多久** | 每条开头有「30 秒速览」五行表；有急事只读它就能办事 |
| **最大的坑** | 把本文当最终依据。政策和地方细则会变，动手前必须再核一次 |

## 一句话结论

**你不需要读完整本书，只需要在办事之前找对那一条。**

每条只回答一个问题——「要不要叫救护车」和「急诊账单怎么核」是两个问题，就是两条。所以正确的用法是：先想清楚自己卡在哪一步，再去查那一步。

> 通读一遍不是学习，是浪费时间。这本书的价值在你带着具体问题翻它的那一刻。

## 两个入口：按领域查，还是按场景查

这是本指南与普通攻略最根本的区别。只有领域分类，新手会不知道该从哪节看起；只有场景分类，具体事务又检索不到。所以两条路都留了。

| 入口 | 什么时候用 | 在哪 |
|---|---|---|
| **按领域**（主轴） | 你已经知道要办的是什么事，来查具体怎么办 | 第 0–12 部分正文章节 |
| **按场景**（第二入口） | 你只知道遇上了麻烦，不知道该办什么 | 附录 C 场景索引 |

举例：你清楚「我要办异地就医备案」——直接翻 4.4。你只知道「我要去外地看病，医保会不会不认」——翻附录 C，它会把你指到 4.4 和 3.2。

## 一个条目里有什么

每个条目都按同一套结构写，顺序固定，所以你翻第二条时不用重新适应：

| 部分 | 回答什么 |
|---|---|
| ⚡ 30 秒速览 | 不读完也能办事的最小信息集 |
| 一句话结论 | 这件事的本质是什么，值不值得花力气 |
| 适用情形 | 你属于哪一类，分类会带来什么待遇差异 |
| 需要准备什么 | 材料清单，并注明哪些其实**不需要** |
| 去哪里办 | 线上渠道、线下窗口、办事话术 |
| 多久办完 / 费用 | 时效与钱，免费项和真正的成本分开写 |
| 办不成怎么办 | 按发生顺序排列的失败场景与对应处理 |
| 常见错误 | 别人踩过的坑，通常能省你一次白跑 |
| 各地差异 | 「同一件事、各地怎么办」的取证表 |
| 信息核实方式 | 官方入口，提醒你本文不能作为最终依据 |
| 行动清单 | 照着做就行的一串动作 |

## 怎么用「30 秒速览」

速览块是一张五行表，每格不超过 60 字、不换行。它的作用是让你在窗口排队时也能读完。

**速览块只复述正文里已经写过的内容**，不会出现正文没有的事实、数字或来源——所以你不用怀疑「速览里的数字是不是另有出处」。想知道为什么，往下读；不想知道，照做即可。

## 一件事该怎么查

1. **先说清自己要办什么。** 一句话写下来，比如「我要把外省的社保转过来」。写不清楚，多半是还没定位到具体问题。
2. **查附录 C。** 用你这句话里的关键词找场景条目，它会指向正文。
3. **读速览。** 判断这件事要不要现在办、值不值得办。
4. **读「需要准备什么」和「去哪里办」。** 这两节决定你跑几趟。
5. **读「办不成怎么办」。** 出发前读，比被退回后再读有用得多。
6. **动手前核一次来源。** 用条目末尾的「信息核实方式」，花两分钟。
7. **照着「行动清单」做。**

## 关于城市：为什么各地做法不一样

同一件事，各地做法常常不一样——落户门槛、社保基数、车牌获取、入学条件，几乎没有全国统一的。

本指南的处理方式是：**先写全国通用的规则，再把各地的具体做法作为证据列在「各地差异」表里**，而不是给每座城市写一篇。

需要提醒你的是：各地差异一节的作用是**举证**，不是替你下结论。它的每一行都标了来源，你可以顺着来源自己核实。

## 信息核实方式

| 你想核什么 | 去哪核 |
|---|---|
| 法律法规原文、是否现行有效 | 国家法律法规数据库 `flk.npc.gov.cn` |
| 国家层面的政策文件 | 中国政府网 `gov.cn` → 政策文件库 |
| 部委规章与办事规定 | 对应部委官网（人社、医保、卫健、公安、税务等） |
| 本地细则与办事指南 | 本地政务服务网 / 本地主管部门官网 |
| 具体窗口口径、临时通知 | 12345 政务服务便民热线 |

> 本文不能作为最终依据。窗口办事以受理人员依据的现行文件为准——这既是法律上的常识，也是实情。
