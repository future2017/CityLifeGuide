# 无犯罪记录证明等常用证明的开具

> ⏱ 本文信息采集于 **2026-11**。同一张证明，各省的线上入口、有效期、受理材料并不一致，动手前请用文末的「信息核实方式」确认一次。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 常用证明大多已能线上开、免费开；先分清「法定由谁开」，别去社区和派出所白跑 |
| **要带什么** | 身份证；在居住地办无犯罪记录证明要居住证；委托办理要委托书和受托人身份证 |
| **去哪办 / 找谁** | 无犯罪记录证明找户籍地或居住地派出所及省级公安平台；社保、医保、个税各走各的平台 |
| **多久 / 多少钱** | 无犯罪记录证明当场或 3 个工作日；社保、医保、个税记录即时；多数证明不收费 |
| **最大的坑** | 无犯罪记录证明只查刑事犯罪，行政拘留、交通违法不在内；有效期各地不同 |

## 一句话结论

**先判断这张证明「法定由谁开」，再决定线上还是线下：公安业务走派出所和省级公安平台，社保、医保、个税走各自官方平台，单位内部事实（在职、收入）只能由单位开。** 绝大多数常用证明已能免费线上办；真正浪费时间的是跑错部门——去社区开无犯罪记录证明、去派出所开收入证明，都会被拒。

证明不是越多越好。用证单位要求某项证明，应当说得出法律法规依据；说不出，你有权要求它共享核验。

## 适用情形

| 你要办的事 | 通常需要的证明 | 法定出具方 |
|---|---|---|
| 入职、政审、入党、参军 | 无犯罪记录证明 | 公安机关 |
| 出国留学、移民、部分签证 | 无犯罪记录证明（可能还要公证、认证） | 公安机关＋公证处 |
| 集体户、社区公共户办事，户口簿不在手边 | 户籍事项证明 | 公安机关 |
| 父母子女不在同一户口簿，办继承、入学、出国 | 亲属关系证明 | 派出所或公证处 |
| 子女入学、居住证、车牌、考驾照 | 居住证明 | 居住证或居住登记信息 |
| 落户、买房、贷款、劳动仲裁 | 社保／医保参保证明、个人缴费记录 | 人社部门、医保部门 |
| 贷款、签证、租房、入职背景调查 | 在职证明、收入证明 | 用人单位、银行、税务机关 |
| 求职、考资格证、升学 | 学历学位信息 | 学信网（学历认证另有流程，本文不展开） |

## 六类证明，分别怎么开

### 1. 无犯罪记录证明（重点）

这是最常被问、也最容易跑错的一项。它证明的是你有没有刑事犯罪记录，依据是公安部《公安机关办理犯罪记录查询工作规定》（公通字〔2021〕19号），2021 年 12 月 31 日起施行，现行有效。

**它证明什么，不证明什么**

- 只证明你有没有**刑事犯罪记录**，也就是有没有人民法院生效裁判确认有罪。
- 涉嫌犯罪但法院尚未作出生效判决、检察院不起诉、办案单位撤案或终止侦查的，法律上属于**无犯罪记录人员**。
- **行政拘留、治安罚款、交通违法、吸毒记录都不属于犯罪记录**。北京的实施细则明确，行政强制、行政处罚和其他行政处理不属于犯罪记录。所以「无违法犯罪记录证明」与「无犯罪记录证明」不是一回事。
- 犯罪时不满 18 周岁、被判处五年有期徒刑以下刑罚的，犯罪记录依法封存；个人查询时，公安机关应当出具《无犯罪记录证明》。

**谁能查**

| 查询主体 | 规则 |
|---|---|
| 本人 | 可以查，也可以委托他人代查；受托人须有完全民事行为能力 |
| 单位 | 只能查本单位在职人员或拟招录人员，且必须符合法律、行政法规关于**从业禁止**的规定 |
| 行政机关、公证处 | 实施行政许可、授予职业资格、办理犯罪记录公证时，可以依法查询 |

「公司想查就查」是错的。单位查询要提交介绍信、经办人身份证、加盖公章的申请表，并在申请表上写明所依据的具体法律条款。拿不出从业禁止依据的，公安机关可以不予受理。

**「跨省通办」的真实含义**

规定第五条写得很清楚：中国公民申请查询，由**户籍地或者居住地**公安派出所受理。你不必回户籍地，在常住地就能办——这就是「跨省通办」的全部含义。它**不是**「随便找个派出所都能办」：在居住地办必须持有当地**居住证**；受理回执不行，居住证过期也不行，得先续期。

**要带什么**

| 在哪办 | 材料 |
|---|---|
| 户籍地 | 本人有效身份证明＋查询申请表 |
| 居住地 | 本人有效身份证明＋**居住证**＋查询申请表 |
| 委托他人 | 上述材料＋委托书＋受托人有效身份证明 |
| 一年内查询超过 3 次 | 还要提交「开具证明用于合理用途」的材料 |

申请表可在窗口领取，多数省份线上平台会自动生成。照片、户口簿（有身份证时）、单位介绍信（个人查询）都不需要。

**多久、多久有效**

- 能当场办的当场办；不能当场办的，出具《受理回执》，**3 个工作日内**办结。情况复杂需要调查核实的，调查时间不计入这 3 个工作日。
- 上海「一网通办」把承诺时限压到 **1 个工作日**，法定时限仍是 3 个工作日。
- **有效期全国没有统一规定。** 北京注明「自开具之日起 3 个月内有效」；其他地区以证明文本和用证单位要求为准。**先问用证单位「要多久以内开的」**，别提前半年办好放到过期。

**费用**：不收费。上海「一网通办」办事指南的收费信息栏明确写「是否收费：否」。

### 2. 户籍证明

先记住一条：**居民户口簿、居民身份证、护照是法定身份证件**，它们能证明的事项，派出所不再出证明。2016 年公安部等 12 部门的意见列了 9 类——姓名、曾用名、性别、身份号码、民族、出生日期、出生地、籍贯、户籍所在地住址；另有 5 类只要户口簿能证明也不再出，包括户口迁移、住址变动、项目变更更正、注销户口、同户亲属关系。

现实中的「户籍证明」，多指《户籍事项证明》，主要用于：你是单位集体户、学生集体户、社区公共户，手里没有户口簿；或者办事单位只认一张载有当前户籍信息的纸。上海的做法是：这三类人员通过「随申办」申请，原则上 **60 分钟内**出具；历史户籍信息证明可到派出所走「跨省通办」，原户籍地派出所 **5 个工作日内**完成核查。全国范围也已在 2021 年底实现开具户籍类证明「跨省通办」。

**注意**：它不能替代户口簿办要求「户口簿原件」的业务（如婚姻登记），也不证明婚姻状况。

### 3. 亲属关系证明

按难易程度分三条路走，别一上来就去公证处花冤枉钱：

1. **在同一户口簿上**——用户口簿即可，派出所不再出具证明。
2. **曾经同户、后来分户**——到派出所查历史户籍档案，档案能反映的，派出所核实后应当出具。
3. **从没同户，或档案查不到**——用《出生医学证明》、结婚证、独生子女证、人事档案等材料证明；仍不够的，办**亲属关系公证**。

社区（居委会、村委会）**不再出具**亲属关系证明。民政部等 6 部门的民发〔2020〕20 号文把它列入「不应由基层群众性自治组织出具证明事项清单（第一批）」第 1 项，办事途径是信息共享，或提供户口簿、结婚证、出生医学证明；曾经同户的由派出所出。文件留了一个例外：不动产登记、公证办理情况除外——这两种场景仍可能需要派出所证明。

### 4. 居住证明

全国没有统一格式、统一名称的「居住证明」。真正有法律效力的是两样：

- **居住证**——《居住证暂行条例》定义的法定凭证，证明你在这个城市常住；
- **居住登记信息**——还没领到居住证时，公安系统里的居住登记记录，部分城市可打印《居住登记查询单》。

子女入学、车牌、考驾照、办护照，认的都是居住证或居住登记信息，不是物业、房东、社区手写的一张纸。上海已经从 2023 年起明确，居村组织不再出具 44 项证明，其中就包括水电燃气开户、多人口基数优惠等场景的居住证明。

**别买假居住证明。** 用虚假材料骗领居住证，按《居住证暂行条例》可处 200 元以下罚款；拿它办入学、车牌，资格会被撤销。

### 5. 社保、医保参保证明与个人缴费记录

这两类要分开看，**多数地区社保和医保已是两个系统**，拿社保参保证明去办医保的事，会被退回。

**社保参保证明**（养老、失业、工伤等）

- 线上：国家社会保险公共服务平台（si.12333.gov.cn）、电子社保卡小程序、「掌上 12333」APP；
- 线下：参保地社保经办窗口，带身份证或社保卡；
- 官方办事指南写明：**可异地查询打印，不受地域限制；即时办结；免费；网上办理无需材料**；
- 内容包括参保起止时间、缴费月数、缴费基数、险种，可用于落户、买房、入学、贷款和仲裁。

**医保参保证明和缴费记录**

- 线上：国家医保服务平台 APP，或参保地医保平台（福建「闽政通」和「福建医疗保障」小程序、广东「粤医保」等）；
- 内容：参保状态、险种、缴费明细、个人账户余额；
- 需要「医保参保凭证」办转移接续的，走医保平台，不要打印社保的养老对账单代替。

**个人权益记录**是你的法定权利：《社会保险法》规定，个人可以免费查询、核对其缴费和享受待遇记录。单位漏缴、少缴的，先走社保稽核，必要时再申请劳动仲裁——参保证明就是最直接的证据。

### 6. 在职证明与收入证明的边界

这两张纸经常被混为一谈，但它们的法律性质完全不同。

**在职证明**：法律没有规定用人单位必须给在职员工开在职证明。唯一明确的法定义务是——《劳动合同法》第五十条要求，用人单位在**解除或者终止**劳动合同时出具离职证明。所以「公司不给我开在职证明」本身不违法，只能协商；但公司不能扣着你的离职证明不开。

**收入证明**：同样由单位自愿出具，社区不再出具。民发〔2020〕20 号文第 17 项把「收入证明、经济状况证明、偿还能力证明」列入社区不应出具清单，改由信息共享或提供相应凭证。

**能写与不该写**：

| 能写 | 不该写 |
|---|---|
| 你的姓名、身份证号、岗位、入职时间、用工形式 | 对你的还款能力、信用状况作担保 |
| 本单位实际发放的工资数额（税前／税后要写明） | 把奖金、报销、他人收入拼成一个好看的年薪 |
| 准假时间、出国事由（签证用） | 与你实际劳动关系不符的职务或收入 |

银行和签证官更认三样能互相印证的材料：**工资流水**（银行打印可盖章）、**个税纳税记录**（个税 APP 开具）、**社保缴费基数**。三者对不上，收入证明写得再高也会被质疑。

**红线**：单位虚开收入证明帮员工骗贷，单位及相关人员也可能被追责；个人伪造印章、流水，轻则拒贷记入征信，重则涉嫌犯罪。

## 哪些证明已经取消，别再跑了

| 证明 | 现状 | 你该用什么 |
|---|---|---|
| 婚姻状况证明（「单身证明」） | 民政部门 2015 年起不再出具，仅涉台公证和 9 个国家公证事项例外 | 结婚证、离婚证、法院生效裁判文书、离婚证明书、个人声明 |
| 无犯罪记录证明（社区版） | 社区不再出具 | 公安机关 |
| 亲属关系证明（社区版） | 社区不再出具 | 户口簿、出生医学证明、派出所、公证处 |
| 户籍证明（社区版） | 社区不再出具 | 户口簿、身份证、公安《户籍事项证明》 |
| 收入证明、财产证明（社区版） | 社区不再出具 | 单位、银行流水、个税记录、不动产权证 |
| 姓名、性别、民族、出生日期等 9 类身份信息证明 | 派出所不再出具 | 身份证、户口簿、护照 |
| 健在证明、死亡证明、出生证明（社区版） | 社区不再出具 | 卫健部门、医疗机构、公安、法院按各自程序 |

民政部那份清单共 20 项，还包括居民养犬证明、人员失踪证明、残疾状况证明、婚育状况证明、居民就业状况证明、遗产继承权证明、证件遗失证明等。

**但清单不是办事单位的「拒绝清单」**，而是告诉它「这件事不该找社区」。政策衔接不到位、企业又明确要求时，社区对属于自身职责且能核实的事项，仍可据实出具。真正的解法是让用证单位走信息共享，或换用法定替代材料。

## 需要准备什么

| 证明 | 要带 | 其实不需要 |
|---|---|---|
| 无犯罪记录证明 | 身份证；居住地办理加居住证；委托加委托书、受托人身份证 | 照片、户口簿（有身份证时）、单位介绍信（个人查询） |
| 户籍事项证明 | 身份证；集体户带户籍卡或常住人口登记卡 | 户口簿原件（集体户通常没有） |
| 亲属关系证明 | 户口簿、出生医学证明、结婚证、历史户籍档案 | 社区证明、单位证明 |
| 居住证明 | 居住证，或居住登记信息 | 物业证明、房东手写证明 |
| 社保参保证明 | 线上无需材料；窗口带身份证或社保卡 | 劳动合同、单位介绍信 |
| 医保参保证明 | 医保电子凭证或身份证 | 社保卡（电子凭证即可） |
| 个税纳税记录 | 个税 APP 实名登录 | 税务局窗口排队（线上可开） |
| 在职／收入证明 | 单位模板、劳动合同、工资流水 | 社区盖章 |

**电子版与纸质版**：线上证明多数带电子印章和二维码，扫码即可核验，效力与纸质版相同。需要纸质的可自行打印或选择邮寄（邮费自付）。**先问用证单位收不收电子版**，能收就不必多跑。

## 去哪里办

| 证明 | 线上入口 | 线下 |
|---|---|---|
| 无犯罪记录证明 | 省级公安平台：北京「京通」、上海「随申办」、广东「粤省事」、山东「爱山东」、湖南「湘易办」、浙江「浙里办」等 | 户籍地或居住地派出所；部分地区政务大厅公安窗口 |
| 户籍事项证明 | 上海「随申办」、长三角「一网通办」；其余看本地公安 | 户籍地派出所 |
| 亲属关系证明 | 多数地区需线下查档案 | 派出所户籍窗口；公证处 |
| 居住证明 | 本地公安公众号、政务 APP | 派出所、社区事务受理中心 |
| 社保参保证明 | 国家社会保险公共服务平台、电子社保卡、掌上 12333 | 社保经办窗口、自助机 |
| 医保参保证明 | 国家医保服务平台 APP、本地医保小程序 | 医保经办窗口 |
| 个税纳税记录 | 个人所得税 APP → 证明开具 → 纳税记录开具 | 办税服务厅 |
| 在职／收入证明 | 无统一线上入口 | 单位人事部门 |

全国层面的总入口是**国家政务服务平台**（gjzwfw.www.gov.cn）的「跨省通办」专区，可以按事项查各省入口；但它多数时候只是跳转，真正受理的仍是省级平台。

**办事话术**（到窗口直接说这一句）：

> 「我要开**无犯罪记录证明**，本人在**户籍地／居住地**申请，带了身份证和居住证，请给我一张查询申请表。」

材料不齐时，加一句：「**麻烦一次性告知需要补哪些材料。**」这是《公安机关办理犯罪记录查询工作规定》第七条给你的权利：材料不全的，应当一次性告知。

## 多久办完

| 证明 | 时限 | 依据 |
|---|---|---|
| 无犯罪记录证明 | 能当场办则当场；否则受理后 **3 个工作日** | 公通字〔2021〕19号第八条 |
| 无犯罪记录证明（上海） | 承诺 **1 个工作日** | 上海一网通办 |
| 户籍事项证明（上海，集体户等） | 原则上 **60 分钟**内 | 上海市公安局 2026-06 |
| 户籍证明「跨省通办」 | 原户籍地核查 **5 个工作日**，反馈后即出具 | 上海市公安局 2026-06 |
| 社保参保证明 | **即时办结** | 人社部办事指南 |
| 医保参保证明 | 线上即时生成 | 各地医保平台 |
| 个税纳税记录 | 线上即时生成 | 个税 APP |
| 亲属关系证明 | 当场或查档案后出具，无全国统一时限 | 以受理单位为准 |
| 在职／收入证明 | 无统一时限，按单位内部流程 | 以单位为准 |

**留余量**：3 个工作日是法定上限，不是承诺；需发函核查、跨省协查的会更长。有硬截止日的事，按**一周**预留。

## 办不成怎么办

按发生顺序排列，遇到哪一步看哪一条：

**1. 线上找不到入口，或实名认证失败**
按「省级公安 APP → 微信／支付宝小程序 → 国家政务服务平台 → 线下派出所」逐级换渠道。实名失败多是手机号与公安登记不一致，连续失败就直接去窗口。

**2. 在居住地办，被告知「没有居住证办不了」**
这是规定，不是刁难。先去办居住证或续期；居住证受理回执通常不被认可。实在来不及，回户籍地办。

**3. 派出所说「户籍证明开不了」**
先确认你要证明什么。姓名、身份证号、户籍地址这类身份证或户口簿能证明的事，确实不再出具，拿户口簿去用证单位即可；如果是集体户、户口簿不在手边，要求开《户籍事项证明》，或走「跨省通办」。

**4. 社区不给开亲属关系、收入、居住证明**
这是民发〔2020〕20 号文的明确要求，争论没有用。改用：户口簿、出生医学证明、结婚证、派出所历史户籍档案、单位证明、银行流水、个税记录。

**5. 单位要求你提供无犯罪记录证明，但说不清依据**
个人自愿去开不影响你；但单位要**自行查询**，必须符合从业禁止的法律规定。可要求 HR 说明依据，或改为「本人提供证明」。

**6. 证明开出来，用证单位说过期了**
全国没有统一有效期，用证单位可要求「近 3 个月」内开具。问清口径，重开一份即可；无犯罪记录证明重开不收费。

**7. 查询结果有误，或你认为记录不应显示**
向原受理单位提交书面异议申请复查。复查结果应在受理后 **15 个工作日内**书面答复；情况复杂可延长，最多再延 **30 个工作日**。认为判决本身有误的，走申诉程序。

**8. 社保记录缺失、单位漏缴**
先在社保平台查明细，确认是「没缴」还是「没显示」。单位漏缴的向社保稽核部门投诉；影响落户、买房的，保留参保证明和劳动合同。

**9. 被收「加急费」「代办费」**
要求出具收费依据。这些证明都没有加急收费项目；遇到窗口或个人索要，记下工号，拨 12345 或 12389 反映。

## 常见错误

1. **把「无犯罪记录」当成「无违法犯罪记录」。** 行政拘留、治安处罚、交通违法都不在犯罪记录里，别自己吓自己。
2. **以为任意派出所都能办。** 只有户籍地、居住地（持居住证）可以；「跨省通办」不等于「全国漫游」。
3. **拿居住证受理回执去办。** 深圳公安明确答复：受理回执属于尚未取得居住证，不能作为居住地申请的依据。
4. **提前很久开证明。** 北京写 3 个月，别处可能更短；用证单位只认「近期」的，开早了等于白开。
5. **让单位「帮我查一下」。** 单位查询要有从业禁止的法律依据，个人查询才是你的权利。
6. **去社区开亲属关系、收入、居住证明。** 这三类都已列入社区不应出具清单，去了也是白跑。
7. **拿社保参保证明当医保参保证明。** 多数地区两个系统分开，险种对不上会被退件。
8. **让单位把收入写高一点。** 银行会拿流水和个税记录交叉核对；虚开对单位和个人都是风险。

## 各地差异

> 下表是**取证**，不是完整对照；每行都标了来源，可顺着来源自行核对。全国性规定用「全国：」起头。

| 事项 | 各地做法 | 来源 |
|---|---|---|
| 无犯罪记录证明的受理地 | **全国**：户籍地或居住地公安派出所受理；居住地须持居住证；外国人居留 180 天以上由居住地县级以上公安出入境受理 | 公通字〔2021〕19号第五条、第六条 |
| 无犯罪记录证明的线上入口 | **北京**：本市户籍居民可网上申请，受理机关为户籍地派出所；**上海**：「随申办」可办，0 次到现场；**广东深圳**：统一在「粤省事」申请，可邮箱送达、全国邮寄；**山东**：2026-06-30 起省外户籍持居住证也可全程网办，未持居住证的可「居住登记＋居住证申领＋无犯罪记录证明」一件事联办 | 京公法字〔2022〕337号第十四条；上海一网通办；深圳市公安局 2023-08-10 访谈；青岛政务网 2026-06-30 |
| 无犯罪记录证明的有效期 | **全国**：规定未设统一有效期；**北京**：证明式样注明「自开具之日起 3 个月内有效」 | 公通字〔2021〕19号；京公法字〔2022〕337号附件 6 |
| 无犯罪记录证明的收费 | **上海**：不收费（办事指南「是否收费：否」） | 上海一网通办 |
| 户籍类证明 | **全国**：户口簿、身份证、护照能证明的 9 类事项，派出所不再出具；**上海**：集体户、学生户、社区公共户可在「随申办」开《户籍事项证明》，原则上 60 分钟内出具；历史户籍信息证明走「跨省通办」，原籍核查 5 个工作日 | 公通字〔2016〕21号；上海市公安局 2026-06-23 |
| 亲属关系证明 | **全国**：同户凭户口簿；曾经同户由派出所查历史档案后出具；社区不再出具（不动产登记、公证除外） | 公通字〔2016〕21号第二条第 3 项；民发〔2020〕20号附件第 1 项 |
| 居住证明 | **全国**：无统一格式，以居住证或居住登记信息为准；**上海**：居村组织不再出具 44 项证明，含水电燃气开户等场景的居住证明 | 《居住证暂行条例》；沪委办〔2023〕12号 |
| 社保参保证明 | **全国**：国家社会保险公共服务平台可异地查询打印，不受地域限制，即时办结，免费 | 人社部「个人社保参保证明查询打印」办事指南 |
| 医保参保证明 | **福建**：「闽政通」APP、「福建医疗保障」微信小程序可开参保证明和缴费明细；**全国**：国家医保服务平台 APP 可查参保信息 | 福建省医保局 2026-02-06；国家医保服务平台 |
| 个税纳税记录 | **全国**：2019-01-01 起以《纳税记录》替代《税收完税证明》（文书式），可在个人所得税 APP「证明开具」中生成 | 国家税务总局公告2018年第55号；北京市税务局 2026-03-19 |
| 收入证明 | **全国**：社区不再出具收入、财产、偿还能力证明，改由单位、银行流水、个税记录等证明 | 民发〔2020〕20号附件第 17 项 |

## 信息核实方式

| 你想核什么 | 去哪核 |
|---|---|
| 无犯罪记录证明的全国规则 | 公安部官网查公通字〔2021〕19号原文；国家法律法规数据库 `flk.npc.gov.cn` |
| 本省线上入口、材料、时限 | 本省公安厅／公安局官网，或省级政务 APP 的办事指南；国家政务服务平台「跨省通办」专区 |
| 户籍类证明能否跨省办 | 现居住地派出所；上海可查「随申办」户籍事项证明页面 |
| 社保参保、缴费记录 | 国家社会保险公共服务平台 si.12333.gov.cn；电子社保卡；12333 热线 |
| 医保参保、缴费记录 | 国家医保服务平台 APP；参保地医保局；12393 热线 |
| 个税纳税记录 | 个人所得税 APP；12366 热线 |
| 某张证明是否已取消 | 中国政府网搜「证明事项清单」；本地政务服务网搜证明名称 |
| 乱要证明、乱收费 | 12345；公安督察 12389 |

## 行动清单

- [ ] 先问用证单位：要哪种证明、有效期要求、收不收电子版
- [ ] 判断法定出具方：公安、人社、医保、税务或单位
- [ ] 无犯罪记录证明：确认在户籍地还是居住地办，居住地先检查居住证是否有效
- [ ] 一年内已查过 3 次的，准备好「合理用途」说明材料
- [ ] 亲属关系先翻户口簿和出生医学证明，别再跑社区
- [ ] 社保、医保、个税记录优先线上开，截图保存 PDF 和二维码
- [ ] 遇到要收费、要代办、要「加急」的，先要依据再付款
