# 附录 C · 场景索引

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 按「你身上出了什么事」找，不按部门名找 |
| **怎么定位** | 用一句话写下处境，在下面十一组场景里挑最像的那一行 |
| **跨条目的问题** | 对上两三条时先办最急的：人身危险看 11.1，钱要不回看 2.3 或 5.6 |
| **找不到时** | 新规看 0.2 自己核；跨领域问题拆开分别查 |
| **最大的坑** | 把住房、婚姻、学区混成一件事，结果一条都没办成 |

> 正文按「领域」排，这一页按「你身上出了什么事」排。你不需要知道该找哪个部门，只需要认出自己的处境，然后翻到对应那一节。

---

## 怎么用这一页

先找最像你处境的那一句，不要找最接近的部门名。比如「房东把我赶出来了」，听起来像住房问题，但真正要办的是证据固定加报警，落在 2.3 和 11.1，而不是 2.5 买房资格。

一句话能对上两三个条目的，说明你的问题还没拆开——先办最急的那一步：有人身危险先看 11.1，钱要不回来先看 2.3 或 5.6，手续办不下去先看对应的办理条目。

## 找不到对应场景怎么办

三种情况：

**一是问题太新。** 比如平台新规、地方新政刚落地，正文还没覆盖。先看 0.2 信息时效性与核实方法，按里面的核实顺序自己查一遍，比等更新快。

**二是问题跨了好几节。** 比如「离婚后房子归谁、贷款还没还完、孩子学区怎么办」，这是 6.7 加 7.2 两个问题，分开查，不要指望一条解决。

**三是你的处境需要的是人，不是文章。** 有人身危险，直接 110；有自伤念头，直接 4.16 里的危机热线或 120；涉及刑事，直接 11.2 找律师。这一页只帮你少走弯路，不替代紧急处置；本指南的适用范围与责任边界，见 0.3。

## 行动清单

1. 用一句话写下你现在的处境，不要写部门名。
2. 在上面十一组里找到最像的那一组，挑一行。
3. 读那一节的「30 秒速览」，五行读完还不能办事，再读正文。
4. 涉及钱和期限的，把正文里的「多久办完」「费用」两节抄到手机备忘录。
5. 办完把工单号、受理编号、经办人姓名记在同一处，后续维权全靠它。
