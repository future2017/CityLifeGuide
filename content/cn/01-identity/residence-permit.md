# 居住证：条件、材料、积分、签注

> ⏱ 本文信息采集于 **2026-09**。申领门槛、签注规则、落户衔接方式各城市不同，动手前请用文末的「信息核实方式」确认一次。

---

## ⚡ 30 秒速览

| | |
|---|---|
| **结论** | 离开户籍地到别的城市住满半年就该办；它不是户口，但很多公共服务的门要靠它开 |
| **要带什么** | 身份证、相片，加上「住址／就业／就读」三类证明之一；住址证明用租房合同就行 |
| **去哪办 / 找谁** | 居住地公安派出所，或受公安机关委托的社区服务机构；多在政务服务网或本地公安小程序可预约 |
| **多久 / 多少钱** | 受理后 15 日内发证（最长不超 30 日）；首次申领**免工本费**、签注不收费 |
| **最大的坑** | 忘了每年签注——使用功能中止，补办后**居住年限从补办之日起重新计算**，积分和入学年限全部清零 |

## 一句话结论

**居住证是「你在常住地能享受什么」的凭证，不是户口。**

《居住证暂行条例》给它的定义是：持证人在居住地居住、作为常住人口享受基本公共服务和便利、**申请登记常住户口**的证明。所以它一头连着当下的公共服务（义务教育、就业服务、公共卫生、法律援助等），一头连着未来的落户通道（积分落户要在它基础上算年限）。

两件事因此变得重要：**办得早**（居住年限早开始积累），和**别断签注**（断了年限重算）。

> 让居住证一直有效，比让它办得快更值钱。

---

## 谁需要办、什么时候办

### 法定条件（《居住证暂行条例》第二条）

同时满足两条即可申领：

1. 离开常住户口所在地，**到其他城市居住半年以上**；
2. 符合**合法稳定就业**、**合法稳定住所**、**连续就读**条件**之一**。

注意第二条第 2 项是「之一」——有工作、有住处、在上学，满足任意一条就行，不需要三条齐全。

### 谁通常会用到它

| 你的情况 | 为什么需要 |
|---|---|
| 跨市县工作、租房居住 | 异地办身份证、办出入境证件、考职业资格、买车登记都要它 |
| 随迁子女要上学 | 多数城市把「持居住证 + 社保/居住年限」作为入学条件的前置 |
| 打算在这个城市落户 | 特大超大城市的积分落户以居住年限、社保年限为基本指标 |
| 灵活就业、自由职业 | 在就业地参加社保、办理相关业务时常用到 |
| 外地户籍在本地考驾照、上牌 | 属于条例列明的「便利」事项 |

### 谁不需要

- **本地户籍人员**——你的身份凭证是户口簿和身份证，不需要居住证；
- **短期出差、旅游、就医**——不满足「居住半年以上」，不属于居住证的情形；
- **在同城的区县之间搬家**——不构成「离开常住户口所在地」。

## 居住登记、居住证、户口：三件事别混

这是最常被混淆的一组概念，混了会实实在在白等时间：

| | 居住登记 | 居住证 | 户口 |
|---|---|---|---|
| **是什么** | 向公安机关申报「我住在这里」 | 常住人口享受基本公共服务和便利、并申请登记常住户口的**证明** | 法定的户籍关系 |
| **什么时候办** | 到居住地之后尽早办 | 登记并居住满半年后申领 | 符合本地落户条件时才能办 |
| **主要作用** | **居住时长的起算依据** | 义务教育、就业服务、证件办理等 | 户籍地的一切权利与义务 |
| **成本** | 免费 | 首次申领免费 | 门槛最高，多数城市要排队或积分 |
| **办错了的代价** | 白等半年 | 签注断了年限重算 | 影响最广，但最难补救 |

**关键一点**：很多城市的「居住半年」是从**居住登记**之日起算的，不是从你搬进去那天算起。搬进新城市当天或当周就去登记，是最省事的做法。

---

## 有了它，具体能开哪些门

《居住证暂行条例》第十二条、第十三条把这些权利分成两类。下面标注了它对应到生活里的哪件事。

**基本公共服务（第十二条）**

| 条例表述 | 对应到你的什么事 |
|---|---|
| 义务教育 | 随迁子女在居住地入学的基本前置条件之一 |
| 基本公共就业服务 | 就业登记、职业介绍、创业扶持等 |
| 基本公共卫生服务和计划生育服务 | 居民健康档案、部分公共卫生服务项目 |
| 公共文化体育服务 | 图书馆、文化馆、公共体育设施等 |
| 法律援助和其他法律服务 | 符合经济困难条件的可申请法律援助 |
| 国家规定的其他基本公共服务 | 兜底条款，各地随财力逐步扩大 |

**便利事项（第十三条，共 7 项）**

| 条款项 | 对应到你的什么事 |
|---|---|
| 按照国家有关规定办理出入境证件 | 异地办护照、往来港澳台证件 |
| 按照国家有关规定换领、补领居民身份证 | 身份证到期、丢失时不必回户籍地 |
| 机动车登记 | 给车上本地牌照 |
| 申领机动车驾驶证 | 报驾校、考驾照 |
| 报名参加职业资格考试、申请授予职业资格 | 考教师资格、会计、建造师等 |
| 办理生育服务登记和其他计划生育证明材料 | 生育登记等 |
| 国家规定的其他便利 | 兜底条款 |

**注意**：条例第十四条要求各地「逐步扩大」范围并**定期向社会公布**。也就是说，你所在城市实际能办的事项，**可能比上面这个清单多**——以本地公布的清单为准。

## 需要准备什么

### 法定材料（《居住证暂行条例》第九条）

| 材料 | 说明 |
|---|---|
| 本人居民身份证 | 原件 |
| 本人相片 | 多数地方现场采集，可先问是否需要自备 |
| **住址证明**（三选一） | 房屋租赁合同、房屋产权证明文件、购房合同，或出租人／用人单位／就读学校出具的住宿证明 |
| **或就业证明** | 工商营业执照、劳动合同、用人单位出具的劳动关系证明，或其他能证明合法稳定就业的材料 |
| **或就读证明** | 学生证、就读学校出具的其他能证明连续就读的材料 |

**住址、就业、就读三类证明提供其中一类即可**，不是全都要交。

### 哪些其实不需要

- 不需要「无犯罪记录证明」——居住证申领不设这道门槛；
- 不需要户籍地开具的准迁证、迁移证——那是办户口才用的；
- 不需要向派出所提交社保缴纳明细原件——社保年限核验多由系统比对，具体要求看当地。

### 代办的情形

未满 16 周岁的未成年人，以及行动不便的老年人、残疾人，**可以由其监护人、近亲属代为申领**。代办时要提供委托人和代办人的合法有效身份证件。

## 去哪里办

| 渠道 | 说明 |
|---|---|
| **线下主渠道** | 居住地**公安派出所**，或受公安机关委托的**社区服务机构**（社区事务受理中心一类） |
| **线上** | 多数城市已开通政务 App 或公安小程序预约、预填；深圳等地还有自助申领机 |
| **居住登记先行** | 很多城市要求先做**居住登记**，再申领居住证——登记时间往往就是「居住半年」的起算依据 |

**办事话术**：材料不齐时，第一句可以直接问——「**麻烦一次性告诉我需要补哪些材料**」。这不是请求，是《居住证暂行条例》第九条给你的权利：材料不全的，受理单位**应当一次性告知**需要补充的材料。

## 多久办完

| 环节 | 法定期限 |
|---|---|
| 制作发放 | 公安机关**自受理之日起 15 日内**制作发放 |
| 偏远、交通不便地区 | 设区的市级以上地方人民政府可在实施办法中规定延长，但**最长不得超过 30 日** |
| 签注 | 现场办理，通常即时办结 |

**现实提醒**：15 日是法定上限而非承诺时限，多数城市实际更快；但**入学、摇号等场景请按 1 个月预留**，不要把 15 日当可靠性预期。

## 费用

| 项目 | 收费 |
|---|---|
| **首次申领** | **免收**证件工本费 |
| 换领、补领 | 应当缴纳证件工本费 |
| 办理签注 | **不得收取费用** |

具体收费办法由国务院财政部门、价格主管部门制定，各地执行标准在地方办法里明确（例如广州的补领换领为 20 元工本费）。

> 凡是「代办居住证加急费」「签注手续费」这类名目，条例里都没有依据。签注本身不收费。

## 签注：最容易被忽略、代价最大的一步

### 规则（《居住证暂行条例》第十条）

- 居住证**每年签注 1 次**，由县级人民政府公安机关签发；
- 连续居住的，应当在**居住每满 1 年之日前 1 个月内**，到派出所或受委托的社区服务机构办理签注；
- **逾期未办理签注手续的，居住证使用功能中止**；
- 补办签注手续后，使用功能恢复，但——**持证人在居住地的居住年限，自补办签注手续之日起连续计算**。

### 这一条为什么值得单独看

居住年限是**积分落户、随迁子女入学、部分公共服务资格**的基础变量。逾期补办等于把之前的连续年限清零重新起算。

**建议**：把签注日期记成手机年度提醒，比记生日更重要。

## 居住年限为什么值得早办

积分落户的指标体系里，**居住年限和社保年限通常是最基础、也最稳的两项**——它们不靠学历、不靠职称，只靠时间。时间是你唯一无法临时补上的东西。

**一个示意性的算例**（分值仅用于说明逻辑，实际以本地指标体系为准）：

假设某城市的积分落户中，「居住年限」每年计 2 分、「社保年限」每年计 3 分，两项各设 10 年上限。甲毕业后到该市就办了居住登记和居住证；乙同样条件，但拖了两年才想起来办。到提交申请那一年，乙的居住年限少 2 年、社保年限通常也同步少缴，两项累计可能相差 **10 分左右**。在名额有限的年度里，这个差距往往就是「今年入围」和「再等一年」的区别。

而签注会放大这个差距：**逾期未签注，居住年限自补办之日起重新计算**。一次忘记签注，可能把三年的时间积累一次性归零。

> 居住证上真正值钱的东西不是你手里的那张卡，是系统里那串不会倒退的年限。

## 换领、补领与信息变更

| 情形 | 怎么办 |
|---|---|
| 居住证损坏难以辨认 | 到派出所或受委托的社区服务机构办理**换领**，换领新证时应当交回原证 |
| 居住证丢失 | 同渠道办理**补领** |
| 费用 | 换领、补领**应当缴纳证件工本费**（首次申领才免费） |
| 住址、就业状态变化 | 条例未作统一规定，由地方实施办法确定；**但签注时受理单位会比对你的居住登记信息**，不一致会被要求先更正再签注 |

搬家或换工作后尽早更新信息，别等到签注当天才发现对不上——那时候你只剩一次机会，材料不齐就得改天再来。

---

## 办不成怎么办

按发生顺序排列，遇到哪一步看哪一条：

| 卡在哪 | 怎么办 |
|---|---|
| **材料不齐被退回** | 要求受理单位**一次性告知**需补充的材料（条例第九条） |
| **房东不配合、拿不到租赁合同** | 换用另两类证明——用人单位或就读学校出具的**住宿证明**；或先办居住登记 |
| **社保年限不够（深圳、上海等地门槛型城市）** | 先核清本地口径是「连续」还是「累计」。深圳设了「近 2 年累计满 18 个月」的缓冲；断缴后先补缴再申请 |
| **忘了签注、功能已中止** | 尽快补办签注即可恢复功能，但**居住年限从补办日重算**——越早补办损失越小 |
| **被收「加急费」「代办费」** | 首次申领免工本费、签注不收费；要求出具收费依据，无依据可向主管部门反映 |
| **居住证被单位或中介扣押** | 条例第十八条明确：**非法扣押他人居住证**由公安机关责令改正并可处罚款 |
| **不符合条件被拒** | 要求出具书面决定；对具体行政行为不服，可依法申请行政复议或提起行政诉讼 |

## 常见错误

1. **以为「住了半年」就自动够条件。** 多数城市要求先做**居住登记**，登记记录才是居住时长的凭证。不登记，租多久都算不出来。
2. **把居住证等同于户口。** 它不改变户籍地，也不自动带来落户资格——落户要在它基础上走积分或人才引进通道。
3. **不签注。** 见上一节。这是本条例里对个人最不友好的一条。
4. **轻信「包办居住证」。** 使用虚假证明材料骗领居住证、出租出借转让居住证，都是违法行为，会被处罚。
5. **信息变了不去更新。** 住址、就业状态变化后不更新，签注和后续核验都会卡住。
6. **只在一个城市攒年限，却准备在另一个城市落户。** 居住年限、社保年限**通常按城市分别计算**，跨城的年限互认范围有限，换城市前先查清楚。

## 违规的红线

这部分不是吓唬人，是因为出租人、用人单位和「代办中介」经常踩在前两类上。

| 行为 | 后果 |
|---|---|
| 使用虚假证明材料骗领居住证 | 警告、责令改正，可处 **200 元以下罚款**；有违法所得的没收违法所得 |
| 出租、出借、转让居住证 | 同上 |
| **非法扣押他人居住证** | 同上 |
| 冒用他人居住证，或使用骗领的居住证 | 处 **200 元以上 1000 元以下罚款**；有违法所得的没收 |
| 购买、出售、使用伪造、变造的居住证 | 同上；伪造、变造和骗领的居住证由公安机关收缴 |

**对房东和用人单位的提醒**：「证件先放我这儿保管」不是保管，是**非法扣押他人居住证**——条例第十八条明确列为违法行为。

**对找中介的人的提醒**：声称「不需要你符合条件也能办下来」的中介，做的多半是骗领；一旦被查，承担后果的是持证人本人。

## 各地差异

> 下表是**取证**，不是完整对照；每行都标了来源，可顺着来源自行核对。全国性规定用「全国：」起头。

| 事项 | 各地做法 | 来源 |
|---|---|---|
| 申领的居住时长与社保门槛 | **全国**：离开常住户口所在地、到其他城市居住半年以上，且符合合法稳定就业／住所／连续就读之一即可（不设社保要求）；**北京**：在京居住 6 个月以上，符合稳定就业／住所／连续就读之一；**上海**：合法稳定居住且合法稳定就业、并参加本市职工社会保险满 6 个月，或因投靠、就读、进修需居住 6 个月以上；**深圳**：须同时满足连续居住满 12 个月，且社保连续满 12 个月或近 2 年累计满 18 个月 | 条例第二条；北京市政府令第270号第七条；上海市政府令第2号第九条；《深圳经济特区居住证条例》第十九条 |
| 签注周期与逾期后果 | **全国**：每年签注 1 次，逾期未办使用功能中止，补办后居住年限自补办之日起连续计算；**上海**：每年签注一次，逾期 60 日内补办可恢复；**深圳**：签注以近一年居住登记累计满 8 个月且社保累计满 8 个月为条件 | 条例第十条；上海市政府令第2号第十六条；《深圳经济特区居住证条例》第二十三、二十四条 |
| 申领与补换领费用 | **全国**：首次申领免收证件工本费，签注不得收费，换领补领应当缴纳工本费；**广州**：补领换领 20 元工本费 | 条例第二十一条；穗公规字〔2019〕2号 |
| 落户衔接通道 | **全国**：城区人口 100 万至 500 万的大城市，对参加城镇社会保险年限的要求**不得超过 5 年**，其中 300 万至 500 万的可结合本地实际建立积分落户制度；500 万以上的特大和超大城市应当建立完善积分落户制度；**广州**：2025 年度积分制入户设六项条件（稳定就业或创业、45 周岁以下、持本市有效《广东省居住证》、社保满 4 年、总积分满 150 分、近 5 年无刑事处罚），年度入户指标 1.6 万个 | 条例第十六条；广州市政府门户网站 2025 年度积分制入户通告 |
| 居住证能开哪些门 | **全国**：条例列明的基本公共服务包括义务教育、基本公共就业服务、基本公共卫生服务和计划生育服务、公共文化体育服务、法律援助和其他法律服务等；便利事项包括办理出入境证件、换领补领居民身份证、机动车登记、申领机动车驾驶证、报名参加职业资格考试、办理生育服务登记等共 7 项 | 条例第十二条、第十三条 |

## 信息核实方式

| 你想核什么 | 去哪核 |
|---|---|
| 条例原文与条文序号 | 中国政府网政策文件库；或《国务院公报》2016 年第 1 号正式文本 |
| 本地申领条件、签注规则、收费 | 本地政务服务网／本地公安局户政栏目；多数城市可在政务 App 内查办事指南 |
| 本地是否要求先办居住登记 | 居住地社区事务受理中心或派出所；先打电话问一句最省事 |
| 落户衔接与积分规则 | 本地「户籍」政策专栏，或人社／公安部门官网发布的当年度通告 |
| 政策是否已更新 | 国家法律法规数据库 `flk.npc.gov.cn` 查条例效力；地方文件查发文机关最新公布件 |

> **本文不能作为最终依据。** 各城市的门槛、材料清单、签注细节差异很大，且常有年度调整——请以受理单位的现行口径为准。

## 行动清单

- [ ] 到居住地后**先办居住登记**，把居住时长的起算点定下来
- [ ] 满半年后，用「住址／就业／就读」中**最容易拿到的那一类**证明去申领
- [ ] 材料不齐时，要求**一次性告知**全部补充项
- [ ] 拿到证后，把**签注日期**加进手机年度提醒（每满 1 年前 1 个月内办理）
- [ ] 换工作、搬家后，**及时更新信息**，别等到签注时才发现对不上
- [ ] 准备落户的，**先查清目标城市的年限互认规则**，再决定换不换城市
- [ ] 遇到收费名目先问依据：首次申领免工本费、签注不收费
